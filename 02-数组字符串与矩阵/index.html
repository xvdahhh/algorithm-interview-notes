本章的主线：维护一段区间，而不是反复扫描

数组、字符串和矩阵题经常从枚举起步，再通过保留相邻状态之间的共同信息优化。双指针利用顺序排除不可能的候选；滑动窗口增量维护连续区间；前缀和复用区间外的累计量；矩阵模拟则维护尚未处理的边界。

先分清三个词：子数组与子串要求连续，子序列可以跳过元素。排序可以帮助判断数值大小，但会改变原来的邻接关系，因此“连续子数组”问题通常不能为了方便双指针而先排序。

02.01

相向双指针与三数之和

知识与适用场景

有序性让一次比较能够排除一批候选。两数之和小于目标时，固定右端点并减小左值不可能成功，因此必须增大左端点。三数之和先固定一个数，再把剩余问题变成两数之和。

1.1 数组与字符串：下标访问快，搬移和复制不免费

vector 的元素连续存储，按下标访问 O(1)，尾部 push_back 均摊 O(1)，中间插入或删除通常需要移动后续元素，最坏 O(n)。反复从数组中间 erase 可能把一次遍历变为 O(n²)。因此很多“删除”题只要求把保留值压到前面，返回新的有效长度。

string 也提供下标访问，但 substr 会复制选定字节，反复截取长子串同样可能导致平方复杂度。扫描时尽量记录左右下标，最后只构造一次结果。字符频次已知只有 a..z 时用 26 长度数组；本章通用字节计数用 256 并将索引转为 unsigned char。

1.2 相向双指针：移动依据来自一个可排除的集合

对非降序数组，固定当前左端 l。如果 a[l]+a[r]<target，那么任意 j≤r 都满足 a[l]+a[j]≤a[l]+a[r]<target，因此 a[l] 不可能参与剩余范围内的答案，可以安全执行 ++l。

反过来，若 a[l]+a[r]>target，任意 i≥l 与 a[r] 配对只会更大，因此可以 --r。找到解后如何继续取决于题目：只求一组可返回；求不同数值对需要跳过重复值；求所有下标对则不能简单跳过重复元素。

1.3 读写指针：有序数组原地去重

循环开始时，[0,write) 是已读前缀中去重后的有序结果；read 指向下一个待读元素。因为 write≤read，写入不会覆盖未来未读取的数据。比较上一份已保留值，就能判断当前值是否是新值。

例如 [1,1,2,2,3] 最后返回 3，前缀为 [1,2,3]，后面的元素不再有意义。时间 O(n)、额外空间 O(1)。若接口确实要求缩小容器，可在结束后调用 resize(write)，不要逐个 erase。

C++17
下载 .cpp
int removeDuplicatesSorted(vector<int>& a) {
    int write = 0;
    for (int read = 0; read < (int)a.size(); ++read) {
        if (write == 0 || a[read] != a[write - 1]) {
            a[write] = a[read];
            ++write;
        }
    }
    return write; // 仅 [0, write) 是结果，vector.size() 未改变
}

1.4 移动零：稳定压缩，再补尾部

第一轮按原顺序写入所有非零值，故其相对次序保持不变；第二轮把剩余位置补为 0。比如 [0,1,0,3,12] 变为 [1,3,12,0,0]。总时间 O(n)，额外空间 O(1)。读写同位置是合法赋值，无需额外分支。

C++17
下载 .cpp
void moveZeroes(vector<int>& a) {
    int write = 0;
    for (int read = 0; read < (int)a.size(); ++read) {
        if (a[read] != 0) a[write++] = a[read];
    }
    for (int i = write; i < (int)a.size(); ++i) a[i] = 0;
}

1.5 盛水容器：为什么移动短板而非长板？

假设左高度≤右高度，当前容量受左侧限制。固定左端而把右端左移，宽度下降、高度上限仍不超过左高度，因此不可能比当前容器更大；可以丢弃左端。两端一样高时任意移动一端都安全。注意此题不能排序，因为原下标距离参与面积。

时间 O(n)、空间 O(1)。这是与两数之和不同的移动证明：两者都用相向指针，但不能只背“和小就左移”这样的表面规则。

C++17
下载 .cpp
long long maxArea(const vector<int>& height) {
    // 前提：所有高度非负。
    int left = 0, right = (int)height.size() - 1;
    long long best = 0;
    while (left < right) {
        best = max(best, 1LL * (right - left)
                         * min(height[left], height[right]));
        if (height[left] <= height[right]) ++left;
        else --right;
    }
    return best;
}

1.6 字符串两端比较：回文与输入语义

这段代码判断原始字节序列是否对称，时间 O(n)、空间 O(1)，空串和单字节串返回 true。若题目要求忽略标点和大小写，需要先规定允许字符的集合，再在两端跳过无效字符并统一大小写。UTF-8 中一个汉字通常占多个字节，不能把字节反转或字节回文当成字符级判断。

C++17
下载 .cpp
bool isBytePalindrome(const string& s) {
    int left = 0, right = (int)s.size() - 1;
    while (left < right) {
        if (s[left] != s[right]) return false;
        ++left;
        --right;
    }
    return true;
}
推导 / 不变量

先排序，枚举 i；在 (i,n) 内维护 l、r。和小于 0 移动 l，大于 0 移动 r；找到解后跳过两侧重复值。枚举层也要跳过重复的 a[i]。

手推一个例子

[-1,0,1,2,-1,-4] 排序为 [-4,-1,-1,0,1,2]。固定 -1 后可得到 [-1,-1,2] 和 [-1,0,1]；下一个相同的 -1 不必重复枚举。

下载 .cpp
vector<vector<int>> threeSum(vector<int> a) {
    sort(a.begin(), a.end());
    vector<vector<int>> ans;
    int n = (int)a.size();
    for (int i = 0; i + 2 < n; ++i) {
        if (i && a[i] == a[i-1]) continue;
        if (a[i] > 0) break;
        int l = i + 1, r = n - 1;
        while (l < r) {
            long long s = 1LL * a[i] + a[l] + a[r];
            if (s < 0) ++l;
            else if (s > 0) --r;
            else {
                ans.push_back({a[i], a[l], a[r]});
                int x = a[l], y = a[r];
                while (l < r && a[l] == x) ++l;
                while (l < r && a[r] == y) --r;
            }
        }
    }
    return ans;
}
复杂度
时间 O(n²)。该实现复制输入，额外 O(n)，另有输出 O(k)；若原地排序则排序栈通常 O(log n)。
易错点与边界
两数之和返回下标时，排序会破坏原下标，需要保存映射。三个 int 相加前就应转为 long long。

不要把去重变成丢失合法答案

输入 [-1,-1,2] 必须允许同一答案里出现两个 -1。去重的目标是避免重复输出相同三元组，不是禁止选择相等的两个元素。外层检查 i>0 && a[i]==a[i-1]，只跳过重复的固定分支；内层则在已经记录一个解之后跳过该端同值。

四数之和可排序后固定两个下标，再做相向双指针，时间 O(n³)。两个枚举层各自同层去重；所有求和和上下界剪枝都应先提升到 long long，不能等 int 相加溢出后才转换。

面试追问：关键点完整解答

去重为什么要在外层和找到解后分别处理？

外层去重避免同一个固定数值引出重复扫描；找到解后跳过左右同值，避免相同固定点下再次输出同一数值组合。两个层次解决的是不同来源的重复。

有序数组去重为什么可以比较 a[write-1]？

它始终是已保留结果的最后一个值。原输入有序，当前值若等于它就属于同一连续重复段；若不等就是新的数值。write=0 时没有前一个保留元素，必须先短路判断。

排序以后还能直接返回原下标吗？

通常不能，因为排序重排了元素。若原下标重要，可排序 (值,原下标) 对，或直接用哈希表解原数组上的两数之和。三数之和题通常返回数值，因此允许排序。

移动零为什么保持非零值的相对顺序？

读指针从左到右，每遇到一个非零值就追加到输出前缀，写入次序与读到次序完全一致。任意交换当前元素和末尾元素则不一定稳定。

相向指针与读写指针有什么本质区别？

相向指针通过比较排除候选，关键是证明排除安全；读写指针通过已处理前缀构建结果，关键是保持结果含义并不覆盖未读数据。都是两个下标，正确性依据却不同。

如何推广到四数之和？

两层固定下标，把余下目标留给双指针；循环边界保证仍有两个位置可选。按层去重，时间 O(n³)，数值用 long long 计算。可以剪枝，但只有当最小可能和或最大可能和的计算与排序前提都正确时才安全。

02.02

可变滑动窗口：最短合法区间

知识与适用场景

窗口适用于连续区间，并要求能根据当前状态安全决定端点的移动方向。所有元素为正时，右移右端点会增大区间和，右移左端点会减小区间和。

2.1 滑动窗口的前提：连续、可维护、可安全丢弃

滑动窗口的左右端点在原序列上移动，因此它求的是连续子数组或子串。窗口和可用加减维护，字符频次可用计数器维护；能增量维护只是第一步，还必须解释为什么某些左边界从此不必再考虑。

例如最长无重复子串，重复出现后必须移过旧重复位置；更靠左的窗口只会仍然包含重复。正数最短和问题则依赖和的单调性：右侧加入正数不减和，左侧移出正数不增和。

2.3 固定窗口：长度为 k 的最大区间和

窗口固定长度时不依赖正数条件，负数也可使用，因为我们不根据和决定是否跳过某个窗口。维护当前最后 k 个元素的和即可。全负数组必须用负无穷或首个完整窗口初始化答案，不能初始化为 0。时间 O(n)，空间 O(1)。

C++17
下载 .cpp
long long maxFixedWindowSum(const vector<int>& a, int k) {
    if (k <= 0 || k > (int)a.size())
        throw invalid_argument("invalid window length");
    long long sum = 0, best = LLONG_MIN;
    for (int right = 0; right < (int)a.size(); ++right) {
        sum += a[right];
        if (right >= k) sum -= a[right - k];
        if (right >= k - 1) best = max(best, sum);
    }
    return best;
}

2.4 最短正数窗口为什么不漏解？

固定 right，若窗口和仍≥target，就记录长度并右移 left，直到不满足为止。这样把以该 right 结尾且有机会更短的候选都处理了。此前被移走的左端点已经产生过合法窗口；未来右端点更大时，从那个旧左端出发只会更长，不可能改善它已经贡献的长度。

两条指针总共最多移动 2n 次，所以嵌套 while 的整体时间仍是 O(n)。这不是每轮外层重新扫描一个独立长度 n 的区间。对于非负元素、target>0，同样的算法也成立；遇到 0 时仍可继续收缩，不会增加和。

2.5 一条负数就足以破坏按和收缩的逻辑

最短和至少 5，数组 [1,-1,5]。原正数模板在最后得到和 5，记录长度 3，移走 1 后和变 4，于是停止。它不会继续移走 -1，因此漏掉 [5] 这个长度 1 的答案。

失败不是代码少写一个 if，而是“删掉左元素只会降低和”这个前提失效。精确和计数可改用前缀和+哈希；含负数的最短和至少 K，常用前缀和+单调队列，不能简单把计数模板拿来当最短模板。

2.6 最小覆盖子串：重复字符也要满足

missing 统计还缺多少个字符实例，不是不同字符种数。t="AAB" 时必须有两个 A 和一个 B。新增字符只有在其原有数量不足时才填补一个缺口；删除字符后数量低于需求，才重新产生缺口。

扫描时间 O(|s|+|t|)，辅助空间固定 256 项，返回子串另计 O(答案长度)。每次只记录最佳起点和长度，最后统一 substr，避免在循环中复制长字符串。

string minWindow(const string& s, const string& t) {
    if (t.empty()) return "";
    array<int, 256> need{}, have{};
    for (unsigned char c : t) ++need[c];
    int missing = (int)t.size();
    int left = 0, bestStart = 0, bestLength = INT_MAX;
    for (int right = 0; right < (int)s.size(); ++right) {
        unsigned char c = static_cast<unsigned char>(s[right]);
        if (have[c] < need[c]) --missing;
        ++have[c];
        while (missing == 0) {
            if (right - left + 1 < bestLength) {
                bestStart = left;
                bestLength = right - left + 1;
            }
            unsigned char old = static_cast<unsigned char>(s[left++]);
            --have[old];
            if (have[old] < need[old]) ++missing;
        }
    }
    return bestLength == INT_MAX ? "" : s.substr(bestStart, bestLength);
}

两个字符串是否互为异位词，需要每个字符的出现次数相同，不能只比较集合。这里每次比较 256 个计数，时间 O(256·|s|+|pattern|)，在固定字节字符集下写作 O(|s|+|pattern|)。辅助空间 O(256)，输出另计。若字符集不固定，可维护频次差异数来避免每轮完整比较。

vector<int> findAnagrams(const string& s, const string& pattern) {
    if (pattern.empty()) return {}; // 本接口不枚举空模式的位置
    int k = (int)pattern.size();
    array<int, 256> need{}, have{};
    for (unsigned char c : pattern) ++need[c];
    vector<int> answer;
    for (int right = 0; right < (int)s.size(); ++right) {
        ++have[static_cast<unsigned char>(s[right])];
        if (right >= k)
            --have[static_cast<unsigned char>(s[right - k])];
        if (right >= k - 1 && have == need)
            answer.push_back(right - k + 1);
    }
    return answer;
}
推导 / 不变量

求和至少 target 的最短子数组：加入右端点后，只要仍满足条件就记录长度并收缩左端点。收缩结束后，该右端点的所有可能更短合法窗口都已检查。

手推一个例子

target=7，数组 [2,3,1,2,4,3]：到 4 时可从 [2,3,1,2,4] 连续收缩至 [1,2,4]；到 3 时找到 [4,3]，长度为 2。

int minSubArrayLen(long long target, const vector<int>& a) {
    // 前提：target > 0，所有 a[i] > 0。
    long long sum = 0;
    int left = 0, ans = (int)a.size() + 1;
    for (int right = 0; right < (int)a.size(); ++right) {
        sum += a[right];
        while (sum >= target) {
            ans = min(ans, right - left + 1);
            sum -= a[left++];
        }
    }
    return ans > (int)a.size() ? 0 : ans;
}
复杂度
每个元素进入和离开窗口至多一次，时间 O(n)，空间 O(1)。
易错点与边界
含负数时和不再单调。例如 [1,-1,5] 不能简单沿用正数窗口的排除逻辑；最短和至少 K 可用前缀和 + 单调队列。

把模板中的 left、sum、ans 分别说清

left 不是“任意当前位置”，而是当前待继续尝试的窗口起点；sum 必须恰好等于 a[left]..a[right] 的总和；ans 是此前已经确认合法的最短长度。每次减去 a[left] 后再递增 left，使总和与边界保持一致。

最短窗口在 while 内、移除左端前更新答案。若写到 while 之后，此时窗口通常已经不合法；最长无重复窗口则恰好反过来，先收缩到合法，再在 while 之后记录最长长度。

面试追问：关键点完整解答

为什么最短与最长窗口更新答案的位置不同？

最短覆盖想不断缩小一个合法窗口，所以先记录合法状态再删左端；最长合法窗口需要先消除违规，再记录剩下的最长合法状态。更新时机来自目标与不变量，而非固定背诵模板。

有负数时，所有滑动窗口都不能用吗？

不是。固定长度窗口可以含负数，因为不会依据区间和决定跳过左边界。失效的是依赖非负性证明的某些可变窗口，例如最短和至少 target。

为什么空目标串要先返回？

最小覆盖实现中空目标让 missing 一开始就是 0，若仍进入不断收缩的 while，可能越过有效窗口。先定义空目标的结果并特判，能同时解决语义和边界问题。

t=AAB，仅维护字符种类是否足够？

不够。窗口 AB 的种类已经包含 A、B，但还缺一个 A。可以统计缺失实例数，也可以统计已经达到需求次数的种类数；后一种必须在计数达到/跌破阈值时更新。

为什么 found 窗口后只保存下标，不立即截取？

substr 会复制字符。若每次改善都复制一个很长的窗口，额外成本可能很大；记录起点与长度是 O(1)，最后只复制一次答案。

异位词判断能否只比较字符总和或异或？

不能，一种摘要值通常会碰撞，不同频次也可能具有相同和或异或。题目要求确定正确时，维护完整频次或等价的无损信息。

最短窗口无解时为什么返回 0？

这是当前正数最短子数组接口的约定：合法答案长度至少为 1，所以 0 可以表示不存在。最小覆盖子串接口则返回空串。返回约定要按题目确认，不能在不同题目间混用。

02.03

前缀和、差分与区间计数

知识与适用场景

前缀和把静态区间和转成两个累计值之差。定义 pre[0]=0，pre[i+1]=pre[i]+a[i]，则闭区间 [l,r] 的和为 pre[r+1]-pre[l]。差分则把多次区间加法转成端点修改，最后一次前缀还原。

3.1 一维前缀和：统一用“前几个元素”定义

定义 pre[k] 是前 k 个元素之和，pre[0]=0，pre[k+1]=pre[k]+a[k]。闭区间 [l,r] 有 r-l+1 个元素，对应 pre[r+1]-pre[l]；若接口采用半开区间 [l,r)，则是 pre[r]-pre[l]。两个公式都正确，但不能把接口和公式混着用。

前缀和把一次 O(区间长度) 的查询转成 O(1)。n 个元素预处理 O(n)，q 次查询总计 O(n+q)，辅助空间 O(n)。它适合数组基本不变的情况；单点修改会影响此位置之后的所有前缀，更新最坏 O(n)。

3.2 精确和计数：从等式中确定哈希键

一个连续区间的和等于 k，即 pre[right+1]-pre[left]=k。移项后，需要此前存在 pre[left]=pre[right+1]-k。扫描右端点时，当前前缀已知，所以查哈希中的“当前前缀-k”即可。

同一个前缀值可能出现多次，每一次都对应不同左边界，因此求数量必须存频次，不能只存一个下标。先查询此前频次，再插入当前前缀，才能保证左边界不越过右边界，也不会把长度 0 区间计入。

3.3 同一个前缀等式，求最长时保存最早位置

对于固定的右边界 end，左前缀位置越早，区间越长。因此同一个前缀值只保留最早下标。平均时间 O(n)、空间 O(n)，哈希最坏可退化。返回 0 表示不存在非空合法区间。

例如 [1,-1,5,-2,3]、k=3，前四个元素之和为 3，长度 4。若要求最短“精确和”区间，则可保存最新的前缀位置并调整答案目标；最短“至少为 k”不是同一等式，不能直接这样改。

int longestSubarraySum(const vector<int>& a, long long k) {
    unordered_map<long long, int> first;
    first[0] = 0; // 空前缀的位置，以“元素个数”为下标
    long long prefix = 0;
    int best = 0;
    for (int end = 1; end <= (int)a.size(); ++end) {
        prefix += a[end - 1];
        auto it = first.find(prefix - k);
        if (it != first.end()) best = max(best, end - it->second);
        first.emplace(prefix, end); // 已存在时不覆盖，保留最早出现位置
    }
    return best;
}

3.4 差分：把区间操作只记在两端

令 diff[0]=a[0]，diff[i]=a[i]-a[i-1]。从左到右累加 diff 就能还原原数组。给闭区间 [l,r] 每项加 x，只需 diff[l]+=x、diff[r+1]-=x；前一个操作让从 l 开始的累计值增加，后一个在 r 后将影响抵消。

多次区间更新可相互叠加：每次 O(1) 记端点，最后 O(n) 还原。若有 m 次更新，总时间 O(n+m)、空间 O(n)。这不表示差分能在每次更新后 O(1) 查询任意区间和；动态查询需另选数据结构。

批量区间加法：预留 r+1 的哨兵位置

前提：所有差分、更新累计和最终结果都在 long long 范围内。空数组允许没有更新；非空区间更新不能落在空数组上。返回新数组保留原输入。

例如全零数组长度 5，依次给 [1,3] 加 2、[2,4] 加 3，端点相加后的 diff 为 [0,2,3,0,-2,-3]，累加前五项得到 [0,2,5,5,3]。

vector<long long> applyRangeAdds(
    const vector<int>& a,
    const vector<tuple<int, int, long long>>& updates) {
    int n = (int)a.size();
    vector<long long> diff(n + 1, 0);
    for (int i = 0; i < n; ++i)
        diff[i] = (long long)a[i] - (i == 0 ? 0LL : a[i - 1]);
    for (auto [left, right, value] : updates) {
        if (left < 0 || right < left || right >= n)
            throw out_of_range("invalid update interval");
        diff[left] += value;
        diff[right + 1] -= value; // right=n-1 时写入 diff[n] 仍安全
    }
    vector<long long> result(n);
    long long current = 0;
    for (int i = 0; i < n; ++i) {
        current += diff[i];
        result[i] = current;
    }
    return result;
}

3.5 二维前缀和：四块区域的容斥

定义 pre[r][c] 为原矩阵前 r 行、前 c 列的和，多开一行一列 0。构造式为 pre[r+1][c+1]=a[r][c]+pre[r][c+1]+pre[r+1][c]-pre[r][c]：上方和左方重叠的左上矩形被加了两次，所以减一次。

查询闭矩形 (r1,c1)..(r2,c2) 时，先取 pre[r2+1][c2+1]，减去上方 pre[r1][c2+1] 与左方 pre[r2+1][c1]，再加回被重复扣掉的 pre[r1][c1]。构造与查询的容斥符号看似相近，但坐标含义必须分别推导。

二维静态区域和：建表 O(RC)，查询 O(1)

假设各中间表达式不溢出 long long。辅助空间 O(RC)，输入要求规则矩形，构造函数会检查行长。空矩阵可以构造，但没有任何合法非空矩形查询。

对 [[1,2,3],[4,5,6]] 查询 (0,1)..(1,2)，结果为 2+3+5+6=16；查询整张矩阵为 21。

class Prefix2D {
    int rows, cols;
    vector<vector<long long>> pre;
public:
    explicit Prefix2D(const vector<vector<int>>& a)
        : rows((int)a.size()), cols(a.empty() ? 0 : (int)a[0].size()),
          pre(rows + 1, vector<long long>(cols + 1, 0)) {
        for (const auto& row : a)
            if ((int)row.size() != cols)
                throw invalid_argument("rectangular matrix required");
        for (int r = 0; r < rows; ++r)
            for (int col = 0; col < cols; ++col)
                pre[r + 1][col + 1] = (long long)a[r][col]
                    + pre[r][col + 1] + pre[r + 1][col] - pre[r][col];
    }
    long long query(int r1, int c1, int r2, int c2) const {
        if (r1 < 0 || c1 < 0 || r2 < r1 || c2 < c1
            || r2 >= rows || c2 >= cols)
            throw out_of_range("invalid rectangle");
        return pre[r2 + 1][c2 + 1] - pre[r1][c2 + 1]
             - pre[r2 + 1][c1] + pre[r1][c1];
    }
};

3.6 前后缀乘积：除自身以外的乘积，不使用除法

第一遍 answer[i] 保存 i 左边所有元素之积；第二遍乘上 i 右边所有元素之积，所以始终排除当前位置。空积取 1，零元素自然被正确处理，不需要除法也不需要单独分支。时间 O(n)，除输出外辅助空间 O(1)。

[1,2,3,4] 的左乘积为 [1,1,2,6]，配合右乘积得到 [24,12,8,6]。若只有一个 0，只有该 0 所在位置可能得到非零答案；至少两个 0 时全部为 0。前缀/后缀中间乘积仍可能很大，不能仅凭最终答案小就认为安全。

vector<long long> productExceptSelf(const vector<int>& a) {
    // 前提：下列前缀、后缀及输出乘积均不溢出 long long。
    int n = (int)a.size();
    vector<long long> answer(n, 1);
    long long left = 1;
    for (int i = 0; i < n; ++i) {
        answer[i] = left;
        if (i + 1 < n) left *= a[i];
    }
    long long right = 1;
    for (int i = n - 1; i >= 0; --i) {
        answer[i] *= right;
        if (i > 0) right *= a[i];
    }
    return answer;
}
推导 / 不变量

求和为 k 的子数组：当前前缀和为 pre，需要统计此前 pre-k 的数量。先查询再插入当前前缀，避免把长度 0 的区间算进去。

手推一个例子

[1,1,1]，k=2：前缀和 0、1、2、3。在 pre=2 时查到 0 一次；pre=3 时查到 1 一次，答案 2。这个方法允许负数。

C++17
下载 .cpp
long long subarraySum(const vector<int>& a, long long k) {
    unordered_map<long long, long long> freq;
    freq[0] = 1;
    long long pre = 0, ans = 0;
    for (int x : a) {
        pre += x;
        auto it = freq.find(pre - k);
        if (it != freq.end()) ans += it->second;
        ++freq[pre];
    }
    return ans;
}
复杂度
哈希平均时间 O(n)，最坏可达 O(n²)，额外空间 O(n)。答案最多 n(n+1)/2，使用 long long。
易错点与边界
差分 diff[r+1]-=x 要预留 n+1 位置。二维前缀查询需要减去两侧、加回重复扣除的左上角。

把原计数模板与本节扩展对应起来

原模板的 freq[0]=1 表示“当前元素之前存在一个空前缀”，这样从数组第 0 项开始的合法区间也能被统一发现。它存的是次数；longestSubarraySum 中的 first[0]=0 存的是前缀位置，含义不同。

原模板每次先查 pre-k，累加频次，再 ++freq[pre]。若 k=0 且先插入，本轮新前缀会与自己配对，多算一个空区间。答案可能达到 n(n+1)/2，因此不仅 pre，ans 和频次也应按规模选择足够宽的整数。

经典考点与练习

练习：LeetCode 560 和为 K 的子数组、304 二维区域和检索、1109 航班预订统计。

面试追问：关键点完整解答

为什么 freq[0]=1，不能省略吗？

它代表任何元素尚未读取时的空前缀。如果当前 pre 恰好等于 k，pre-k=0，空前缀使从下标 0 开始的区间被计入。省略会漏掉这类答案。

同一个前缀状态，求数量、最长、最短分别存什么？

数量存频次；最长精确和存最早位置；最短非空精确和可存最新位置，并在更新当前前缀前先查询。不能把“最短精确和”与“最短至少为 k”混为一谈。

含负数时前缀和为什么仍然正确？

区间和由两个累计和相减是代数恒等式，不需要累计和单调。负数影响某些窗口或二分的前提，但不会破坏前缀和等式。

差分的 r+1 为什么要减去 x？

diff[l]+=x 会让从 l 往后的每个累计值都增加 x；为了只影响到 r，在 r+1 开始减回 x。使用 n+1 长度的差分数组，让最后一个位置之后也有可写的哨兵。

二维前缀查询为什么最后是加左上区域？

减去上方和左方时，它们共同的左上矩形被减了两遍，但只应减一次。因此加回一次，正好得到目标矩形。

差分适合哪些操作组合，不适合哪些？

适合很多区间增减后统一还原或一次性检查。若每次更新之后都要立即做区间求和，反复还原会很慢，可考虑树状数组或带懒标记的线段树。

不用除法算乘积如何处理零？

前后缀乘积自动排除当前位置。如果唯一的零在 i，answer[i] 的左右两段都不含零，可能非零；其他位置的某一侧包含零，结果为零。两个及以上零会使每个位置的左右部分至少包含一个零。

02.04

矩阵边界与螺旋遍历

知识与适用场景

矩阵模拟先明确四条边界，再按固定方向访问。每走完一条边缩小对应边界；对于单行、单列，必须在折返前检查是否还有未访问区域。

4.1 矩阵题先确认坐标、形状和访问成本

通常 a[r][c] 表示第 r 行第 c 列，合法范围是 0≤r<R、0≤c<C。先判断外层为空，再读 a[0].size()。vector<vector<int>> 每一行独立存储，不保证所有行连接成一个连续内存块，因此不能直接对 &a[0][0] 做跨行平铺访问。

规则矩形要求每行列数一致。在线题经常保证这一点，通用函数则应检查或明确前提。方向数组统一使用 (dr,dc)，别把行列的偏移次序写反；必须先验证邻居坐标，再读取数组。

4.2 螺旋遍历的不变量：四条边围出所有剩余元素

top..bottom 与 left..right 始终构成尚未访问的矩形。按上、右、下、左依次走边，每走完一条就缩小对应边界。新边界可能已经交错，所以折返前需要重新判断。

原模板在上边走完后 ++top，右边走完后 --right。如果只剩一行，这时 top>bottom，下边不能再走；如果只剩一列，则 left>right，左边不能重复走。不要只依赖最外层 while，因为边界在这一轮内部已经改变。

4.3 顺时针旋转：转置，再反转每一行

方阵顺时针旋转的坐标映射是 (r,c)→(c,n-1-r)。转置完成 (r,c)→(c,r)，每行反转再变为 (c,n-1-r)，组合后正好是目标。转置只遍历对角线一侧，每对元素交换一次；遍历整个矩阵会交换两次，抵消效果。

[[1,2],[3,4]] 先转置为 [[1,3],[2,4]]，再反转各行得到 [[3,1],[4,2]]。时间 O(n²)，额外空间 O(1)。长方形 R×C 旋转后是 C×R，通常创建新矩阵并写 result[c][R-1-r]=a[r][c]。

void rotateClockwise(vector<vector<int>>& a) {
    int n = (int)a.size();
    for (const auto& row : a)
        if ((int)row.size() != n)
            throw invalid_argument("square matrix required");
    for (int r = 0; r < n; ++r)
        for (int col = r + 1; col < n; ++col)
            swap(a[r][col], a[col][r]);
    for (auto& row : a) reverse(row.begin(), row.end());
}

4.4 矩阵置零：新写入的零不能冒充原始零

若看到一个 0 就立刻清空整行整列，后面扫描时可能把新产生的 0 当成原始 0，扩散出多余的清零。例如 [[1,1,1],[1,0,1],[1,1,1]] 只应清中间行列，而非整个矩阵。

简单可靠版本先用行标记和列标记记录原始零，额外空间 O(R+C)。要压到 O(1)，可用第一行和第一列作为标记区，但它们本身是否需要清零必须提前用两个布尔变量保存。

常数辅助空间置零：先记录，后应用

第一轮先保存首行/首列的原始状态；第二轮扫描内部并写标记；第三轮只根据标记清空内部；最后再处理首行和首列。顺序保证标记在用完之前不会被整体清空。时间 O(RC)，额外空间 O(1)。

void setZeroes(vector<vector<int>>& a) {
    if (a.empty()) return;
    int rows = (int)a.size(), cols = (int)a[0].size();
    for (const auto& row : a)
        if ((int)row.size() != cols)
            throw invalid_argument("rectangular matrix required");
    if (cols == 0) return;
    bool firstRowZero = false, firstColZero = false;
    for (int col = 0; col < cols; ++col)
        if (a[0][col] == 0) firstRowZero = true;
    for (int r = 0; r < rows; ++r)
        if (a[r][0] == 0) firstColZero = true;
    for (int r = 1; r < rows; ++r)
        for (int col = 1; col < cols; ++col)
            if (a[r][col] == 0) {
                a[r][0] = 0;
                a[0][col] = 0;
            }
    for (int r = 1; r < rows; ++r)
        for (int col = 1; col < cols; ++col)
            if (a[r][0] == 0 || a[0][col] == 0) a[r][col] = 0;
    if (firstRowZero) fill(a[0].begin(), a[0].end(), 0);
    if (firstColZero)
        for (int r = 0; r < rows; ++r) a[r][0] = 0;
}

4.5 每行每列有序：从右上角排除一行或一列

前提是每行从左到右非降序、每列从上到下非降序。右上角值过大，则该列下方只会更大，排除这一列；值过小，则该行左方只会更小，排除这一行。每步至少删一行或一列，总时间 O(R+C)，额外空间 O(1)。

“每行每列有序”不保证按行拼接后有序。例如 [[1,4],[2,5]] 的平铺序列 [1,4,2,5] 无序，不能直接整体二分。只有进一步保证下一行首元素大于等于上一行尾元素时，才具备按行展开后二分的前提。

bool searchSortedMatrix(const vector<vector<int>>& a, int target) {
    if (a.empty()) return false;
    int rows = (int)a.size(), cols = (int)a[0].size();
    for (const auto& row : a)
        if ((int)row.size() != cols)
            throw invalid_argument("rectangular matrix required");
    int r = 0, col = cols - 1;
    while (r < rows && col >= 0) {
        if (a[r][col] == target) return true;
        if (a[r][col] > target) --col;
        else ++r;
    }
    return false;
}

4.6 岛屿数量：把网格当成隐式图

每发现一个未访问的陆地，就启动一次 BFS 并消去整个四邻接连通块，所以启动次数就是岛屿数。下标 (r,c) 是图节点，不需要真的创建邻接表。时间 O(RC)，队列辅助空间最坏 O(RC)。代码会修改输入；若禁止修改，需单独 visited。

必须入队时标记，否则同一陆地可能被多个邻居重复加入。对角接触是否连通取决于题目：本例只有上下左右四个方向，不能擅自加入斜方向。BFS 队列避免了大网格递归 DFS 的调用栈过深问题。

int countIslands(vector<vector<char>>& grid) {
    if (grid.empty()) return 0;
    int rows = (int)grid.size(), cols = (int)grid[0].size();
    for (const auto& row : grid)
        if ((int)row.size() != cols)
            throw invalid_argument("rectangular grid required");
    const int dr[4] = {-1, 1, 0, 0};
    const int dc[4] = {0, 0, -1, 1};
    int count = 0;
    for (int r = 0; r < rows; ++r)
        for (int col = 0; col < cols; ++col) {
            if (grid[r][col] != '1') continue;
            ++count;
            queue<pair<int, int>> pending;
            grid[r][col] = '0'; // 入队时即标记
            pending.push({r, col});
            while (!pending.empty()) {
                auto [x, y] = pending.front();
                pending.pop();
                for (int dir = 0; dir < 4; ++dir) {
                    int nx = x + dr[dir], ny = y + dc[dir];
                    if (nx < 0 || nx >= rows || ny < 0 || ny >= cols)
                        continue;
                    if (grid[nx][ny] != '1') continue;
                    grid[nx][ny] = '0';
                    pending.push({nx, ny});
                }
            }
        }
    return count;
}

上边从左到右，右边从上到下，下边从右到左，左边从下到上。top/bottom/left/right 始终围成尚未输出的矩形。

vector<int> spiralOrder(const vector<vector<int>>& a) {
    if (a.empty() || a[0].empty()) return {};
    vector<int> ans;
    int top = 0, bottom = (int)a.size()-1;
    int left = 0, right = (int)a[0].size()-1;
    while (top <= bottom && left <= right) {
        for (int c = left; c <= right; ++c) ans.push_back(a[top][c]);
        ++top;
        for (int r = top; r <= bottom; ++r) ans.push_back(a[r][right]);
        --right;
        if (top <= bottom) {
            for (int c = right; c >= left; --c) ans.push_back(a[bottom][c]);
            --bottom;
        }
        if (left <= right) {
            for (int r = bottom; r >= top; --r) ans.push_back(a[r][left]);
            ++left;
        }
    }
    return ans;
}
复杂度
时间 O(RC)，除输出外额外空间 O(1)。假设每行列数相同。
易错点与边界
原地旋转 90° 仅对方阵可直接采用转置 + 每行反转。网格搜索中坐标合法性检查必须在数组访问之前。

矩阵题的检查顺序

先确认矩阵形状和空值，再确认行列下标范围，然后明确当前访问会不会修改未来依赖的信息。螺旋遍历依赖未访问边界，旋转依赖成对交换不重复，置零依赖原始标记，网格搜索依赖访问状态——每类题的不变量不同。

复杂度要用 R 与 C 表述：遍历矩形一般是 O(RC)，不是笼统的 O(n²)。若输出全部元素，结果本身占 O(RC)，应与辅助空间分开报告。

面试追问：关键点完整解答

只剩一行或一列时，螺旋遍历如何避免重复？

每走完一条边就立即收紧对应边界；下边开始前检查 top≤bottom，左边开始前检查 left≤right，同时循环本身使用最新行界。外层开始时合法，不代表走完两条边后仍有剩余矩形。

旋转为什么只交换上三角区域？

转置交换 (r,c) 和 (c,r)。如果上下三角都遍历，第一次交换后第二次又交换回来。只遍历 c>r，恰好覆盖每一对非对角元素一次。

矩阵置零为什么最后处理首行和首列？

它们在中途是标记存储区；提前清空会把所有行/列误标成需要置零。先保存首行首列原始零状态，等内部清理完再用这两个布尔值收尾。

vector<vector<int>> 可以视为平铺数组吗？

逻辑上可把线性下标 i 映射为行 i/C、列 i%C，但物理上各行未必相邻，因此不能用单个 int* 无条件跨越行访问。整体二分还需要额外的全局有序性。

为什么网格搜索在入队时标记，而不是出队时？

入队即标记让每个节点最多入队一次。若出队才标记，它等待期间可能被多个邻居反复加入，增加处理与内存，甚至让某些计数逻辑重复执行。

每行每列都有序，为什么选择右上角而非左上角？

右上角向左不增、向下不减，一次比较能排除一整列或一整行。左上角的右侧和下侧都不小于它，目标更大时无法仅凭一次比较决定排除哪一个方向。

综合例题与章末自测

综合例题：相同的“区间和”，目标一变算法就变

现在求“和恰好等于 k 的连续子数组数量”，允许负数、零和重复前缀。先从暴力出发：枚举左端点 l，再向右累加；每增加一个元素只更新当前和，不重新求整段和。这样是 O(n²)，而不是三层重算的 O(n³)。

优化的关键是 pre[end]-pre[start]=k。扫描到 end 时，所有合法左前缀都已见过，只需查询 pre[end]-k 的频次。于是平均时间降到 O(n)，辅助空间 O(n)。一条方程就解释了查询键、频次值、空前缀初始化和更新顺序四个实现细节。

若改为“最短和至少 k 且全为正数”，使用本章窗口；若允许负数，则需要前缀和+单调队列等方法；若改为“很多次指定区间查询”，使用前缀数组直接相减。看清题目的目标和限制，比看到关键词就套模板更重要。

long long bruteCount(const vector<int>& a, long long k) {
    long long answer = 0;
    for (int left = 0; left < (int)a.size(); ++left) {
        long long sum = 0;
        for (int right = left; right < (int)a.size(); ++right) {
            sum += a[right];
            if (sum == k) ++answer;
        }
    }
    return answer;
}
long long prefixCount(const vector<int>& a, long long k) {
    unordered_map<long long, long long> frequency;
    frequency[0] = 1;
    long long prefix = 0, answer = 0;
    for (int x : a) {
        prefix += x;
        auto it = frequency.find(prefix - k);
        if (it != frequency.end()) answer += it->second;
        ++frequency[prefix];
    }
    return answer;
}
int main() {
    assert(prefixCount({}, 0) == 0);
    assert(prefixCount({0}, 0) == 1);
    assert(prefixCount({0, 0, 0}, 0) == 6);
    assert(prefixCount({1, -1, 1}, 1) == 3);
    assert(prefixCount({1, 1, 1}, 2) == 2);
    assert(prefixCount({1000000000, 1000000000, 1000000000},
                       3000000000LL) == 1);

    mt19937 rng(20260918);
    uniform_int_distribution<int> length(0, 12), value(-3, 3), target(-8, 8);
    for (int trial = 0; trial < 1000; ++trial) {
        vector<int> a(length(rng));
        for (int& x : a) x = value(rng);
        int k = target(rng);
        long long slow = bruteCount(a, k), fast = prefixCount(a, k);
        if (slow != fast) {
            cerr << "Mismatch: k=" << k << ", input:";
            for (int x : a) cerr << ' ' << x;
            cerr << "\nbrute=" << slow << ", prefix=" << fast << '\n';
            return 1;
        }
    }
    cout << "boundary and differential checks passed\n";
}

章末自测：把规则还原成理由

连续子数组问题先排序再做双指针，有什么风险？

排序会改变原始相邻关系。例如原数组中不相邻的元素排序后可能相邻，从而得到不属于原题的“连续区间”。只有问题不关心原顺序，或题目本来有序时，才能据此使用排序。

把最短窗口更新答案移到 while 外会怎样？

收缩循环结束时，窗口通常已经不满足目标。此时记录长度会把非法窗口作为答案。正确做法是每次仍合法时先记录，再移除左端。

“含负数就用前缀和+哈希”总是完整答案吗？

不是。前缀和是表示方式，后续结构由目标决定。精确和计数可查频次，精确和最长可存最早位置，最短和至少 k 往往需要单调队列。

三数之和输入 [0,0,0,0] 应输出几个数值三元组？

只输出一个 [0,0,0]。虽然有多个下标组合，但本题通常要求不同数值三元组；若题意改为统计下标组合，答案和去重方法都要改变。

异位词串 abab 与 aabb 相同吗？回文判断呢？

它们字符频次相同，因此互为异位词；但回文要求位置对称，不能靠频次判断。这体现出集合、次数、顺序是不同的信息。

差分的更新和前缀和的查询为什么都只涉及端点？

区间加法在差分中只改变进入和离开区间时的跳变量；区间求和在前缀中是累计量相减。它们都利用了区间内部重复贡献相互抵消，但服务的操作方向相反。

把 [[1,4],[2,5]] 平铺后二分为什么错误？

按行平铺为 [1,4,2,5]，并非有序。只有每行、每列有序不足以支撑整体二分；可从右上角按行列单调性排除。
