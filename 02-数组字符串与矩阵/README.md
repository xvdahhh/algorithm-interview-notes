## 数组与字符串基础

- 数组支持 `O(1)` 随机访问，但中间插入删除通常为 `O(n)`。
- 字符串题先确认字符集：只有小写字母可用长度 26 的数组；Unicode 或未知字符集更适合哈希表。
- 原地修改时区分“读指针”和“写指针”，常用于删除重复项、移动零、压缩字符串。

## 双指针

### 相向双指针

适合有序数组、回文判断、两数之和、盛水容器。关键是证明每次移动一侧不会漏掉答案。

```text
left = 0, right = n - 1
while left < right:
    根据当前状态更新答案
    移动能排除无效解的一侧
```

### 同向双指针

适合原地去重、链表快慢指针、维护合法区间。两个指针通常分别表示已处理区域边界与扫描位置。

## 滑动窗口

用于“连续子数组/子串”且窗口合法性可随左右端点增量维护的问题。

```text
left = 0
for right in [0..n-1]:
    加入 right 对应元素
    while 窗口不合法:
        移除 left 对应元素
        left += 1
    更新答案
```

- 固定窗口：每次加入一个、移出一个。
- 可变窗口：右端扩张，左端收缩到重新合法。
- 若元素含负数，“和越大就收缩”往往不再单调，不能直接套窗口。

## 前缀和与差分

- 一维前缀和：`pre[i+1] = pre[i] + a[i]`，区间 `[l,r]` 的和为 `pre[r+1]-pre[l]`。
- 前缀和 + 哈希：把“区间和等于 k”转为查找此前是否出现 `pre-k`。
- 二维前缀和：用容斥在 `O(1)` 查询子矩形和。
- 差分数组：适合多次区间增减、最后一次性还原；区间 `[l,r] += x` 对差分做 `diff[l]+=x, diff[r+1]-=x`。

## 矩阵常见技巧

- 方向数组统一处理上下左右：`[(1,0),(-1,0),(0,1),(0,-1)]`。
- 螺旋遍历维护 `top/bottom/left/right`，每走完一条边立即检查边界。
- 原地旋转常拆成“转置 + 翻转”。
- 岛屿类问题本质是网格图 DFS/BFS，注意标记访问时机。

## 高频题型

- 三数之和：排序 + 枚举一个数 + 相向双指针，并处理重复值。
- 最长无重复子串：窗口 + 字符最后出现位置。
- 最小覆盖子串：窗口内计数与“已满足种类数”。
- 除自身以外数组的乘积：左右乘积，避免除法。
- 合并区间：排序后维护当前区间。

## 易错点与自测

- [ ] 明确区间采用 `[l,r]` 还是 `[l,r)`，全程统一。
- [ ] 窗口答案是在扩张后、收缩中还是收缩后更新。
- [ ] 前缀数组通常多开一位，避免 `l=0` 特判。
- [ ] 矩阵先判断是否为空，再读取列数。
- [ ] 去重题能解释为何跳过某一侧的重复值。
