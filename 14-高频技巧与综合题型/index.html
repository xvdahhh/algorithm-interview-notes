14.01

LRU 缓存：哈希 + 双向链表

知识与适用场景

LRU 淘汰最久未使用的键。哈希提供按键 O(1) 定位，双向链表提供 O(1) 移动和删除。约定链表头为最近使用，尾为最久未使用。

推导 / 不变量

get 命中时把节点移到头；put 已存在时更新并移到头；新键插入后超容量则删除尾部，同时移除哈希项。两个结构必须始终保存相同键集合。

手推一个例子

容量 2：put(1)、put(2)、get(1) 后顺序为 1、2；put(3) 淘汰 2，保留 3、1。

C++17
下载 .cpp
class LRUCache {
    size_t cap;
    list<pair<int,int>> order;
    unordered_map<int,list<pair<int,int>>::iterator> pos;
public:
    explicit LRUCache(int capacity):cap(max(0,capacity)){}
    LRUCache(const LRUCache&)=delete;
    LRUCache& operator=(const LRUCache&)=delete;
    int get(int key){
        auto it=pos.find(key);
        if(it==pos.end()) return -1;
        order.splice(order.begin(),order,it->second);
        return it->second->second;
    }
    void put(int key,int value){
        auto it=pos.find(key);
        if(it!=pos.end()){
            it->second->second=value;
            order.splice(order.begin(),order,it->second);
            return;
        }
        if(cap==0) return;
        order.emplace_front(key,value);
        pos[key]=order.begin();
        if(order.size()>cap){
            pos.erase(order.back().first);
            order.pop_back();
        }
    }
};
复杂度
哈希平均每次操作 O(1)，空间 O(capacity)；哈希极端情况可能退化。
易错点与边界
list::splice 移动节点不会使该节点迭代器失效。不能用 vector 存位置并期待中间删除 O(1)。示例禁止拷贝，避免哈希迭代器仍指向旧链表。

经典考点与练习

练习：LeetCode 146 LRU 缓存、460 LFU 缓存。

14.02

扫描线：并发数量与端点规则

知识与适用场景

把区间开始转成 +1 事件，结束转成 -1 事件，排序后维护活跃数量。重点不在求和，而在同一时间发生的事件谁先处理。

推导 / 不变量

会议采用 [start,end) 时，某会议结束的瞬间可以开始下一场，故相同时间先处理 -1，再处理 +1。闭区间且端点重叠时需要反过来。

手推一个例子

[0,10)、[5,10)、[10,15) 最大并发为 2；时间 10 应先释放两个房间，再安排新会议，而不是算成 3。

C++17
下载 .cpp
int minMeetingRooms(const vector<pair<int,int>>& meetings){
    vector<pair<int,int>> events;
    for(auto [l,r]:meetings){
        if(l>r) throw invalid_argument("invalid interval");
        if(l==r) continue;
        events.push_back({l,1});
        events.push_back({r,-1});
    }
    sort(events.begin(),events.end());
    int active=0,best=0;
    for(auto [time,delta]:events){
        active+=delta;
        best=max(best,active);
    }
    return best;
}
复杂度
时间 O(n log n)，事件空间 O(n)。
易错点与边界
区间合并求覆盖范围、扫描线求并发数、贪心调度求不冲突数量，是三个不同目标。零长度区间应根据语义单独处理。

经典考点与练习

练习：LeetCode 253 会议室 II、1094 拼车、56 合并区间。

14.03

随机集合：交换末尾删除

知识与适用场景

数组支持随机下标访问，哈希支持按值定位。删除中间元素时用末尾元素填洞，再修正末尾元素的下标映射，即可避免线性搬移。

推导 / 不变量

维护 index[value] 等于该值在数组中的实际下标。删除 x 时先把最后值写到 x 的位置并更新映射，再 pop_back 和擦除 x。

手推一个例子

数组 [10,20,30] 删除 20：把 30 移到下标 1，数组变为 [10,30]，映射 index[30] 从 2 改为 1。

C++17
下载 .cpp
class RandomizedSet {
    vector<int> data;
    unordered_map<int,int> index;
    mt19937 rng{random_device{}()};
public:
    bool insert(int x){
        if(index.count(x)) return false;
        index[x]=(int)data.size(); data.push_back(x); return true;
    }
    bool remove(int x){
        auto it=index.find(x);
        if(it==index.end()) return false;
        int i=it->second,last=data.back();
        data[i]=last; index[last]=i;
        data.pop_back(); index.erase(x); return true;
    }
    int getRandom(){
        if(data.empty()) throw out_of_range("empty set");
        uniform_int_distribution<int> pick(0,(int)data.size()-1);
        return data[pick(rng)];
    }
};
复杂度
插入、删除哈希平均 O(1)，数组追加为均摊 O(1)，随机读取 O(1)，空间 O(n)。
易错点与边界
直接 rand()%n 可能有取模偏差。删除末尾元素时也必须正确工作，不能先删映射再依赖它。

经典考点与练习

练习：LeetCode 380 O(1) 时间插入、删除和获取随机元素、381 允许重复版本。

14.04

欧几里得、筛法与数值边界

知识与适用场景

数学题同样先找不变量：gcd(a,b)=gcd(b,a%b)，因为两对数拥有相同公因数。最小公倍数可由 a/gcd(a,b)*b 计算，先除后乘降低中间溢出风险。

推导 / 不变量

埃氏筛从每个未标记质数 p 的 p² 开始标记倍数，因为更小倍数已被更小质因子标记。循环条件使用 p<=n/p 避免 p*p 在条件中溢出。

手推一个例子

筛到 10：p=2 标记 4、6、8、10；p=3 从 9 开始标记，剩下 2、3、5、7 为质数。

C++17
下载 .cpp
vector<int> primesUpTo(int n){
    if(n<2) return {};
    vector<bool> prime(n+1,true);
    prime[0]=prime[1]=false;
    for(int p=2;p<=n/p;++p)
        if(prime[p])
            for(long long x=1LL*p*p;x<=n;x+=p) prime[(size_t)x]=false;
    vector<int> ans;
    for(int x=2;x<=n;++x) if(prime[x]) ans.push_back(x);
    return ans;
}
long long gcdNonnegative(long long a,long long b){
    // 前提：a,b >= 0；约定 gcd(0,0)=0。
    while(b){ long long r=a%b; a=b; b=r; }
    return a;
}
复杂度
筛法时间 O(n log log n)、空间 O(n)；gcd 时间 O(log(min(a,b)+1))、空间 O(1)。
易错点与边界
模运算不能把除法直接改成除后取模，逆元需要满足存在条件。负数取模在 C++ 中可能为负，常用 (x%mod+mod)%mod 归一化。

经典考点与练习

练习：LeetCode 204 计数质数、50 Pow(x,n)、189 轮转数组中的 gcd 循环置换。
