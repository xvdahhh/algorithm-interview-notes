## 排序必须掌握的比较

| 算法 | 平均时间 | 最坏时间 | 额外空间 | 稳定性 |
| --- | --- | --- | --- | --- |
| 快速排序 | 随机基准期望 `O(n log n)` | `O(n²)` | 普通双侧递归期望 `O(log n)`、最坏 `O(n)` 栈 | 不稳定 |
| 归并排序 | `O(n log n)` | `O(n log n)` | `O(n)` | 稳定 |
| 堆排序 | `O(n log n)` | `O(n log n)` | `O(1)` | 不稳定 |
| 插入排序 | `O(n²)` | `O(n²)` | `O(1)` | 稳定 |
| 计数排序 | `O(n+k)` | `O(n+k)` | 计数 `O(k)`；稳定记录版另需 `O(n)` 输出 | 可稳定 |

- 快排重点：分区过程、随机选基准、递归边界。
- 归并重点：合并两个有序区间，可顺带统计逆序对。
- 堆排重点：建堆可为 `O(n)`，反复取堆顶为 `O(n log n)`。
- 面试中优先使用语言标准排序，但被问原理时要能手写快排或归并。

## 二分查找的本质

边界二分不是只用于“找某个数”，而是用于在单调答案空间中寻找边界。先定义谓词 `check(x)`，确保它随 `x` 单调变化。旋转数组、任意峰值等结构性二分不一定有全局单调谓词，应另证每轮保留的区域仍含解。

### 左闭右开：找第一个满足条件的位置

```text
left = 0, right = n
while left < right:
    mid = left + (right-left)/2
    if check(mid):
        right = mid
    else:
        left = mid + 1
return left
```

此模板尚未判断的元素范围始终为 `[left,right)`，已知 `[0,left)` 为假、`[right,n)` 为真；分界位置本身可能等于 `right`，最终返回值也可能等于 `n`，读取数组前必须检查。

### 答案二分

适用于“最小化最大值”或“最大化最小值”，例如运输能力、切割长度、分配距离。步骤是：

1. 明确答案上下界。
2. 编写 `check(answer)` 判断该答案是否可行。
3. 证明可行性随答案单调。
4. 二分第一个可行或最后一个可行答案。

## 高频题型

- 查找目标的第一个/最后一个位置。
- 旋转排序数组：判断哪一半有序，再决定目标在哪边。
- 寻找峰值：比较中点与相邻元素，保留必有峰值的一侧。
- 两有序数组中位数：在较短数组上二分分割位置。
- 快速选择：借助快排分区求第 K 小，平均 `O(n)`。

## 易错点与自测

- [ ] 写代码前明确搜索区间含义，不能混用闭区间和半开区间。
- [ ] 用 `left + (right-left)/2` 避免加法溢出。
- [ ] 循环每轮都严格缩小区间，避免死循环。
- [ ] 返回后检查是否越界、是否真的满足目标条件。
- [ ] 能手写归并排序、快速排序和左边界二分。
