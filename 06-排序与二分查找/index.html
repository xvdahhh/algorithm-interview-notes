06.01

归并排序、稳定性与逆序对

知识与适用场景

归并先递归排序两半，再用双指针合并。相等时优先取左半元素可以保持稳定性，即原本相等元素的相对顺序不变。稳定性对多字段排序有意义。

推导 / 不变量

每层合并总共处理 n 个元素，递归约 log n 层。逆序对统计时，如果右值小于左值，则该右值与左半剩余所有元素都构成逆序对。

手推一个例子

[3,1,2] 分为 [3] 与 [1,2]。合并时先取 1，产生一对 (3,1)；再取 2，产生 (3,2)。

C++17
下载 .cpp
void mergeSortRange(vector<int>& a, vector<int>& tmp, int l, int r) {
    if (r - l <= 1) return;
    int m = l + (r-l)/2;
    mergeSortRange(a, tmp, l, m);
    mergeSortRange(a, tmp, m, r);
    int i=l, j=m, k=l;
    while (i<m && j<r)
        tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++];
    while (i<m) tmp[k++] = a[i++];
    while (j<r) tmp[k++] = a[j++];
    for (int p=l; p<r; ++p) a[p]=tmp[p];
}
void mergeSort(vector<int>& a) {
    vector<int> tmp(a.size());
    mergeSortRange(a, tmp, 0, (int)a.size());
}
复杂度
时间 O(n log n)，辅助数组 O(n)，调用栈 O(log n)，总额外空间 O(n)。
易错点与边界
sort 不保证稳定，stable_sort 保证稳定。比较器不能写 <=，必须满足严格弱序。

经典考点与练习

练习：LeetCode 912 排序数组、LCR 170 交易逆序对的总数。

06.02

快速排序与三路分区

知识与适用场景

快排通过分区把较小值放左边、较大值放右边，再递归处理。平均 O(n log n)，选择极差基准时最坏 O(n²)。大量重复值时，三路分区能一次跳过整个相等区域。

推导 / 不变量

保持 [l,lt) < pivot，[lt,i) = pivot，[i,gt] 未处理，(gt,r] > pivot。遇到大值时与 gt 交换，但新换来的值尚未处理，因此 i 不前进。

手推一个例子

[2,1,2,3,2] 以 2 为基准，最终得到 [1]、[2,2,2]、[3]，只需要继续处理两侧。

C++17
下载 .cpp
void quickSort(vector<int>& a, int l, int r) {
    if (l >= r) return;
    int pivot = a[l + (r-l)/2];
    int lt=l, i=l, gt=r;
    while (i <= gt) {
        if (a[i] < pivot) swap(a[lt++], a[i++]);
        else if (a[i] > pivot) swap(a[i], a[gt--]);
        else ++i;
    }
    quickSort(a, l, lt-1);
    quickSort(a, gt+1, r);
}
void sortArray(vector<int>& a) {
    if (!a.empty()) quickSort(a, 0, (int)a.size()-1);
}
复杂度
常见输入平均 O(n log n)，本实现中点基准没有随机化，最坏 O(n²)；栈平均 O(log n)、最坏 O(n)。
易错点与边界
快排不是稳定排序。需要可靠最坏性能时通常使用标准库 sort，或自己实现内省排序；随机化只能降低遇到极端分区的概率。

经典考点与练习

练习：LeetCode 75 颜色分类、215 数组中的第 K 个最大元素。

面试官可能继续问什么？

如何用分区实现第 K 小？为什么只递归一边时平均可达 O(n)？

06.03

左右边界与标准库二分

知识与适用场景

lower_bound 返回第一个 >=x 的位置，upper_bound 返回第一个 >x 的位置。两者之差就是 x 的出现次数；找不到时可能返回 end。

推导 / 不变量

下界搜索把 >=x 作为右半区条件，上界搜索把 >x 作为右半区条件。重复元素不是特例，而是边界定义的一部分。

手推一个例子

[1,2,2,2,4] 中 x=2，下界 1，上界 4，因此范围 [1,3]，次数 3。

C++17
下载 .cpp
pair<int,int> searchRange(const vector<int>& a, int x) {
    auto first = lower_bound(a.begin(), a.end(), x);
    if (first == a.end() || *first != x) return {-1,-1};
    auto after = upper_bound(first, a.end(), x);
    return {(int)(first-a.begin()), (int)(after-a.begin())-1};
}
复杂度
随机访问数组上时间 O(log n)，空间 O(1)。在链表迭代器上，比较次数虽为对数，移动迭代器却可能为线性。
易错点与边界
有序容器 set/map 优先使用成员 lower_bound，不能把通用算法在其迭代器上的成本误认为 O(log n)。旋转数组要先判断哪半有序。

经典考点与练习

练习：LeetCode 34 查找首尾位置、33 搜索旋转排序数组、153 寻找旋转排序数组中的最小值。

面试官可能继续问什么？

找最后一个 <=x 如何用 upper_bound 表达？空数组会返回什么？

06.04

答案二分：最小运输能力

知识与适用场景

答案二分要求可行性单调。运输容量越大，需要的天数越少，因此存在“不可行→可行”的分界。对每个候选容量，按顺序尽量装满当前天即可检查可行性。

推导 / 不变量

下界为最大单件重量，上界为总重量。容量固定后，贪心每天尽量多装不会让未来变差；check 返回能否在 D 天内完成。

手推一个例子

重量 [1,2,3,1,1]，D=4，容量 2 装不下重量 3；容量 3 可分为 [1,2]、[3]、[1,1]，最小答案是 3。

C++17
下载 .cpp
long long shipCapacity(const vector<int>& w, int days) {
    if (w.empty()) return 0;
    if (days <= 0) throw invalid_argument("days must be positive");
    long long lo = *max_element(w.begin(),w.end());
    long long hi = accumulate(w.begin(),w.end(),0LL);
    auto ok = [&](long long cap) {
        int used=1;
        long long load=0;
        for (int x:w) {
            if (load+x>cap) { ++used; load=0; }
            load+=x;
        }
        return used<=days;
    };
    while (lo<hi) {
        long long mid=lo+(hi-lo)/2;
        if (ok(mid)) hi=mid;
        else lo=mid+1;
    }
    return lo;
}
复杂度
时间 O(n log(S-M+1))，S 为总重、M 为最大重量；空间 O(1)。重量需为正。
易错点与边界
不要看到最小化最大值就直接二分；先证明 check 单调，并保证初始上界可行。

经典考点与练习

练习：LeetCode 1011 在 D 天内送达包裹的能力、875 爱吃香蕉的珂珂、410 分割数组的最大值。
