04.01

括号匹配与栈中的待解决问题

知识与适用场景

栈保存尚未匹配的左括号。右括号只能与最近的未匹配左括号配对，天然符合后进先出。表达式求值、函数调用和嵌套结构解析都沿用同样的层级思想。

推导 / 不变量

扫描到右括号时先检查栈是否为空，再检查类型。扫描完成后栈必须为空，否则仍有未闭合括号。下面约定输入只允许六种括号字符。

手推一个例子

输入 ([)]：栈依次为 (、([；读到 ) 时栈顶是 [，立即失败，不能跨过它与更早的 ( 配对。

C++17
下载 .cpp
bool validBrackets(const string& s) {
    vector<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') st.push_back(c);
        else {
            char need = c == ')' ? '(' : c == ']' ? '[' : c == '}' ? '{' : 0;
            if (!need || st.empty() || st.back() != need) return false;
            st.pop_back();
        }
    }
    return st.empty();
}
复杂度
时间 O(n)，最坏额外空间 O(n)。
易错点与边界
最小栈要保存每一层对应的最小值；重复最小值不能只记录一次。表达式中的一元负号与二元减法需要区分。

经典考点与练习

练习：LeetCode 20 有效的括号、155 最小栈、150 逆波兰表达式求值。

04.02

单调栈：下一个更大元素

知识与适用场景

对每个位置寻找右侧第一个更大值，暴力会重复扫描。单调栈保存还没有找到答案的下标，新值出现时可以一次解决多个较小值。

推导 / 不变量

保持栈中温度非递增。若当前温度大于栈顶温度，则当前下标就是栈顶的第一个更高温度：之前扫描过的位置都没能弹出它。

手推一个例子

[73,71,72,75]：72 解决 71；75 依次解决 72 与 73。对应等待天数 [3,1,1,0]。

C++17
下载 .cpp
vector<int> dailyTemperatures(const vector<int>& t) {
    vector<int> ans(t.size(), 0), st;
    for (int i = 0; i < (int)t.size(); ++i) {
        while (!st.empty() && t[i] > t[st.back()]) {
            int j = st.back();
            st.pop_back();
            ans[j] = i - j;
        }
        st.push_back(i);
    }
    return ans;
}
复杂度
时间 O(n)，空间 O(n)；每个下标入栈出栈至多一次。
易错点与边界
严格更大使用 >，大于等于使用 >=。柱状图求面积时，弹出元素后新的栈顶代表左侧边界，宽度不能用两端下标直接相减。

经典考点与练习

练习：LeetCode 739 每日温度、496 下一个更大元素 I、84 柱状图中最大的矩形。

面试官可能继续问什么？

为什么相同温度不弹出？如何寻找左侧第一个更小元素？

04.03

单调队列：窗口最大值

知识与适用场景

堆能解决窗口最值，但需要处理过期元素。单调队列利用固定的时间顺序，把将来永远不可能成为最大值的候选提前删除。

推导 / 不变量

队列保存下标，对应值递减。新值 x 到来时，队尾所有 <=x 的旧值都可淘汰：x 更大且更晚过期。查询前移除下标 <= i-k 的元素。

手推一个例子

[1,3,-1,-3,5]，k=3：3 淘汰 1；5 到来时移除过期的 3，并从尾部淘汰 -3、-1，窗口最大值依次为 3、3、5。

C++17
下载 .cpp
vector<int> maxSlidingWindow(const vector<int>& a, int k) {
    if (k <= 0 || k > (int)a.size()) return {};
    deque<int> q;
    vector<int> ans;
    for (int i = 0; i < (int)a.size(); ++i) {
        while (!q.empty() && q.front() <= i-k) q.pop_front();
        while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();
        q.push_back(i);
        if (i >= k-1) ans.push_back(a[q.front()]);
    }
    return ans;
}
复杂度
时间 O(n)，辅助空间 O(k)，输出空间 O(n-k+1)。
易错点与边界
队列中存值会失去精确过期信息；若使用值，需要另行处理重复值及其数量。

经典考点与练习

练习：LeetCode 239 滑动窗口最大值、862 和至少为 K 的最短子数组。

04.04

两个栈实现队列与均摊分析

知识与适用场景

输入栈接收新元素，输出栈负责弹出最旧元素。当输出栈为空时，把输入栈全部倒入，顺序就被反转。输出栈非空时不能把新元素混入。

推导 / 不变量

每个元素最多压入输入栈一次、转入输出栈一次、弹出一次。虽然某次 pop 可能耗时 O(n)，一串 n 次操作的总成本是 O(n)。

手推一个例子

push(1)、push(2)、pop()：倒入输出栈后栈顶为 1；再 push(3) 不影响输出栈中的 2，下一次 pop 仍返回 2。

C++17
下载 .cpp
class TwoStackQueue {
    stack<int> in, out;
    void transfer() {
        if (out.empty()) {
            while (!in.empty()) { out.push(in.top()); in.pop(); }
        }
    }
public:
    void push(int x) { in.push(x); }
    bool empty() const { return in.empty() && out.empty(); }
    int pop() {
        transfer();
        if (out.empty()) throw out_of_range("empty queue");
        int x = out.top(); out.pop(); return x;
    }
    int front() {
        transfer();
        if (out.empty()) throw out_of_range("empty queue");
        return out.top();
    }
};
复杂度
push 最坏 O(1)；pop/front 均摊 O(1)、单次最坏 O(n)；空间 O(n)。
易错点与边界
空队列行为要与接口约定一致。使用队列做 BFS 时入队就标记，防止重复入队。

经典考点与练习

练习：LeetCode 232 用栈实现队列、225 用队列实现栈。
