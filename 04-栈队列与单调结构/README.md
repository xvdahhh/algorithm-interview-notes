# 第 04 章：栈、队列与单调结构

## 栈与队列

- 栈是后进先出，适合括号匹配、递归模拟、表达式求值、撤销操作。
- 队列是先进先出，适合 BFS、任务调度、按层处理。
- 双端队列可在两端 `O(1)` 插入删除，是单调队列的基础。

## 栈的高频应用

- 有效括号：遇左括号入栈，遇右括号检查栈顶是否匹配。
- 最小栈：额外维护同步最小值栈，或为每个元素保存当前最小值。
- 表达式求值：掌握中缀转后缀，或用数字栈与运算符栈处理优先级。
- 用栈模拟递归：显式保存节点、阶段和局部状态。

## 单调栈

用于寻找“左/右侧第一个更大或更小元素”，典型题有每日温度、下一个更大元素、柱状图最大矩形、接雨水。

```text
stack 保存下标，并维持对应值单调
for i in [0..n-1]:
    while stack 非空 且 a[i] 破坏单调性:
        j = stack.pop()
        用 i 与新的栈顶确定 j 的答案或作用区间
    stack.push(i)
```

关键问题：栈中存值还是下标、单调递增还是递减、相等元素弹不弹。答案依赖距离或边界时通常存下标。

## 单调队列

用于滑动窗口最大值/最小值。队列保存候选下标，并满足：

1. 下标从队首到队尾递增。
2. 对应值按需要单调。
3. 新元素进入前，从队尾移除不可能再成为最优的元素。
4. 每次查询前，从队首移除已离开窗口的下标。

每个元素最多入队出队一次，总复杂度 `O(n)`。

## 高频设计题

- 两个栈实现队列：输入栈只负责接收，输出栈为空时一次性倒入。
- 两个队列实现栈：每次弹出前搬运到只剩最后一个，或让入栈操作保持目标顺序。
- 浏览器前进后退、编辑器撤销重做：两个栈管理历史状态。

## 易错点与自测

- [ ] 能解释单调栈中一个元素为什么只处理常数次。
- [ ] 明确相等元素的处理策略，避免边界重复计算。
- [ ] 单调队列先移除过期元素还是先取答案，顺序与窗口定义一致。
- [ ] 表达式题考虑一元负号、空格、括号和除法取整规则。
- [ ] 能独立写出滑动窗口最大值。
