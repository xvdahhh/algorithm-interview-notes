08.01

堆的数组表示与向下调整

知识与适用场景

0 下标完全二叉树的孩子为 2i+1、2i+2。大顶堆每个父节点不小于孩子。交换根和末尾后，只有根附近可能破坏性质，可以沿一条路径向下修复。

推导 / 不变量

从最后一个非叶节点逆序执行下沉即可建堆。底层节点多但下沉距离短，按高度求和得到 O(n)，并非 O(n log n)。

手推一个例子

[3,1,5,2] 从下标 1 开始，1 与 2 交换；再处理根 3，与 5 交换，得到 [5,2,3,1]。

C++17
下载 .cpp
void siftDown(vector<int>& a, int i, int n) {
    while (2*i+1 < n) {
        int child=2*i+1;
        if (child+1<n && a[child+1]>a[child]) ++child;
        if (a[i]>=a[child]) break;
        swap(a[i],a[child]);
        i=child;
    }
}
void buildMaxHeap(vector<int>& a) {
    int n=(int)a.size();
    for (int i=n/2-1; i>=0; --i) siftDown(a,i,n);
}
复杂度
建堆 O(n) 时间、O(1) 额外空间；单次上浮/下沉 O(log n)。
易错点与边界
priority_queue<int> 默认大顶堆，小顶堆用 greater<int>。堆不是整体有序数组，不能对内部存储做二分。

经典考点与练习

练习：手写堆排序；LeetCode 1046 最后一块石头的重量。

08.02

固定大小堆与 Top K

知识与适用场景

求最大的 K 个时维护小顶堆：堆顶是目前入选者中最弱的，新的大值可以替换它。保留的集合始终是已扫描前缀的 K 个最大值。

推导 / 不变量

加入每个元素后若大小超过 K，就删除最小值。最终堆顶是第 K 大。K=1 时退化为维护最大值。

手推一个例子

[3,2,1,5,6,4]，K=2：堆最终保留 5、6，堆顶 5 即第 2 大。

C++17
下载 .cpp
int kthLargest(const vector<int>& a, int k) {
    if (k<=0 || k>(int)a.size()) throw invalid_argument("invalid k");
    priority_queue<int,vector<int>,greater<int>> heap;
    for (int x:a) {
        heap.push(x);
        if ((int)heap.size()>k) heap.pop();
    }
    return heap.top();
}
复杂度
时间 O(n log(k+1))，额外空间 O(k)。
易错点与边界
第 K 大通常按元素计数而不是去重后的值，重复值要保留。静态数组且可修改时，nth_element 平均线性更合适。

经典考点与练习

练习：LeetCode 215 第 K 个最大元素、703 数据流中的第 K 大元素、347 前 K 个高频元素。

面试官可能继续问什么？

若 k 接近 n，可否改为维护 n-k+1 个最小值？

08.03

多路归并：只保存每一路的前沿

知识与适用场景

每个有序序列未处理部分的最小值一定是其当前头部。因此全局最小值一定在各路头部之中，堆只需保存这些候选。

推导 / 不变量

弹出三元组 (value,row,index)，输出 value，再把同一路下一个元素入堆。每一路最多有一个候选存在于堆中。

手推一个例子

[1,4]、[2,5]、[0,3]：堆初始 0、1、2；弹出 0 后补入 3；持续得到 0、1、2、3、4、5。

C++17
下载 .cpp
vector<int> mergeSorted(const vector<vector<int>>& a) {
    using Item=tuple<int,int,int>;
    priority_queue<Item,vector<Item>,greater<Item>> pq;
    for (int r=0;r<(int)a.size();++r)
        if (!a[r].empty()) pq.emplace(a[r][0],r,0);
    vector<int> ans;
    while (!pq.empty()) {
        auto [value,r,i]=pq.top(); pq.pop();
        ans.push_back(value);
        if (i+1<(int)a[r].size()) pq.emplace(a[r][i+1],r,i+1);
    }
    return ans;
}
复杂度
总元素数 N，路数 K：时间 O(N log(K+1)+K)，额外堆空间 O(K)，输出 O(N)。
易错点与边界
保存来源索引才能推进正确的序列。K 个链表合并时，弹出节点后要保留 next，避免错误修改连接。

经典考点与练习

练习：LeetCode 23 合并 K 个升序链表、373 查找和最小的 K 对数字。

面试官可能继续问什么？

08.04

双堆维护中位数

知识与适用场景

大顶堆 lo 保存较小一半，小顶堆 hi 保存较大一半。维护 lo 的元素数等于 hi，或比 hi 多 1；并保证所有 lo 元素 <= 所有 hi 元素。

推导 / 不变量

先按 lo.top 分流，再通过移动堆顶平衡大小。奇数个元素的中位数是 lo.top，偶数个是两个堆顶平均值。

手推一个例子

插入 1、5、2：最终 lo={1,2}，hi={5}，中位数 2；再插入 4，两个堆顶为 2 和 4，中位数 3。

C++17
下载 .cpp
class MedianFinder {
    priority_queue<int> lo;
    priority_queue<int,vector<int>,greater<int>> hi;
public:
    void addNum(int x) {
        if (lo.empty() || x<=lo.top()) lo.push(x);
        else hi.push(x);
        if (lo.size()>hi.size()+1) { hi.push(lo.top()); lo.pop(); }
        if (hi.size()>lo.size()) { lo.push(hi.top()); hi.pop(); }
    }
    double findMedian() const {
        if (lo.empty()) throw out_of_range("no data");
        if (lo.size()!=hi.size()) return lo.top();
        return ((long long)lo.top()+hi.top())/2.0;
    }
};
复杂度
插入 O(log n)，查询 O(1)，存储 O(n)。
易错点与边界
两个 int 先相加可能溢出，先转 long long。若还支持删除任意旧值，需要额外的延迟删除或有序多重集合。

经典考点与练习

练习：LeetCode 295 数据流的中位数、480 滑动窗口中位数。
