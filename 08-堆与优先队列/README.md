## 核心性质

- 堆是一棵完全二叉树，通常用数组存储。
- 小顶堆保证父节点不大于孩子，堆顶是最小值；大顶堆相反。
- 取堆顶 `O(1)`，插入与删除堆顶 `O(log n)`，从无序数组建堆可为 `O(n)`。
- 堆只保证局部有序，不支持像有序数组那样直接二分查找。

## 数组下标关系

采用 0 下标时：

- 父节点：`(i-1)/2`，仅在 `i>0` 时计算。
- 左孩子：`2*i+1`。
- 右孩子：`2*i+2`。

插入时向上调整，删除堆顶后把末尾元素移到顶部并向下调整。

## 高频模式

### Top K

- 求最大的 K 个：维护大小为 K 的小顶堆，堆顶是当前答案中最小者。
- 求最小的 K 个：维护大小为 K 的大顶堆。
- 时间 `O(n log(k+1))`，空间 `O(k)`；若允许修改数组，也可用快速选择取得平均 `O(n)`。按元素次数计秩还是按不同值计秩，应先明确。

### 多路归并

把每一路当前最小元素放入小顶堆；弹出后再加入同一路的下一个元素。用于合并 K 个有序链表、多个有序数组和外部排序。

### 数据流中位数

- 大顶堆保存较小的一半，小顶堆保存较大的一半。
- 保持两堆大小差不超过 1，且大顶堆堆顶不大于小顶堆堆顶。
- 插入 `O(log n)`，查询中位数 `O(1)`。

### 调度与最短候选

优先队列常用于 Dijkstra、会议室分配、任务调度。堆元素通常同时保存“优先级 + 标识”，比较器要与题意一致。

## 易错点与自测

- [ ] 确认标准库优先队列默认是大顶堆还是小顶堆。
- [ ] 自定义比较器满足严格弱序，避免相等元素比较异常。
- [ ] 堆中可能存在过期状态，弹出时要验证是否仍有效。
- [ ] 延迟删除时区分有效元素数与物理堆大小，不能无条件声称空间始终为窗口大小。
- [ ] 能解释 Top K 为什么使用“相反方向”的堆。
- [ ] 能手写向上调整、向下调整和数据流中位数。
