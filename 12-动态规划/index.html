12.01

线性 DP：以当前位置结尾

知识与适用场景

最大子数组和的状态是“必须以 i 结尾的非空子数组最大和”，不是前 i 个元素的全局最优。状态只需在继续前一段和从当前元素重新开始之间选择。

1.1 必须以 i 结尾，与前 i 项全局最优是两个问题

end[i] 表示必须以 a[i] 结尾的非空连续子数组最大和。它要么只取 a[i]，要么接在一个以 i−1 结尾的最优段后面。只有这两类情况，因而 end[i]=max(a[i],end[i−1]+a[i])。best[i] 才是前缀全局最优，等于 max(best[i−1],end[i])。

不能用 best[i−1]+a[i] 代替连续延伸：a=[5,−100,4] 时，前缀最优仍是 5，但 5 与 4 不相邻，直接相加虚构出了不存在的和 9。要求非空时，全负数组必须返回其中最大的负数，不能用 0 作为答案初值。

1.3 打家劫舍：空方案是合法初态

令 dp[i] 表示只考虑前 i 间房、相邻不能同时选的最大收益，允许一个都不选。最后一间不选则为 dp[i−1]，选则为 dp[i−2]+value[i−1]。dp[0]=0，dp[1]=max(0,value[0])；若示例允许负值，也应保留空方案。

环形房屋的首尾相邻。任何合法方案至少不选首或不选尾，所以分别求 [0,n−1) 与 [1,n) 两段线性最优后取 max。两类可以重叠，不影响求最大值；若是计数，直接相加就可能重复计数。n=1 必须单独处理。

推导 / 不变量

endHere=max(a[i],endHere+a[i])；全局答案取所有 endHere 的最大值。若前一段和为负，接上它只会让当前更差，应重新开始。

long long maxSubArray(const vector<int>& a) {
    if(a.empty()) throw invalid_argument("nonempty array required");
    long long endHere=a[0],best=a[0];
    for(int i=1;i<(int)a.size();++i){
        endHere=max((long long)a[i],endHere+a[i]);
        best=max(best,endHere);
    }
    return best;
}
复杂度
时间 O(n)，滚动状态空间 O(1)。
易错点与边界
若允许空子数组则全负数组答案可为 0；本题要求非空，必须用首元素初始化。打家劫舍中则可以一个都不选。

1.4 最大子数组和与下标：明确平局规则

返回闭区间 [left,right]。同最大和时选左端点更小的，再选右端点更小的。状态保存当前段的起点，不只保存全局答案起点。时间 O(n)、额外空间 O(1)，不会修改输入。

struct BestSubarray { long long sum; int left, right; };
BestSubarray maxSubarrayRange(const vector<int>& a) {
    if (a.empty()) throw invalid_argument("nonempty array required");
    long long ending = a[0];
    int start = 0;
    BestSubarray best{a[0],0,0};
    for (int i = 1; i < (int)a.size(); ++i) {
        if (ending < 0) { ending = a[i]; start = i; }
        else ending += a[i]; // 等于 0 时延续，保留较早左端点
        if (ending > best.sum ||
            (ending == best.sum && (start < best.left ||
             (start == best.left && i < best.right)))) {
            best = {ending,start,i};
        }
    }
    return best;
}

1.5 环形打家劫舍：拆成两个允许空选的线性问题

允许负房值但可不选；空数组和全负数组返回 0。两个线性扫描总时间 O(n)、额外空间 O(1)。没有复制子数组，也没有错误地同时选首尾。

long long robLinearRange(const vector<int>& value, int left, int right) {
    // 半开区间 [left,right)，调用者保证下标合法
    long long prev2 = 0, prev1 = 0;
    for (int i = left; i < right; ++i) {
        long long current = max(prev1,prev2+value[i]);
        prev2 = prev1; prev1 = current;
    }
    return prev1;
}
long long robCircle(const vector<int>& value) {
    int n = (int)value.size();
    if (!n) return 0;
    if (n == 1) return max(0LL,(long long)value[0]);
    return max(robLinearRange(value,0,n-1),robLinearRange(value,1,n));
}

1.6 记忆化如何从同一个状态定义产生

线性劫舍也能写成 f(i)=max(f(i+1),value[i]+f(i+2))，边界 i≥n 返回 0。缓存键为 i，因为 value 固定且剩余问题只由起点决定。用 seen 数组区分未计算与已经算出 0，不能把 memo[i]==0 当成未算标记，否则全零输入会反复计算。

这个递归版本仍可能有 O(n) 深度。滚动递推只依赖前两项，用 O(1) 辅助空间且没有深调用栈；记忆化的优势是自然表达状态并跳过不用访问的部分，而不是天然更省空间。

面试追问：关键点完整解答

为什么不能只维护全局 best 来转移最大子数组？

best 可能在很早以前结束，不满足紧邻当前元素的连接条件。需要单独维护以当前位置结尾的 endHere，连接合法后再更新全局 best。状态中的“结尾”不是修饰语，而是决定转移是否合法的约束。

最大子数组全负时为什么不返回 0？

题目要求非空。[-5,−2] 的答案是 −2，空数组不是候选。若题意明确允许空选，才可让 0 参与竞争；不要把打家劫舍允许不选的初始化搬到非空子数组题。

返回左右下标时，何时更新当前起点？

当旧 ending<0 时，从当前元素重新开始，起点改为 i。旧 ending==0 时延续与重启的和相同；本实现为保留更早左端点选择延续。只有当前候选按约定优于全局答案时，才同步更新答案的两个端点。

环形劫舍为什么不直接算线性答案，再删掉较小的首尾？

线性方案一旦选了首尾，删掉其中一个后，它的邻居可能应该重新入选，仅删一个不能重新优化。正确做法是按至少不选首或不选尾划分所有合法方案，两种限制下分别完整求最优。

缓存值为 0 为什么不能代表未计算？

0 常是合法答案，例如空问题、全负允许不选或全部为零。把它当未计算会破坏每个状态只算一次的复杂度保证。可以另设 seen，或使用不会与合法结果冲突的显式标记。

滚动变量更新为何要先保存 current？

新 dp[i] 依赖旧 dp[i−1] 与旧 dp[i−2]。如果先覆盖 prev2 或 prev1，再计算另一个变量，就可能读到本轮值。先用旧值求 current，再整体移动窗口，才能保持状态含义。

12.02

0/1 背包：容量倒序的原因

知识与适用场景

dp[c] 表示处理到当前物品时，在容量不超过 c 的限制下能获得的最大价值。每个物品最多用一次；二维转移应从上一行取值。

2.1 先写二维状态，才看得见一维覆盖了什么

令 f[i][c] 表示只用前 i 件物品、总重量不超过 c 的最大价值。第 i 件不选，来源是 f[i−1][c]；选，来源是 f[i−1][c−w]+v。两项都来自上一行，这正是每件最多用一次的约束。

压缩为 dp[c] 后，倒序更新 c，使更小的 c−w 尚未被本件物品改写，读到的仍是上一行。对于完全背包，选本件后还能继续选它，来源反而应是当前行 f[i][c−w]，因此正序更新。方向不是口诀，而是数据依赖。

2.4 分割等和子集与目标和的代数入口

非负数组总和 S 若为奇数，不可能分成两个相同整数和。否则问题等价于选一部分下标使和为 S/2，使用布尔 0/1 背包倒序更新。相同数值的不同下标仍是不同物品，不应随手去重；零值不影响可达性。

目标和中，给非负数分配正负号，令被赋正号部分总和为 P，则 P−(S−P)=target，得到 P=(S+target)/2。先检查 |target|≤S 与奇偶性，再转成计数 0/1 背包。零值的正负号是两个不同选择，会使每个可达方案数翻倍，不能为了方便删掉零。

推导 / 不变量

压缩为一维后按容量倒序，使 dp[c-weight] 尚未使用本轮物品。如果正序，会把本轮更新值再次拿来转移，错误地重复选择同一件物品。

只有一件重量 2、价值 3 的物品，容量 4。正序会先把 dp[2] 更新为 3，再把 dp[4] 更新为 6；倒序则 dp[4] 只能得到 3。

long long knapsack01(const vector<int>& weight,
                     const vector<int>& value,int capacity) {
    if(capacity<0 || weight.size()!=value.size())
        throw invalid_argument("invalid input");
    vector<long long> dp(capacity+1,0);
    for(int i=0;i<(int)weight.size();++i){
        if(weight[i]<=0) throw invalid_argument("positive weights required");
        for(int c=capacity;c>=weight[i];--c)
            dp[c]=max(dp[c],dp[c-weight[i]]+value[i]);
    }
    return dp[capacity];
}

2.5 恰好装满的 0/1 背包：显式表达不可达

正重量，价值可为负；容量上限 200000 用于控制教学示例资源。恰好装满可能必须接受负收益，例如重量 2、价值 −3、容量 2 的答案是 −3，不是 0。optional 区分无解与任意有限值。由于选中件数至多为容量，int 价值累加在 long long 内安全。时间 O(nC)，空间 O(C)。

optional<long long> knapsackExact(const vector<int>& weight,
                                  const vector<int>& value, int capacity) {
    if (capacity < 0 || capacity > 200000 || weight.size() != value.size())
        throw invalid_argument("capacity/length");
    vector<optional<long long>> dp(capacity+1);
    dp[0] = 0;
    for (int i = 0; i < (int)weight.size(); ++i) {
        if (weight[i] <= 0) throw invalid_argument("positive weight");
        for (int c = capacity; c >= weight[i]; --c) {
            if (!dp[c-weight[i]]) continue;
            long long candidate = *dp[c-weight[i]]+value[i];
            if (!dp[c] || candidate > *dp[c]) dp[c] = candidate;
        }
    }
    return dp[capacity];
}

2.6 布尔背包：分割等和子集

采用允许空子集的定义，因此空数组和全零数组返回 true。题目若要求两组都非空，需按题意增加条件或状态。零重量布尔物品只会保持已有可达值，不会造成无限循环；本循环 c 为有符号 int。时间 O(n·S)，空间 O(S)，这里 S 表示目标和而非输入位数。

bool equalPartition(const vector<int>& a) {
    long long sum = 0;
    for (int x : a) {
        if (x < 0) throw invalid_argument("nonnegative values");
        sum += x;
    }
    if (sum % 2) return false;
    if (sum/2 > 200000) throw invalid_argument("teaching target limit");
    int target = (int)(sum/2);
    vector<char> reachable(target+1,false); reachable[0] = true;
    for (int x : a)
        for (int c = target; c >= x; --c)
            if (reachable[c-x]) reachable[c] = true;
    return reachable[target];
}

面试追问：关键点完整解答

恰好装满为何不能把所有 dp 初始化为 0？

这会把本来凑不出的容量当成零价值的可行前驱。例如只有重量 2 的物品，容量 3 会从虚假的 dp[1]=0 转移出一个假答案。只让 dp[0] 可达，其余显式标不可达，才能保证所有转移有合法来源。

二维 0/1 背包是否也必须倒序容量？

不必须，只要它始终读取上一行 f[i−1]，当前行的计算顺序可以正序。倒序是将两行压缩到同一数组后，为避免覆盖上一行小容量状态才需要的技巧。

零重量物品该如何处理？

本章价值型背包接口要求正重量，拒绝零重以统一数值与循环契约。若允许 0/1 零重物品，可专门处理每件至多一次；完全背包若有零重正价值物品，最优值无上界。布尔子集中的零不会改变可达性，计数中却会倍增方案，不能混为一谈。

为什么背包 O(nC) 不一定适合大输入？

C=10^9 即使只有几十件物品，数组和循环也不可接受。输入只需约 30 位表达容量，但 DP 按数值铺开。可结合物品数、价值总和考虑按价值 DP、折半枚举或其他结构，不应看到 O(nC) 就默认可运行。

一维背包能否只放一个 parent[c] 就可靠恢复物品？

容易出错：记录的前驱容量在后续物品中可能被覆盖，回溯时拿到的是另一时刻的方案，甚至重复使用同一件。需要保留分层决策、不可变路径节点，或用重新计算等经过证明的方法；本节接口只承诺最优值，不伪造恢复链。

总和为偶数是否意味着一定能等分？

不是，仅是必要条件。[1,2,5] 总和 8，但无法选出和为 4 的子集。奇数可立即失败，偶数仍须检查目标容量是否真的可达。

知识与适用场景

物品可无限次使用时，同一轮允许重复依赖当前物品，所以容量正序遍历。计数题必须再区分组合与排列：组合忽略选择顺序，排列保留顺序。

optional<vector<int>> minimumCoinsPath(vector<int> coins, int amount) {
    if (amount < 0 || amount > 200000) throw invalid_argument("amount");
    for (int c : coins) if (c <= 0) throw invalid_argument("positive coin");
    sort(coins.begin(),coins.end());
    coins.erase(unique(coins.begin(),coins.end()),coins.end());
    const int INF = amount+1;
    vector<int> dp(amount+1,INF), last(amount+1,-1);
    dp[0] = 0;
    for (int s = 1; s <= amount; ++s)
        for (int c : coins) {
            if (c > s) break;
            if (dp[s-c] != INF && dp[s-c]+1 < dp[s]) {
                dp[s] = dp[s-c]+1; last[s] = c;
            }
        }
    if (dp[amount] == INF) return nullopt;
    vector<int> chosen;
    for (int s = amount; s > 0; s -= last[s]) chosen.push_back(last[s]);
    return chosen;
}

pair<long long,long long> coinCountsMod(vector<int> coins, int amount,
                                         int mod = 1000000007) {
    if (amount < 0 || amount > 200000 || mod < 2 || mod > 1000000007)
        throw invalid_argument("amount/mod");
    for (int c : coins) if (c <= 0) throw invalid_argument("positive coin");
    sort(coins.begin(),coins.end());
    coins.erase(unique(coins.begin(),coins.end()),coins.end());
    vector<long long> combos(amount+1), ordered(amount+1);
    combos[0] = ordered[0] = 1;
    for (int c : coins)
        for (int s = c; s <= amount; ++s)
            combos[s] = (combos[s]+combos[s-c])%mod;
    for (int s = 1; s <= amount; ++s)
        for (int c : coins) {
            if (c > s) break;
            ordered[s] = (ordered[s]+ordered[s-c])%mod;
        }
    return {combos[amount],ordered[amount]};
}

面试追问：关键点完整解答

dp[0]=1 为什么不是凭空多出一个方案？

构成金额 0 有一种空选择。它充当递推的乘法单位：例如第一枚币 c 使 dp[c] 加上 dp[0]，恰好产生只用这一枚的方案。若初始全零，所有加法状态永远为零。最少枚数中 dp[0]=0 是成本定义，不能与计数混淆。

为什么金额外层会计入 [1,2] 与 [2,1] 两种？

在金额 s 时遍历 c，相当于按最后一枚分类。s=3 的 c=1 接在序列 [2] 后得到 [2,1]；c=2 接在 [1] 后得到 [1,2]。最后元素不同是互不重叠的分类，正适合有序序列。

为什么币种外层不会重复构造同一组合？

处理第 i 种币后，只允许用前 i 种币，且按固定币种顺序扩展。任意多重集合都由每个币种使用次数唯一确定，不会再以反过来的币种顺序构造第二次。这个理由依赖相同币种没有被重复列为两个类型。

重复面值应该总是去重吗？

不总是。无限面额模型通常去重，因为相同面额不是不同选择；0/1 背包里的两个同重量物品可能是可各用一次的独立实体，去重会改变问题。先明确物品身份与方案判等规则，再决定。

最少硬币是不是每次拿最大面额即可？

任意币制不成立。面额 [1,3,4]、金额 6，先拿 4 需要再拿两个 1，共 3 枚；两个 3 只需 2 枚。DP 保留各剩余金额的最优值，不依赖特殊币制性质。

有序计数中的零值为什么特别危险？

允许无限次选择 0 后，任何合法序列都可插入任意多个 0 而不改变金额，方案数不再有限。方程还会出现 dp[s] 依赖自身，普通有限次扫描无法代表题意。必须限制次数或拒绝这类输入，不能只改变遍历方向。

12.04

序列 DP：最长公共子序列与编辑距离

知识与适用场景

两个字符串的相对进度需要两个下标。LCS 的 dp[i][j] 表示两个前缀的最长公共子序列长度；子序列允许跳过字符，子串必须连续，转移不同。

4.1 用前缀长度作坐标，空串才有自然位置

LCS 的 f[i][j] 表示 a 的前 i 个字节与 b 的前 j 个字节的最长公共子序列长度，下标 i、j 不是当前字符下标，末字符分别是 a[i−1]、b[j−1]。空前缀 f[0][j] 和 f[i][0] 均为 0。

末字符相等时，可以把它们配为公共序列的最后一项，接在两个短前缀的最优解后；存在包含这对末字符的最优解，所以得到 f[i−1][j−1]+1。末字符不等时，它们不能同时作为匹配末项，至少舍弃一侧，取上方与左方最大值。子串要求连续，字符不等时应把“以这两个位置结尾的长度”置 0，而不是延续 max。

4.2 LCS 表格：a=abc、b=ac

从右下角回溯：c 匹配，走左上；b 与 a 不匹配，走向保留同最优值的上方；a 匹配。记录顺序是 c、a，需要反转为 ac。

4.3 编辑距离的三条边，分别代表什么动作？

令 d[i][j] 为将 a 的前 i 个字符变为 b 的前 j 个字符的最少编辑次数。删掉 a 的末字符来自 d[i−1][j]+1；在 a 的末尾插入 b 的末字符来自 d[i][j−1]+1；替换末字符来自 d[i−1][j−1]+1。末字符相同则直接用左上角，不付费。

空串变成长度 j 的串必须插入 j 次，因此第一行是 0..m；长度 i 的串变为空串必须删除 i 次，第一列是 0..n。压缩一行时，dp[j] 尚是旧上方，dp[j−1] 已是新左方，旧左上必须额外保存，不能读被覆盖后的 dp[j−1]。

4.4 严格 LIS：tails 不是最终子序列

O(n²) LIS 定义 f[i] 为以 i 结尾的严格递增长度，转移枚举 j<i 且 a[j]<a[i]。O(n log n) 的 tails 是按长度保留最小末值的支配优化：同长度末值越小，越容易接后续元素。严格递增找第一个 ≥x 的位置；非递减则找第一个 >x 的位置。

int longestCommonSubsequence(const string& a,const string& b) {
    int n=(int)a.size(),m=(int)b.size();
    vector<vector<int>> dp(n+1,vector<int>(m+1,0));
    for(int i=1;i<=n;++i)
        for(int j=1;j<=m;++j)
            if(a[i-1]==b[j-1]) dp[i][j]=dp[i-1][j-1]+1;
            else dp[i][j]=max(dp[i-1][j],dp[i][j-1]);

string oneLCS(const string& a, const string& b) {
    int n = (int)a.size(), m = (int)b.size();
    vector<vector<int>> dp(n+1,vector<int>(m+1));
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= m; ++j)
            if (a[i-1] == b[j-1]) dp[i][j] = dp[i-1][j-1]+1;
            else dp[i][j] = max(dp[i-1][j],dp[i][j-1]);
    string result;
    int i = n, j = m;
    while (i > 0 && j > 0) {
        if (a[i-1] == b[j-1]) { result.push_back(a[i-1]); --i; --j; }
        else if (dp[i-1][j] >= dp[i][j-1]) --i;
        else --j;
    }
    reverse(result.begin(),result.end());
    return result;
}

int editDistanceRolling(const string& source, const string& target) {
    // 让列是短串。单位插删改的距离对称，所以可交换两串。
    const string* a = &source;
    const string* b = &target;
    if (a->size() < b->size()) swap(a,b);
    int n = (int)a->size(), m = (int)b->size();
    vector<int> dp(m+1);
    iota(dp.begin(),dp.end(),0);
    for (int i = 1; i <= n; ++i) {
        int diagonal = dp[0];
        dp[0] = i;
        for (int j = 1; j <= m; ++j) {
            int above = dp[j];
            if ((*a)[i-1] == (*b)[j-1]) dp[j] = diagonal;
            else dp[j] = 1+min({above,dp[j-1],diagonal});
            diagonal = above;
        }
    }
    return dp[m];
}

4.7 严格 LIS 的下标方案：二分之外保存前驱

vector<int> strictLISIndices(const vector<int>& a) {
    vector<int> tails, indexAtLength, parent(a.size(),-1);
    for (int i = 0; i < (int)a.size(); ++i) {
        int pos = (int)(lower_bound(tails.begin(),tails.end(),a[i])-tails.begin());
        if (pos > 0) parent[i] = indexAtLength[pos-1];
        if (pos == (int)tails.size()) {
            tails.push_back(a[i]); indexAtLength.push_back(i);
        } else {
            tails[pos] = a[i]; indexAtLength[pos] = i;
        }
    }
    vector<int> result;
    if (tails.empty()) return result;
    for (int i = indexAtLength.back(); i != -1; i = parent[i]) result.push_back(i);
    reverse(result.begin(),result.end());
    return result;
}

面试追问：关键点完整解答

LCS 与最长公共子串的转移区别在哪里？

LCS 可跳过字符，不匹配时取上、左状态最大值。公共子串必须连续，若定义以 i、j 结尾的长度，不匹配时必须归零，匹配时才从左上加一；最后取所有状态最大值，而不一定右下角。

一维 LCS 或编辑距离为什么需要 diagonal？

内层从左往右时，dp[j−1] 已是当前行，旧的 f[i−1][j−1] 已被覆盖。先把旧 dp[j] 保存为 above，完成当前格后再令 diagonal=above，就能给下一格提供正确的旧左上值。

一行 DP 能直接恢复完整 LCS 吗？

通常不能直接按原表回溯，因为旧行已丢失。保留二维表是最清楚的基础方法；更省空间的恢复可以用分治等专门方法，需要额外推导，不能声称长度压缩后父路径自动仍然存在。

为什么严格 LIS 用 lower_bound，非递减用 upper_bound？

严格递增不允许等值延长，因此 x 应替换第一个 ≥x 的结尾；非递减允许等值接在末尾，所以跳过等值，找第一个 >x 的位置。数组 [2,2,2] 的严格 LIS 长度 1，非递减长度 3。

tails 能否直接作为一条 LIS 输出？

不能。不同长度位置可能来自不同历史时刻，[3,5,6,2,4] 最后的 tails=[2,4,6] 并不是原数组子序列。需要记录每个原始元素的前驱与各长度对应的末元素下标，再回溯。

编辑距离把第一行第一列都设 0 会怎样？

它会把从空串插入任意字符、或删除任意前缀当作免费操作，系统性低估代价。状态是前缀之间的转换成本，空边界的答案就是长度，不是无信息所以填零。

12.05

区间 DP：由短区间构造长区间

知识与适用场景

区间 DP 的状态通常是闭区间 [l,r] 上的答案，依赖更短区间。最长回文子序列：两端相同可配对，不同则至少丢掉一端。

5.1 区间遍历顺序是依赖关系的线性展开

最长回文子序列的 f[l][r] 表示闭区间内可删除字符后保留的最大回文长度。两端相同可配对，取内部最优加 2；两端不同，至少丢掉一端，取 f[l+1][r] 与 f[l][r−1] 的最大值。

所需区间均严格更短，因此长度从 1 到 n 是合法顺序；也可让 l 逆序、r 正序。若 l 从小到大、r 从小到大，f[l+1][r] 所在下一行还没算，读到零值也不会报错，却会产生错误结果。

5.3 戳气球为什么选最后一步，而不是第一步？

先戳 k 会让它左右两边新相邻，后面的收益相互耦合，难以形成两个独立的固定区间。反过来，设 k 是开区间 (l,r) 最后戳的气球，那么在它被戳之前 l、k、r 都保留，左右子问题的边界固定，彼此独立。

转移 f[l][r]=max(f[l][k]+f[k][r]+value[l]·value[k]·value[r])。l、r 是还未戳的边界，不属于子问题要清空的集合；两端补值 1，原数组全部位于 (0,n+1)。相邻边界之间没有气球，初值 0。这里“最后”只是分类方法，实际执行可以先做左右子区间，再戳 k。

推导 / 不变量

dp[l][r] 在相同端点时等于内部答案+2，否则取 dp[l+1][r] 与 dp[l][r-1] 的最大值。按长度递增填表，确保内部和两个短区间已计算。

    int n=(int)s.size();
    if(n==0) return 0;
    vector<vector<int>> dp(n,vector<int>(n,0));
    for(int i=0;i<n;++i) dp[i][i]=1;
    for(int len=2;len<=n;++len)
        for(int l=0;l+len<=n;++l){
            int r=l+len-1;
            if(s[l]==s[r]) dp[l][r]=2+(len==2 ? 0 : dp[l+1][r-1]);
            else dp[l][r]=max(dp[l+1][r],dp[l][r-1]);
        }
    return dp[0][n-1];
}

string longestPalindromeSubstringDP(const string& s) {
    int n = (int)s.size();
    if (!n) return "";
    vector<vector<char>> palindrome(n,vector<char>(n,false));
    int start = 0, bestLength = 1;
    for (int len = 1; len <= n; ++len)
        for (int l = 0; l+len <= n; ++l) {
            int r = l+len-1;
            palindrome[l][r] = s[l] == s[r] &&
                (len <= 2 || palindrome[l+1][r-1]);
            if (palindrome[l][r] && len > bestLength) {

            }
        }
    return s.substr(start,bestLength);
}

long long burstBalloonsDP(const vector<int>& nums) {
    if (nums.size() > 300) throw invalid_argument("teaching size limit");
    vector<long long> a{1};
    for (int x : nums) {
        if (x < 0 || x > 1000) throw invalid_argument("balloon value");
        a.push_back(x);
    }
    a.push_back(1);
    int n = (int)a.size();
    vector<vector<long long>> dp(n,vector<long long>(n));
    for (int gap = 2; gap < n; ++gap)
        for (int l = 0; l+gap < n; ++l) {
            int r = l+gap;
            for (int k = l+1; k < r; ++k)
                dp[l][r] = max(dp[l][r],dp[l][k]+dp[k][r]+a[l]*a[k]*a[r]);
        }
    return dp[0][n-1];
}

面试追问：关键点完整解答

为什么区间长度递增能保证所有依赖已计算？

去掉一个端点、两个端点，或按内部 k 分开，得到的区间都更短。只要初始最短区间已定义，逐长度增加就是对依赖图的一种拓扑顺序。若转移仍依赖同长度或更长区间，不能未经证明套这种顺序。

最长回文子序列两端不同，为什么只需丢一端？

一个回文子序列若同时保留两端，它们将成为首尾，必须相等。两端不同就不可能同时选，最优方案至少属于“丢左端”或“丢右端”中的一类。两类重叠不影响求 max，但若改为计数就必须处理重复。

把子串状态换成子序列状态，会产生什么假答案？

子序列可以跳过中间元素，子串不能。例如 bbbab 的最长回文子序列是 bbbb，长度 4，但它不是连续片段；最长回文子串只有长度 3。判断整个区间是否回文时必须保证内部整个区间也回文。

戳气球的虚拟边界为什么是 1？

原题边缘外侧相当于不存在的邻居，乘积计算使用 1。补 1 后可以统一处理边缘与内部情况，避免每个状态重新判断越界。虚拟边界永远不戳，答案是清空它们之间的开区间。

为什么第一步容易耦合，最后一步能独立？

先删内部气球会改变左右两侧未来的相邻关系，它们不再独立；确定最后戳 k 时，k 在左右子问题整个执行期间都存在，充当固定边界。这个思想也用于矩阵链等区间决策：寻找能固定子问题边界的最后动作。

区间 DP 的计数能否直接把 max 改成加法？

不一定。求最优值允许不同转移覆盖同一候选，因为重复取 max 无害；计数要求转移分类互斥或显式去重。回文子序列计数尤其要区分不同下标方案与不同字符串内容，状态和重叠修正需要重新推导。

12.06

树形与状态机 DP：把限制写进状态

知识与适用场景

树上打家劫舍中相邻父子不能同时选。一个节点需返回两个值：不选它的最优值 skip、选它的最优值 take。只返回一个最优值会丢失父节点决策所需的信息。

6.1 树形 DP 的返回值，是提供给父节点的决策接口

父子不能同时选时，父节点需要知道孩子“不选”的最优值，而不只是孩子任意选择时的最大值。因此每个节点保留 skip、take 两个条件答案。选当前节点时只能加孩子 skip；不选当前节点时，每个孩子可独立取 max(skip,take)。

对树，不同孩子的子树没有共享节点或跨子树约束，才能独立相加。把这个递推直接用在有环图、共享孩子的 DAG 上，可能重复计算同一节点收益或漏掉跨边冲突。后序顺序只是计算顺序，子问题独立才是转移成立的原因。

    if(!p) return {0,0}; // {skip,take}
    auto [ls,lt]=robState(p->left);
    auto [rs,rt]=robState(p->right);
    long long skip=max(ls,lt)+max(rs,rt);
    long long take=p->val+ls+rs;
    return {skip,take};
}

struct RobNode {
    int value;
    RobNode *left = nullptr, *right = nullptr;
    explicit RobNode(int v): value(v) {}
};
long long robTreeIterative(RobNode* root) {
    if (!root) return 0;
    unordered_map<RobNode*,pair<long long,long long>> state;
    vector<pair<RobNode*,bool>> stack{{root,false}};
    while (!stack.empty()) {
        auto [node,expanded] = stack.back(); stack.pop_back();
        if (!expanded) {
            stack.push_back({node,true});
            if (node->right) stack.push_back({node->right,false});
            if (node->left) stack.push_back({node->left,false});
        } else {
            auto left = node->left ? state.at(node->left) : make_pair(0LL,0LL);
            auto right = node->right ? state.at(node->right) : make_pair(0LL,0LL);
            long long skip = max(left.first,left.second)+max(right.first,right.second);
            long long take = node->value+left.first+right.first;
            state[node] = {skip,take};
        }
    }
    auto [skip,take] = state.at(root);
    return max(skip,take);
}

6.6 最多 K 次交易：按额度保存两种持仓状态

long long stockAtMostK(const vector<int>& prices, int k) {
    if (k < 0) throw invalid_argument("k");
    for (int p : prices) if (p < 0) throw invalid_argument("price");
    int n = (int)prices.size();
    if (k >= n/2) {
        long long answer = 0;
        for (int i = 1; i < n; ++i)
            answer += max(0LL,(long long)prices[i]-prices[i-1]);
        return answer;
    }
    const long long NEG = LLONG_MIN/4;
    vector<long long> cash(k+1,0), hold(k+1,NEG);
    for (int p : prices) {
        auto oldCash = cash, oldHold = hold;
        for (int t = 1; t <= k; ++t) {
            hold[t] = max(oldHold[t],oldCash[t-1]-p);
            cash[t] = oldCash[t];
            if (oldHold[t] != NEG) cash[t] = max(cash[t],oldHold[t]+p);
        }
    }
    return cash[k];
}

6.7 状态压缩任务分配与方案恢复

pair<long long,vector<int>> minimumAssignment(const vector<vector<int>>& cost) {
    int n = (int)cost.size();
    if (n > 18) throw invalid_argument("n <= 18 required");
    for (const auto& row : cost) {
        if ((int)row.size() != n) throw invalid_argument("square matrix");
        for (int x : row) if (x < -1000000000 || x > 1000000000)
            throw invalid_argument("cost");
    }
    int total = 1 << n;
    const long long INF = LLONG_MAX/4;
    vector<long long> dp(total,INF);
    vector<int> chosen(total,-1);
    dp[0] = 0;
    for (int mask = 0; mask < total; ++mask) {
        int worker = 0;
        for (int bits = mask; bits; bits &= bits-1) ++worker;
        if (worker == n || dp[mask] == INF) continue;
        for (int task = 0; task < n; ++task) if (!(mask & (1 << task))) {
            int next = mask | (1 << task);
            long long candidate = dp[mask]+cost[worker][task];
            if (candidate < dp[next]) { dp[next] = candidate; chosen[next] = task; }
        }
    }
    vector<int> assignment(n);
    int mask = total-1;
    for (int worker = n-1; worker >= 0; --worker) {
        int task = chosen[mask];
        assignment[worker] = task; mask ^= 1 << task;
    }
    return {dp.back(),assignment};
}

面试追问：关键点完整解答

树上为何不能只返回 max(skip,take)？

父节点如果选择自己，就必须知道孩子不选时的答案。一个无条件最大值可能来自选孩子，将其相加会同时选择相邻节点。把边界条件作为状态维度，是向父节点提供足够信息。

递归树 DP 和显式后序的复杂度有什么不同？

两者都计算每个节点一次。基础递归只需调用栈 O(h)；本显式版本保存全部节点状态，额外空间 O(n)，避免了深链的系统栈风险但增加存储。哈希表查找是平均常数，不能无条件称最坏 O(n)。

股票 cash[t] 初始为 0 为什么不是把不可达当可达？

这里的 t 是至多交易额度，不是恰好完成次数。尚未交易、空仓余额 0 对每个额度都合法；持股仍不可达。如果 t 定义成恰好完成次数，初值和转移必须另改，不能沿用所有 cash 都为 0。

K 很大时为什么可退化成无限次交易？

在每天最多一个动作、先买后卖的无费用模型中，每笔非空交易至少占买卖两天，至多 floor(n/2) 笔。额度达到这个上限就不再限制合法策略。存在手续费、冷冻期时虽然也有次数上限，但最终最优值不能直接用正差累加。

状态压缩为什么能省掉工人编号？

工人固定按顺序各分配一项，mask 中 1 的个数就是已分配工人数，下一工人编号由 mask 唯一确定。这是有依据地删除冗余维度；若工人顺序也可跳过或每人分配多项，就不能直接采用相同状态。

单词拆分也属于 DP 吗，状态需要保存整条切分路径吗？

只问能否拆分时，令 reachable[i] 表示前 i 个字符可由词典组成，枚举最后一个词对应的切分 j，检查 reachable[j] 与 s[j:i] 是否在词典。未来只依赖当前位置，无需保存整条历史；要输出所有切分时，才需保留前驱并面对可能指数级的输出量。

章末自测：四个跨模型问题

最优子结构与重叠子问题分别起什么作用？

最优子结构使最优解能由恰当条件下的子问题最优解组合而来；重叠子问题使缓存与复用有价值。若子问题之间还共享未记录的约束，直接相加可能不合法；必须先扩充状态。没有大量重叠的递归也可以做递推，但未必能因缓存获得显著加速。

怎样判断某个状态维度能不能删？

如果两段历史被映射到同一状态，它们的后续合法选择与后续代价规则应相同；或者能证明其中一个始终支配另一个。LIS 同长度较小结尾支配较大结尾，可以只留最小者；不同持仓状态未来动作不同，不能直接只保留余额最大者。

DP 计数取模后等于 0，为什么不代表无解？

真实计数可能正好是模数的倍数。比如 [1,2] 凑 2 的组合有 2 种，模 2 后为 0，但明显可达。需要可达性时另存布尔值，不要把模数结果当作 visited 或 reachable。

最优值正确，恢复方案为何仍可能错？

恢复依赖保存的决策是否属于同一历史状态。滚动背包可能覆盖前驱所代表的物品层；tails 本身也不是一条实际 LIS。验证方案应同时检查下标顺序、约束、总代价和最优值，不能只核对长度。

bool isSubsequenceOf(const string& small, const string& large) {
    size_t i = 0;
    for (char c : large) if (i < small.size() && small[i] == c) ++i;
    return i == small.size();
}
bool isPalindromeText(const string& s) {
    string reversed(s.rbegin(),s.rend());
    return s == reversed;
}
string maskString(const string& s, int mask) {
    string result;
    for (int i = 0; i < (int)s.size(); ++i)
        if (mask & (1 << i)) result.push_back(s[i]);
    return result;
}
BestSubarray bruteSubarray(const vector<int>& a) {
    BestSubarray best{LLONG_MIN,0,0};
    for (int l = 0; l < (int)a.size(); ++l) {
        long long sum = 0;
        for (int r = l; r < (int)a.size(); ++r) {
            sum += a[r];
            if (sum > best.sum) best = {sum,l,r};
        }
    }
    return best; // l、r 升序枚举，严格改进自然保持相同平局规则
}
long long bruteRobCircle(const vector<int>& a) {
    int n = (int)a.size();
    long long best = 0;
    for (int mask = 0; mask < (1 << n); ++mask) {
        bool ok = true; long long sum = 0;
        for (int i = 0; i < n; ++i) if (mask & (1 << i)) {
            sum += a[i];
            if (n > 1 && (mask & (1 << ((i+1)%n)))) ok = false;
        }
        if (ok) best = max(best,sum);
    }
    return best;
}
pair<optional<long long>,long long> bruteKnapsack(
    const vector<int>& w, const vector<int>& v, int capacity) {
    optional<long long> exact; long long atMost = 0;
    for (int mask = 0; mask < (1 << w.size()); ++mask) {
        int weight = 0; long long value = 0;
        for (int i = 0; i < (int)w.size(); ++i) if (mask & (1 << i)) {
            weight += w[i]; value += v[i];
        }
        if (weight == capacity && (!exact || value > *exact)) exact = value;
        if (weight <= capacity) atMost = max(atMost,value);
    }
    return {exact,atMost};
}
bool brutePartition(const vector<int>& a) {
    int total = accumulate(a.begin(),a.end(),0);
    for (int mask = 0; mask < (1 << a.size()); ++mask) {
        int sum = 0;
        for (int i = 0; i < (int)a.size(); ++i)
            if (mask & (1 << i)) sum += a[i];
        if (2*sum == total) return true;
    }
    return false;
}
long long bruteCoinCombos(const vector<int>& coins, int index, int remaining) {
    if (index == (int)coins.size()) return remaining == 0 ? 1LL : 0LL;
    long long ways = 0;
    for (int count = 0; count*coins[index] <= remaining; ++count)
        ways += bruteCoinCombos(coins,index+1,remaining-count*coins[index]);
    return ways;
}
long long bruteCoinOrdered(const vector<int>& coins, int remaining) {
    if (!remaining) return 1;
    long long ways = 0;
    for (int c : coins) if (c <= remaining) ways += bruteCoinOrdered(coins,remaining-c);
    return ways;
}
int coinBFS(const vector<int>& coins, int amount) {
    vector<int> distance(amount+1,-1);
    queue<int> q; q.push(0); distance[0] = 0;
    while (!q.empty()) {
        int sum = q.front(); q.pop();
        for (int c : coins) if (sum+c <= amount && distance[sum+c] == -1) {
            distance[sum+c] = distance[sum]+1; q.push(sum+c);
        }
    }
    return distance[amount];
}
int bruteLCS(const string& a, const string& b) {
    int best = 0;
    for (int mask = 0; mask < (1 << a.size()); ++mask) {
        string candidate = maskString(a,mask);
        if (isSubsequenceOf(candidate,b)) best = max(best,(int)candidate.size());
    }
    return best;
}
int recursiveEdit(const string& a, const string& b, int i, int j) {
    if (i == (int)a.size()) return (int)b.size()-j;
    if (j == (int)b.size()) return (int)a.size()-i;
    if (a[i] == b[j]) return recursiveEdit(a,b,i+1,j+1);
    return 1+min({recursiveEdit(a,b,i+1,j),recursiveEdit(a,b,i,j+1),
                  recursiveEdit(a,b,i+1,j+1)});
}
int bruteLIS(const vector<int>& a) {
    int best = 0;
    for (int mask = 0; mask < (1 << a.size()); ++mask) {
        bool ok = true; long long prev = LLONG_MIN; int length = 0;
        for (int i = 0; i < (int)a.size(); ++i) if (mask & (1 << i)) {
            if (a[i] <= prev) ok = false;
            prev = a[i]; ++length;
        }
        if (ok) best = max(best,length);
    }
    return best;
}
int brutePalindromeSubseq(const string& s) {
    int best = 0;
    for (int mask = 0; mask < (1 << s.size()); ++mask) {
        string candidate = maskString(s,mask);
        if (isPalindromeText(candidate)) best = max(best,(int)candidate.size());
    }
    return best;
}
string brutePalindromeSubstring(const string& s) {
    string best;
    for (int l = 0; l < (int)s.size(); ++l)
        for (int len = 1; l+len <= (int)s.size(); ++len) {
            string candidate = s.substr(l,len);
            if (isPalindromeText(candidate) && candidate.size() > best.size()) best = candidate;
        }
    return best;
}
long long bruteBurst(vector<int> a) {
    long long best = 0;
    for (int i = 0; i < (int)a.size(); ++i) {
        long long gain = (i == 0 ? 1LL : a[i-1])*a[i]*
                         (i+1 == (int)a.size() ? 1LL : a[i+1]);
        auto next = a; next.erase(next.begin()+i);
        best = max(best,gain+bruteBurst(next));
    }
    return best;
}
long long bruteTreeRob(const vector<int>& value, const vector<int>& parent) {
    int n = (int)value.size(); long long best = 0;
    for (int mask = 0; mask < (1 << n); ++mask) {
        bool ok = true; long long sum = 0;
        for (int i = 0; i < n; ++i) if (mask & (1 << i)) {
            sum += value[i];
            if (parent[i] >= 0 && (mask & (1 << parent[i]))) ok = false;
        }
        if (ok) best = max(best,sum);
    }
    return best;
}
long long bruteStock(const vector<int>& p, int k) {
    const long long NEG = LLONG_MIN/4;
    function<long long(int,bool,int)> dfs = [&](int day,bool holding,int sold) {
        if (day == (int)p.size()) return holding ? NEG : 0LL;
        long long best = dfs(day+1,holding,sold);
        if (holding && sold < k)
            best = max(best,(long long)p[day]+dfs(day+1,false,sold+1));
        if (!holding && sold < k) {
            long long future = dfs(day+1,true,sold);
            if (future != NEG) best = max(best,future-p[day]);
        }
        return best;
    };
    return dfs(0,false,0);
}
long long bruteAssignment(const vector<vector<int>>& cost) {
    vector<int> order(cost.size()); iota(order.begin(),order.end(),0);
    long long best = LLONG_MAX;
    do {
        long long sum = 0;
        for (int i = 0; i < (int)cost.size(); ++i) sum += cost[i][order[i]];
        best = min(best,sum);
    } while (next_permutation(order.begin(),order.end()));
    return best;
}
