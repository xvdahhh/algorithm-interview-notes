12.01

线性 DP：以当前位置结尾

知识与适用场景

最大子数组和的状态是“必须以 i 结尾的非空子数组最大和”，不是前 i 个元素的全局最优。状态只需在继续前一段和从当前元素重新开始之间选择。

推导 / 不变量

endHere=max(a[i],endHere+a[i])；全局答案取所有 endHere 的最大值。若前一段和为负，接上它只会让当前更差，应重新开始。

手推一个例子

[-2,1,-3,4,-1,2,1,-5,4]：处理到 4 时重新开始，随后累加 -1、2、1 得到 6，是最终最大值。

C++17
下载 .cpp
long long maxSubArray(const vector<int>& a) {
    if(a.empty()) throw invalid_argument("nonempty array required");
    long long endHere=a[0],best=a[0];
    for(int i=1;i<(int)a.size();++i){
        endHere=max((long long)a[i],endHere+a[i]);
        best=max(best,endHere);
    }
    return best;
}
复杂度
时间 O(n)，滚动状态空间 O(1)。
易错点与边界
若允许空子数组则全负数组答案可为 0；本题要求非空，必须用首元素初始化。打家劫舍中则可以一个都不选。

经典考点与练习

练习：LeetCode 53 最大子数组和、198 打家劫舍、213 打家劫舍 II。

面试官可能继续问什么？

如何返回子数组左右下标？为何不能只保存当前全局 best 做下一轮转移？

12.02

0/1 背包：容量倒序的原因

知识与适用场景

dp[c] 表示处理到当前物品时，在容量不超过 c 的限制下能获得的最大价值。每个物品最多用一次；二维转移应从上一行取值。

推导 / 不变量

压缩为一维后按容量倒序，使 dp[c-weight] 尚未使用本轮物品。如果正序，会把本轮更新值再次拿来转移，错误地重复选择同一件物品。

手推一个例子

只有一件重量 2、价值 3 的物品，容量 4。正序会先把 dp[2] 更新为 3，再把 dp[4] 更新为 6；倒序则 dp[4] 只能得到 3。

C++17
下载 .cpp
long long knapsack01(const vector<int>& weight,
                     const vector<int>& value,int capacity) {
    if(capacity<0 || weight.size()!=value.size())
        throw invalid_argument("invalid input");
    vector<long long> dp(capacity+1,0);
    for(int i=0;i<(int)weight.size();++i){
        if(weight[i]<=0) throw invalid_argument("positive weights required");
        for(int c=capacity;c>=weight[i];--c)
            dp[c]=max(dp[c],dp[c-weight[i]]+value[i]);
    }
    return dp[capacity];
}
复杂度
时间 O(nC)，空间 O(C)，属于伪多项式算法，C 的数值可能很大。
易错点与边界
恰好装满与不超过容量不同：恰好装满应仅 dp[0]=0，其余设负无穷，并跳过不可达转移。

经典考点与练习

练习：LeetCode 416 分割等和子集、494 目标和、1049 最后一块石头的重量 II。

面试官可能继续问什么？

如何把分割等和子集转成布尔背包？总和为奇数为何可立即失败？

12.03

完全背包与计数顺序

知识与适用场景

物品可无限次使用时，同一轮允许重复依赖当前物品，所以容量正序遍历。计数题必须再区分组合与排列：组合忽略选择顺序，排列保留顺序。

推导 / 不变量

求硬币组合数时外层遍历币种、内层正序遍历金额。每种组合按币种顺序构建一次。若外层金额、内层币种，转移是在为序列追加最后一枚硬币，通常计数排列。

手推一个例子

硬币 [1,2]，金额 3：组合为 {1,1,1}、{1,2} 共 2；排列还区分 [1,2] 与 [2,1]，共 3。

C++17
下载 .cpp
long long coinCombinations(const vector<int>& coins,int amount) {
    if(amount<0) return 0;
    vector<long long> dp(amount+1,0);
    dp[0]=1;
    for(int c:coins){
        if(c<=0) throw invalid_argument("positive distinct coins required");
        for(int s=c;s<=amount;++s) dp[s]+=dp[s-c];
    }
    return dp[amount];
}
复杂度
时间 O(币种数·amount)，空间 O(amount)。示例假设币种互异，方案数不超过 long long。
易错点与边界
dp[0]=1 代表一种空选择，是计数的起点。最少硬币数问题把加法计数改为 min，并把不可达初始化为 INF。

经典考点与练习

练习：LeetCode 322 零钱兑换、518 零钱兑换 II、377 组合总和 IV。

面试官可能继续问什么？

为什么重复币种会造成重复计数？需要取模时在哪里进行？

12.04

序列 DP：最长公共子序列与编辑距离

知识与适用场景

两个字符串的相对进度需要两个下标。LCS 的 dp[i][j] 表示两个前缀的最长公共子序列长度；子序列允许跳过字符，子串必须连续，转移不同。

推导 / 不变量

若最后字符相同，LCS 可由 dp[i-1][j-1]+1 得到；否则舍弃其中一侧末字符，取 max(dp[i-1][j],dp[i][j-1])。编辑距离则把三种删除、插入、替换成本取最小。

手推一个例子

"abcde" 与 "ace" 的 LCS 是 "ace"，长度 3。若要求公共子串，就不能跨过 b、d，答案不再是 3。

C++17
下载 .cpp
int longestCommonSubsequence(const string& a,const string& b) {
    int n=(int)a.size(),m=(int)b.size();
    vector<vector<int>> dp(n+1,vector<int>(m+1,0));
    for(int i=1;i<=n;++i)
        for(int j=1;j<=m;++j)
            if(a[i-1]==b[j-1]) dp[i][j]=dp[i-1][j-1]+1;
            else dp[i][j]=max(dp[i-1][j],dp[i][j-1]);
    return dp[n][m];
}
复杂度
时间 O(nm)，空间 O(nm)，只求长度时可滚动优化到 O(m)。字符串按字节比较。
易错点与边界
状态下标是前缀长度，访问字符时需要减 1。编辑距离初始化 dp[i][0]=i、dp[0][j]=j，不能全部置零。

经典考点与练习

练习：LeetCode 1143 最长公共子序列、72 编辑距离、300 最长递增子序列。

面试官可能继续问什么？

如何从 DP 表回溯一条 LCS？最长递增子序列的 O(n²) 状态怎么定义？

12.05

区间 DP：由短区间构造长区间

知识与适用场景

区间 DP 的状态通常是闭区间 [l,r] 上的答案，依赖更短区间。最长回文子序列：两端相同可配对，不同则至少丢掉一端。

推导 / 不变量

dp[l][r] 在相同端点时等于内部答案+2，否则取 dp[l+1][r] 与 dp[l][r-1] 的最大值。按长度递增填表，确保内部和两个短区间已计算。

手推一个例子

"bbbab" 中区间两端都是 b，把它们配对并求内部 "bba" 的答案，可得到长度 4 的 "bbbb"。

C++17
下载 .cpp
int longestPalindromeSubseq(const string& s) {
    int n=(int)s.size();
    if(n==0) return 0;
    vector<vector<int>> dp(n,vector<int>(n,0));
    for(int i=0;i<n;++i) dp[i][i]=1;
    for(int len=2;len<=n;++len)
        for(int l=0;l+len<=n;++l){
            int r=l+len-1;
            if(s[l]==s[r]) dp[l][r]=2+(len==2 ? 0 : dp[l+1][r-1]);
            else dp[l][r]=max(dp[l+1][r],dp[l][r-1]);
        }
    return dp[0][n-1];
}
复杂度
时间 O(n²)，空间 O(n²)。
易错点与边界
最长回文子串要求内部整个区间是回文；最长回文子序列允许删除字符，不能混用状态。戳气球应考虑区间最后戳哪一个，固定边界后子问题才独立。

经典考点与练习

练习：LeetCode 516 最长回文子序列、5 最长回文子串、312 戳气球。

面试官可能继续问什么？

为什么直接按 l 从小到大、r 从小到大可能用到未计算状态？

12.06

树形与状态机 DP：把限制写进状态

知识与适用场景

树上打家劫舍中相邻父子不能同时选。一个节点需返回两个值：不选它的最优值 skip、选它的最优值 take。只返回一个最优值会丢失父节点决策所需的信息。

推导 / 不变量

选当前节点时，两个孩子都必须不选；不选当前节点时，每个孩子可以独立取选或不选的最大值。后序顺序恰好保证孩子状态先完成。

手推一个例子

根 3，孩子 2、3，孙辈 3、1：选择根和两个孙辈可得 7；仅比较孩子局部最大值而不区分是否选取，会错误连接相邻节点。

C++17
下载 .cpp
struct TreeNode {
    int val; TreeNode *left=nullptr,*right=nullptr;
    explicit TreeNode(int v):val(v){}
};
pair<long long,long long> robState(TreeNode* p) {
    if(!p) return {0,0}; // {skip,take}
    auto [ls,lt]=robState(p->left);
    auto [rs,rt]=robState(p->right);
    long long skip=max(ls,lt)+max(rs,rt);
    long long take=p->val+ls+rs;
    return {skip,take};
}
long long robTree(TreeNode* root) {
    auto [skip,take]=robState(root);
    return max(skip,take);
}
复杂度
时间 O(n)，递归空间 O(h)。
易错点与边界
股票 DP 同理：用持有/未持有、剩余交易次数等状态表达约束。更新多个状态时先保存上一轮值，避免未经证明的本轮互相依赖。

经典考点与练习

练习：LeetCode 337 打家劫舍 III、309 最佳买卖股票时机含冷冻期、714 买卖股票的最佳时机含手续费。

面试官可能继续问什么？

为什么只返回 max(skip,take) 不够？有冷冻期时股票 DP 需要增加什么状态？
