# 第 12 章：动态规划

## 动态规划五步法

1. 定义状态：`dp[...]` 精确表示什么。
2. 写出转移：当前状态由哪些更小状态得到。
3. 确定初始条件：最小问题的答案是什么。
4. 确定计算顺序：依赖状态必须先算出。
5. 明确最终答案：不一定总是最后一个状态。

动态规划适用于存在重叠子问题和最优子结构的问题。状态设计比代码更重要。

## 记忆化搜索与递推

- 记忆化搜索：从目标状态向下递归，只计算会访问到的状态，易于从暴力搜索改造。
- 自底向上递推：控制计算顺序，无递归栈，通常常数更小。
- 两者状态和转移本质相同，不要把“用了递归”误认为不是 DP。

## 高频类型

### 线性 DP

- 打家劫舍：`dp[i]` 表示考虑前 `i` 个位置的最优值。
- 最大子数组和：以当前位置结尾的最优和，要么单独开始，要么接在前一段后。
- 股票问题：用“天数、交易次数、是否持有”描述状态。

### 背包 DP

- 0/1 背包：每件物品最多一次，压缩为一维后容量必须倒序遍历。
- 完全背包：每件物品可无限次，容量通常正序遍历。
- 组合数与排列数：外层遍历物品还是容量会影响计数顺序含义。
- 常见变形：分割等和子集、零钱兑换、目标和、单词拆分。

### 序列 DP

- 最长递增子序列：`O(n²)` DP；也可用贪心 + 二分优化到 `O(n log n)`。
- 最长公共子序列：二维状态表示两个前缀的答案。
- 编辑距离：插入、删除、替换对应三种前驱状态。

### 区间 DP

状态常为 `dp[l][r]`，按区间长度从小到大计算。典型题有最长回文子序列、戳气球、石子合并。

### 树形 DP

以节点为状态载体，由孩子状态合并出父节点状态。典型题有树上打家劫舍、树的最大独立集。

### 状态压缩 DP

用位掩码表示已选集合，适合节点数较少的旅行商、任务分配和集合匹配问题，复杂度常含 `2^n`。

## 空间优化

- 若当前行只依赖上一行，可使用滚动数组。
- 一维压缩时必须确认遍历方向，避免在同一轮错误复用刚更新的值。
- 优化前先写出正确的二维状态和转移，再压缩空间。

## 易错点与自测

- [ ] 状态定义包含“范围、限制和结尾条件”。
- [ ] 初始化没有把不可达状态误设为 0。
- [ ] 最大值问题中的负无穷、最小值问题中的正无穷设置安全。
- [ ] 能解释 0/1 背包为什么倒序、完全背包为什么正序。
- [ ] 能独立写出最大子数组和、LCS、编辑距离和零钱兑换。
