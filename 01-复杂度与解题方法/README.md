# 第 01 章：复杂度与解题方法

## 需要掌握

### 时间复杂度

- 常见量级：`O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2^n) < O(n!)`。
- 顺序执行取最大项；嵌套循环通常相乘；二分、倍增、平衡树操作常见 `O(log n)`。
- 均摊复杂度：动态数组扩容、单调栈中元素“最多入栈出栈一次”都可均摊为 `O(1)` 或总计 `O(n)`。
- 递归复杂度要同时看分支数和深度；分治常用递推式分析，如归并排序 `T(n)=2T(n/2)+O(n)`。

### 空间复杂度

- 区分输入空间与额外空间；面试通常问额外空间。
- 递归调用栈也占空间：树的 DFS 为 `O(h)`，最坏退化成 `O(n)`。
- “原地算法”通常指额外空间 `O(1)`，但要确认是否允许修改输入。

### 用数据规模反推算法

| 数据规模 | 通常可接受的复杂度 |
| --- | --- |
| `n <= 20` | 指数搜索、状态压缩 |
| `n <= 100` | `O(n³)` 需谨慎 |
| `n <= 1,000` | `O(n²)` 常可接受 |
| `n <= 100,000` | `O(n log n)` 或 `O(n)` |
| `n >= 1,000,000` | 尽量 `O(n)`，注意内存与常数 |

具体阈值取决于语言、时限和常数，不能机械套用。

## 通用解题流程

1. 复述题意，确认输入输出、是否有序、是否可修改、是否存在重复值。
2. 用样例手推，明确真正要求的是“值、下标、方案数还是具体方案”。
3. 给出暴力解法作为正确性基线，再找重复计算或无效枚举。
4. 根据题型信号选择工具：有序想到二分/双指针，连续区间想到窗口/前缀和，最优子结构想到 DP。
5. 写代码前先说清不变量、状态含义或递归函数定义。
6. 编码后做桌面测试，最后给出复杂度。

## 正确性说明的三种常用方式

- 循环不变量：每轮开始或结束时，哪些性质始终成立。
- 归纳法：假设子问题正确，证明当前问题由子问题得到正确答案。
- 交换论证：证明某个最优解可以替换为贪心选择而不变差。

## 必查边界

- 空数组、空字符串、空树、空图。
- 单元素、全相同、严格递增/递减。
- 重复值、负数、零、大整数溢出。
- 下标越界、左右边界相交、链表空指针。
- 图不连通、有环、自环、重边。
