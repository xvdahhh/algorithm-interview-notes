13.01

并查集：路径压缩与按大小合并

知识与适用场景

每个集合用一棵父指针树表示，根是代表元。find 找根，unite 连接两个根。路径压缩把沿途节点直接连到根；按大小合并让小树挂到大树上。

推导 / 不变量

只有根维护有效的集合大小。合并前先 find，若同根说明已连通，不应重复减少连通块数。两种优化一起使用时，均摊成本为反阿克曼函数 α(n)。

手推一个例子

先合并 0、1，再合并 1、2。find(2) 与 find(0) 相同；再次合并 0、2 返回 false，表示此边会在无向图中形成环。

C++17
下载 .cpp
class UnionFind {
    vector<int> parent,sz;
    int components;
public:
    explicit UnionFind(int n):parent(n),sz(n,1),components(n) {
        iota(parent.begin(),parent.end(),0);
    }
    int find(int x) {
        if(parent[x]!=x) parent[x]=find(parent[x]);
        return parent[x];
    }
    bool unite(int a,int b) {
        a=find(a); b=find(b);
        if(a==b) return false;
        if(sz[a]<sz[b]) swap(a,b);
        parent[b]=a; sz[a]+=sz[b]; --components;
        return true;
    }
    int count() const { return components; }
};
复杂度
初始化 O(n)，m 次操作 O(m·α(n))，空间 O(n)。
易错点与边界
并查集擅长合并，不直接支持一般删边。代表元不一定是集合最小元素，不应把它当成有业务含义的标识。

经典考点与练习

练习：LeetCode 547 省份数量、684 冗余连接、990 等式方程的可满足性。

13.02

Trie：前缀与完整单词

知识与适用场景

Trie 的边表示字符，根到节点的路径表示前缀。路径存在只说明前缀存在，还需要 terminal 标记区分完整单词。固定小写字母可用 26 路数组。

推导 / 不变量

插入逐字符寻找或创建孩子，最后标记结束。查询完整单词需 terminal=true，查询前缀只需路径存在。使用节点下标避免手写释放指针。

手推一个例子

插入 "apple" 后，"app" 的路径存在，但 search("app") 为 false；再插入 "app" 后才变为 true。

C++17
下载 .cpp
class Trie {
    struct Node {
        array<int,26> next;
        bool terminal=false;
        Node(){ next.fill(-1); }
    };
    vector<Node> nodes{Node{}};
    static int letter(char c) {
        if(c<'a'||c>'z') throw invalid_argument("lowercase a-z only");
        return c-'a';
    }
    int walk(const string& s) const {
        int u=0;
        for(char c:s){
            int v=nodes[u].next[letter(c)];
            if(v==-1) return -1;
            u=v;
        }
        return u;
    }
public:
    void insert(const string& s){
        int u=0;
        for(char c:s){
            int k=letter(c);
            if(nodes[u].next[k]==-1){
                int v=(int)nodes.size();
                nodes.emplace_back();
                nodes[u].next[k]=v;
            }
            u=nodes[u].next[k];
        }
        nodes[u].terminal=true;
    }
    bool search(const string& s) const {
        int u=walk(s); return u!=-1 && nodes[u].terminal;
    }
    bool startsWith(const string& s) const { return walk(s)!=-1; }
};
复杂度
单次插入/查询 O(L)，最多 O(总字符数·字符集大小) 空间；本例字符集固定为 26。
易错点与边界
vector 扩容时元素引用失效，所以创建新节点前后不要持有 Node&。删除单词若要回收节点需维护经过计数或引用数量。

经典考点与练习

练习：LeetCode 208 实现 Trie、211 添加与搜索单词、212 单词搜索 II。

13.03

树状数组：动态前缀和

知识与适用场景

树状数组把前缀分成若干长度为 2 的幂的区间。tree[i] 管理 (i-lowbit(i),i]，使用 1 下标。前缀查询沿 i-=lowbit(i) 汇总；更新沿 i+=lowbit(i) 通知所有包含该点的区间。

推导 / 不变量

它适合单点加法与区间和。区间和 [l,r] 等于 prefix(r)-prefix(l-1)。若接口是赋值而非增量，需要保存旧数组计算 delta。

手推一个例子

查询 prefix(13)：13→12→8→0，对应区间 [13,13]、[9,12]、[1,8]，恰好不重不漏覆盖前 13 项。

C++17
下载 .cpp
class Fenwick {
    int n;
    vector<long long> bit;
public:
    explicit Fenwick(int size):n(size),bit(size+1,0){}
    void add(int i,long long delta){
        if(i<1||i>n) throw out_of_range("index");
        for(;i<=n;i+=i&-i) bit[i]+=delta;
    }
    long long prefix(int i) const {
        if(i<0||i>n) throw out_of_range("index");
        long long ans=0;
        for(;i>0;i-=i&-i) ans+=bit[i];
        return ans;
    }
    long long rangeSum(int l,int r) const {
        if(l<1||r>n||l>r) throw out_of_range("range");
        return prefix(r)-prefix(l-1);
    }
};
复杂度
单次更新、查询 O(log n)，空间 O(n)。逐项初始化 O(n log n)，也存在线性建树方法。
易错点与边界
add(0,delta) 会因 lowbit(0)=0 死循环，所以必须避免 0 下标更新。值域很大时先排序去重并离散化。

经典考点与练习

练习：LeetCode 307 区域和检索—数组可修改、315 计算右侧小于当前元素的个数。

13.04

线段树：可合并的区间信息

知识与适用场景

线段树把区间二分，父节点信息由两个孩子合并。sum 用加法，max 用最大值。相比树状数组，它支持更广泛的可结合运算，但实现更复杂。

推导 / 不变量

下面采用迭代线段树，叶子放在 [n,2n)。查询半开区间 [l,r)：若 l 是右孩子，则先纳入它再向右；若 r 是右边界，则先减一纳入左侧末节点，然后共同上移。

手推一个例子

数组 [2,1,3,4] 查询 [1,3) 得到 1+3=4。把下标 2 赋为 5 后，同一区间变为 6。

C++17
下载 .cpp
class SegmentTree {
    int n;
    vector<long long> tree;
public:
    explicit SegmentTree(const vector<int>& a):n((int)a.size()),tree(2*a.size(),0){
        for(int i=0;i<n;++i) tree[n+i]=a[i];
        for(int i=n-1;i>0;--i) tree[i]=tree[i*2]+tree[i*2+1];
    }
    void setValue(int p,long long value){
        if(p<0||p>=n) throw out_of_range("index");
        p+=n; tree[p]=value;
        for(p/=2;p>0;p/=2) tree[p]=tree[p*2]+tree[p*2+1];
    }
    long long query(int l,int r) const {
        if(l<0||r<l||r>n) throw out_of_range("range");
        long long ans=0;
        for(l+=n,r+=n;l<r;l/=2,r/=2){
            if(l&1) ans+=tree[l++];
            if(r&1) ans+=tree[--r];
        }
        return ans;
    }
};
复杂度
建树 O(n)，更新/查询 O(log(n+1))，空间 O(n)。
易错点与边界
本例只支持单点赋值。区间更新需懒标记：区间加 x 时节点和增加 x×区间长度，并保存待下传增量；赋值与加法混用时要特别定义标记组合顺序。

经典考点与练习

练习：LeetCode 307；进阶：区间加法与区间求和的懒标记线段树。
