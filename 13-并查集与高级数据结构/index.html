13.01

并查集：路径压缩与按大小合并

知识与适用场景

每个集合用一棵父指针树表示，根是代表元。find 找根，unite 连接两个根。路径压缩把沿途节点直接连到根；按大小合并让小树挂到大树上。

1.1 根节点是代表，不是图上的真正父亲

并查集的 parent 描述集合森林，不是原图的路径。find(x) 返回代表元；同根表示连通，不同根表示尚未连通。把一条原图边加入结构时，连接的是两个集合的根，而不是把任意一个端点的 parent 改掉，否则可能只挪走一个子树并破坏集合。

路径压缩可把沿路所有节点直接连到根，因为它只改变集合内部表示，不改变哪些节点属于同一集合。size 只在根上有权威含义，非根遗留的 size 不能当作整个集合大小。代表元依赖合并顺序，不一定是最小编号；若业务需要最小值，应作为额外聚合信息合并。

1.4 删除、离线与回滚的边界

只增边时，连通关系只会合并；删除一条边却可能把集合拆成两块，普通并查集没有保存足够的替代路径信息。若操作可离线，纯删边有时可倒序转成加边；加删混合时，可把每条边的有效时间段放入时间线段树，DFS 进入节点时合并、退出时回滚。

回滚日志恢复的是最近一段状态变化，不能撤销任意历史边又保留依赖它的后续合并。按大小合并且不压缩时，每次深度增加意味着所属集合至少翻倍，故树高 O(log n)；不能再宣称它与带路径压缩版本一样均摊 α(n)。

推导 / 不变量

只有根维护有效的集合大小。合并前先 find，若同根说明已连通，不应重复减少连通块数。两种优化一起使用时，均摊成本为反阿克曼函数 α(n)。

class UnionFind {
    vector<int> parent,sz;
    int components;
public:
    explicit UnionFind(int n):parent(n),sz(n,1),components(n) {
        iota(parent.begin(),parent.end(),0);
    }
    int find(int x) {
        if(parent[x]!=x) parent[x]=find(parent[x]);
        return parent[x];
    }
    bool unite(int a,int b) {
        a=find(a); b=find(b);
        if(a==b) return false;
        if(sz[a]<sz[b]) swap(a,b);
        parent[b]=a; sz[a]+=sz[b]; --components;
        return true;
    }
    int count() const { return components; }
};

class CheckedDSU {
    vector<int> parent, size;
    int groups = 0;
    void check(int x) const {
        if (x < 0 || x >= (int)parent.size()) throw out_of_range("vertex");
    }
public:
    explicit CheckedDSU(int n) {
        if (n < 0) throw invalid_argument("n");
        parent.resize(n); size.assign(n,1); groups = n;
        iota(parent.begin(),parent.end(),0);
    }
    int find(int x) {
        check(x);
        int root = x;
        while (parent[root] != root) root = parent[root];
        while (parent[x] != x) {
            int next = parent[x]; parent[x] = root; x = next;
        }
        return root;
    }
    bool unite(int a, int b) {
        check(a); check(b);
        a = find(a); b = find(b);
        if (a == b) return false;
        if (size[a] < size[b]) swap(a,b);
        parent[b] = a; size[a] += size[b]; --groups;
        return true;
    }
    bool connected(int a, int b) { check(a); check(b); return find(a) == find(b); }
    int componentSize(int x) { return size[find(x)]; }
    int count() const { return groups; }
};

1.6 动态添加陆地：重复添加不能重复计数

内部 −1 表示尚未激活的水格，不能把所有格子一开始都算作岛屿。每次只检查四邻居：同一岛屿可能从两个方向接触新格子，必须只在不同根时减一。初始化 O(RC)，q 次添加 O(q·α(RC))，空间 O(RC+q)。格子数上限是教学资源限制；超大稀疏网格可用坐标映射。

vector<int> islandCountsAfterAdds(int rows, int cols,
                                 const vector<pair<int,int>>& positions) {
    if (rows < 0 || cols < 0 || (long long)rows*cols > 1000000)
        throw invalid_argument("grid size");
    for (auto [r,c] : positions)
        if (r < 0 || r >= rows || c < 0 || c >= cols) throw out_of_range("cell");
    int n = rows*cols;
    vector<int> parent(n,-1), size(n,1), answer;
    auto find = [&](int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]]; x = parent[x];
        }
        return x;
    };
    int count = 0;
    const int dr[] = {-1,1,0,0}, dc[] = {0,0,-1,1};
    for (auto [r,c] : positions) {
        int id = r*cols+c;
        if (parent[id] == -1) {
            parent[id] = id; ++count;
            for (int k = 0; k < 4; ++k) {
                int nr = r+dr[k], nc = c+dc[k];
                if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) continue;
                int other = nr*cols+nc;
                if (parent[other] == -1) continue;
                int a = find(id), b = find(other);
                if (a == b) continue;
                if (size[a] < size[b]) swap(a,b);
                parent[b] = a; size[a] += size[b]; --count;
            }
        }
        answer.push_back(count);
    }
    return answer;
}

1.7 可回滚并查集：快照是日志位置

同根合并不写日志，因此 snapshot 不是操作次数。只能回到当前历史链上的有效快照；已被回滚丢弃的分支快照不可重用，数字检查不能识别这种语义错误。撤销 k 个成功合并 O(k)，find / unite 最坏 O(log n)，空间 O(n)，当前日志至多 n−1 项。

class RollbackDSU {
    struct Change { int child, root, oldSize; };
    vector<int> parent, size;
    vector<Change> history;
    int groups = 0;
    void check(int x) const {
        if (x < 0 || x >= (int)parent.size()) throw out_of_range("vertex");
    }
public:
    explicit RollbackDSU(int n) {
        if (n < 0) throw invalid_argument("n");
        parent.resize(n); size.assign(n,1); groups = n;
        iota(parent.begin(),parent.end(),0);
    }
    int find(int x) const {
        check(x);
        while (x != parent[x]) x = parent[x];
        return x;
    }
    size_t snapshot() const { return history.size(); }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;
        if (size[a] < size[b]) swap(a,b);
        history.push_back({b,a,size[a]});
        parent[b] = a; size[a] += size[b]; --groups;
        return true;
    }
    void rollback(size_t snap) {
        if (snap > history.size()) throw out_of_range("snapshot");
        while (history.size() > snap) {
            auto change = history.back(); history.pop_back();
            parent[change.child] = change.child;
            size[change.root] = change.oldSize; ++groups;
        }
    }
    int count() const { return groups; }
    int componentSize(int x) const { return size[find(x)]; }
};

面试追问：关键点完整解答

为什么合并前必须先 find？

只有根代表整个集合。直接令 parent[a]=b 可能把 a 所在集合的一部分搬走，而其他节点仍指向旧根。find 后连接两个根，才保证整个集合合并，且不会误连出父指针环。

路径压缩与按大小合并各解决什么？

按大小合并限制新形成树的深度，压缩利用查询把已有长路径变短。两者结合得到反阿克曼函数均摊界，不是每一次操作严格 O(1)。按秩中的秩在压缩后也不等于真实高度，不能随手重新计算它。

如何维护集合最小值、总和或大小？

把这些信息放在根上，每次成功合并时合并两个根的聚合值；查询时先找根。根编号本身不承担业务含义，路径压缩后也无需重算集合聚合值，因为集合成员没有改变。

冗余连接为何可用并查集，有向图也可以吗？

无向边的两端如果已经连通，新边加上已有路径就构成环。对有向图，忽略方向的连通不代表存在返回路径，例如 0→1、0→2、1→2 是 DAG。一般有向判环要用三色 DFS 或拓扑排序，不能直接套此条件。

等式与不等式约束为什么通常要分两轮？

先把全部等式合并，再检查每个不等式两端是否同根。若边读边只检查当前不等式，后面的等式可能让此前不同组的节点连起来，从而漏掉矛盾。相等传递可合并，不等关系不能直接合成一个“不同集合”。

回滚为什么不做路径压缩？

压缩会在每次 find 时改写沿途多个 parent，若要回滚都得额外记录，且复杂度分析更复杂。标准回滚模板用按大小合并控制高度，让一次成功 unite 只改固定几个字段，逆序恢复即可。

动态岛屿里一个格子接到同一个岛两次怎么办？

四邻接可能属于同一个集合。每次先 find，只有根不同才真正合并并减少岛数。重复添加已有陆地直接返回当前数量，不能增加岛数再依靠邻接合并修补。

13.02

Trie：前缀与完整单词

知识与适用场景

Trie 的边表示字符，根到节点的路径表示前缀。路径存在只说明前缀存在，还需要 terminal 标记区分完整单词。固定小写字母可用 26 路数组。

2.1 路径存在、单词结束、出现次数是三层语义

插入 apple 只保证 a、ap、app 等路径存在，不表示 app 是完整单词。布尔 terminal 足以表示集合；若要支持同一个词插入多次并逐次删除，就需要终点计数 end，以及经过每个节点的词频 pass。

本节计数 Trie 的 pass[u] 表示以根到 u 的字符串为前缀的当前单词总次数，重复词重复计算；end[u] 表示恰好等于该字符串的次数。根也参与 pass，表示所有词的总次数，根的 end 则统计空字符串。

2.4 vector 扩容陷阱与逻辑删除

不要写 Node& node=nodes[u] 后调用 nodes.emplace_back() 再使用 node，因为扩容可能让引用失效。保存整数下标，扩容完成后重新用 nodes[u] 访问即可。也不要让 int& child 指向数组元素并跨越扩容。

删除一个词前先确认终点 end>0，再沿整条路径减少计数。共享前缀仍被别的词使用，不能整条删掉。下面保留历史节点不回收，空间取决于历史累计创建的不同前缀，而不是当前仍存在的词数；查询必须看计数，不能只看 next 是否存在。

class Trie {
    struct Node {
        array<int,26> next;
        bool terminal=false;
        Node(){ next.fill(-1); }
    };
    vector<Node> nodes{Node{}};
    static int letter(char c) {
        if(c<'a'||c>'z') throw invalid_argument("lowercase a-z only");
        return c-'a';
    }
    int walk(const string& s) const {
        int u=0;
        for(char c:s){
            int v=nodes[u].next[letter(c)];
            if(v==-1) return -1;
            u=v;
        }
        return u;
    }
public:
    void insert(const string& s){
        int u=0;
        for(char c:s){
            int k=letter(c);
            if(nodes[u].next[k]==-1){
                int v=(int)nodes.size();
                nodes.emplace_back();
                nodes[u].next[k]=v;
            }
            u=nodes[u].next[k];
        }
        nodes[u].terminal=true;
    }
    bool search(const string& s) const {
        int u=walk(s); return u!=-1 && nodes[u].terminal;
    }
    bool startsWith(const string& s) const { return walk(s)!=-1; }
};

class CountingTrie {
    struct Node {
        array<int,26> next;
        long long pass = 0, end = 0;
        Node() { next.fill(-1); }
    };
    vector<Node> nodes{Node{}};
    static void validate(const string& s, bool wildcard = false) {
        for (char c : s)
            if (!(c >= 'a' && c <= 'z') && !(wildcard && c == '.'))
                throw invalid_argument("lowercase a-z, or dot in pattern");
    }
    int walk(const string& s) const {
        int u = 0;
        for (char c : s) {
            u = nodes[u].next[c-'a'];
            if (u == -1) return -1;
        }
        return u;
    }
public:
    void insert(const string& word) {
        validate(word);
        if (nodes[0].pass == LLONG_MAX) throw overflow_error("word count");
        vector<int> path{0}; int u = 0;
        for (char c : word) {
            int k = c-'a';
            if (nodes[u].next[k] == -1) {
                int v = (int)nodes.size(); nodes.emplace_back();
                nodes[u].next[k] = v;
            }
            u = nodes[u].next[k]; path.push_back(u);
        }
        for (int v : path) ++nodes[v].pass;
        ++nodes[u].end;
    }
    long long countWord(const string& word) const {
        validate(word); int u = walk(word);
        return u == -1 ? 0 : nodes[u].end;
    }
    long long countPrefix(const string& prefix) const {
        validate(prefix); int u = walk(prefix);
        return u == -1 ? 0 : nodes[u].pass;
    }
    bool eraseOne(const string& word) {
        validate(word);
        int u = walk(word);
        if (u == -1 || nodes[u].end == 0) return false;
        --nodes[u].end;
        u = 0; --nodes[u].pass;
        for (char c : word) { u = nodes[u].next[c-'a']; --nodes[u].pass; }
        return true;
    }
    bool matches(const string& pattern) const {
        validate(pattern,true);
        vector<pair<int,size_t>> stack{{0,0}};
        while (!stack.empty()) {
            auto [u,pos] = stack.back(); stack.pop_back();
            if (nodes[u].pass == 0) continue;
            if (pos == pattern.size()) {
                if (nodes[u].end > 0) return true;
                continue;
            }
            if (pattern[pos] == '.') {
                for (int v : nodes[u].next)
                    if (v != -1 && nodes[v].pass > 0) stack.push_back({v,pos+1});
            } else {
                int v = nodes[u].next[pattern[pos]-'a'];
                if (v != -1) stack.push_back({v,pos+1});
            }
        }
        return false;
    }
};

2.6 二进制 Trie：最高位优先最大化异或值

返回 x 与已插入数的最大无符号异或值，不是对应元素本身。高位的 1 大于全部低位可能贡献之和，因此能选相反位就优先选；所有路径固定 32 位，包括前导零。空树返回 nullopt，重复插入不影响最大值，本接口不支持删除。空间 O(32n)，操作 O(32)。

class BinaryTrie32 {
    struct Node { array<int,2> next{{-1,-1}}; };
    vector<Node> nodes{Node{}};
    bool nonempty = false;
public:
    void insert(uint32_t x) {
        int u = 0;
        for (int bit = 31; bit >= 0; --bit) {
            int b = (x >> bit) & 1U;
            if (nodes[u].next[b] == -1) {
                int v = (int)nodes.size(); nodes.emplace_back();
                nodes[u].next[b] = v;
            }
            u = nodes[u].next[b];
        }
        nonempty = true;
    }
    optional<uint32_t> maxXor(uint32_t x) const {
        if (!nonempty) return nullopt;
        int u = 0; uint32_t answer = 0;
        for (int bit = 31; bit >= 0; --bit) {
            int b = (x >> bit) & 1U;
            if (nodes[u].next[b^1] != -1) {
                answer |= uint32_t(1) << bit; u = nodes[u].next[b^1];
            } else u = nodes[u].next[b];
        }
        return answer;
    }
};

面试追问：关键点完整解答

前缀 app 存在为何不等于单词 app 存在？

存在 apple 的路径就会有 app 节点，但只有在 app 节点标记终点或 end>0，才表示词典确实包含 app。前缀查询与完整词查询是两个接口，不能复用同一个判断条件。

计数 Trie 删除一个不存在的词会怎样？

应返回 false，且任何 pass、end 都不变。必须先走到完整词终点并确认 end>0，再做减少；不能边走边减，走到一半才发现不存在，否则会破坏其他词的前缀计数。

空字符串和空前缀如何定义？

空词对应根的 end，只有插入过才存在。计数接口 countPrefix("") 返回所有当前单词次数；如果词典为空则为 0。基础 startsWith("") 仅问根路径是否存在，通常仍为 true；两者语义不同，需按接口说明使用。

为什么有 k 个点号不能简单声明 O(L)？

一个点号可能扩展到 26 个孩子，多个点号可能产生大量分支。上界受 26^k、模式长度和实际已创建前缀数共同限制，通常表述为访问到的节点数乘固定字符集常数。实际只有少量有效分支时才会快。

Trie 查询一定比哈希表查完整单词更好吗？

不一定。哈希表也常能平均 O(L) 处理一个词，且空间常数可能更小。Trie 的优势是共享前缀、逐字符过滤、前缀计数和通配分支等结构性操作；固定 26 路数组在前缀稀疏时会浪费大量空指针槽。

最大异或为什么必须先看高位？

无符号数的第 b 位贡献是 2^b，而所有更低位的最大总和只有 2^b−1；只要能在当前位获得 1，就不该为低位机会牺牲它。这是严格的位权支配论证，不是随意局部选择。

删除后节点不释放，会导致查询错误吗？

只要查询依据 pass/end 的当前计数而非仅依据旧路径存在，就不会误认已删除词。但内存不会随删除下降，长期动态词典若需回收，应维护空子树并谨慎复用节点；共享前缀不能被误删。

树状数组：动态前缀和

知识与适用场景

树状数组把前缀分成若干长度为 2 的幂的区间。tree[i] 管理 (i-lowbit(i),i]，使用 1 下标。前缀查询沿 i-=lowbit(i) 汇总；更新沿 i+=lowbit(i) 通知所有包含该点的区间。

3.1 lowbit 不是魔法，它给出节点覆盖的长度

正整数 i 的 lowbit(i)=i&(-i)，保留最低的一个 1。内部节点 bit[i] 表示原数组的一基闭区间 [i−lowbit(i)+1,i] 的和。查询不断减 lowbit，将一个前缀拆成互不重叠的块；更新不断加 lowbit，沿包含该单点的祖先块传播。

例如 i=12（二进制 1100）时 lowbit=4，负责 [9,12]；i=8 负责 [1,8]。0 没有最低置位，lowbit(0)=0，所以更新从 0 出发不会推进。补充接口将外部 p 转成 p+1，避免让调用者记两种下标。

3.4 离散化与第 K 小，各自依赖什么？

排序去重后用排名替代原值，保留大小关系与相等关系，但不保留数值距离。扫描数组右侧已插入的频率，查询 rank(x) 之前的前缀，就得到严格小于 x 的数量；查询到 rank(x) 则会错误包含相等值。

频率非负时，累计频率单调，第 K 小可看成最小下标 p，使 prefix(p+1)≥K。用二分外加前缀查询是 O(log²n)，直接沿 Fenwick 节点倍增查找可到 O(log n)。若频率允许负数，累计值不单调，这种查找不再有保证。

推导 / 不变量

它适合单点加法与区间和。区间和 [l,r] 等于 prefix(r)-prefix(l-1)。若接口是赋值而非增量，需要保存旧数组计算 delta。

class Fenwick {
    int n;
    vector<long long> bit;
public:
    explicit Fenwick(int size):n(size),bit(size+1,0){}
    void add(int i,long long delta){
        if(i<1||i>n) throw out_of_range("index");
        for(;i<=n;i+=i&-i) bit[i]+=delta;
    }
    long long prefix(int i) const {
        if(i<0||i>n) throw out_of_range("index");
        long long ans=0;
        for(;i>0;i-=i&-i) ans+=bit[i];
        return ans;
    }
    long long rangeSum(int l,int r) const {
        if(l<1||r>n||l>r) throw out_of_range("range");
        return prefix(r)-prefix(l-1);
    }
};

class FenwickZero {
    int n;
    vector<long long> bit;
public:
    explicit FenwickZero(const vector<long long>& a): n((int)a.size()) {
        if (a.size() > 1000000) throw invalid_argument("size limit");
        bit.assign(n+1,0);
        for (int i = 1; i <= n; ++i) {
            bit[i] += a[i-1];
            int parent = i+(i&-i);
            if (parent <= n) bit[parent] += bit[i];
        }
    }
    void add(int p, long long delta) {
        if (p < 0 || p >= n) throw out_of_range("index");
        for (int i = p+1; i <= n; i += i&-i) bit[i] += delta;
    }
    long long prefix(int r) const {
        if (r < 0 || r > n) throw out_of_range("prefix");
        long long result = 0;
        for (int i = r; i > 0; i -= i&-i) result += bit[i];
        return result;
    }
    long long rangeSum(int l, int r) const {
        if (l < 0 || r < l || r > n) throw out_of_range("range");
        return prefix(r)-prefix(l);
    }
    void setValue(int p, long long value) {
        if (p < 0 || p >= n) throw out_of_range("index");
        add(p,value-rangeSum(p,p+1));
    }
};

        addBit(first,p,delta); addBit(second,p,delta*(p-1));

class FrequencyFenwick {
    int n;
    vector<long long> bit, frequency;
    long long total = 0;
public:
    explicit FrequencyFenwick(int size): n(size) {
        if (n < 0 || n > 1000000) throw invalid_argument("size");
        bit.assign(n+1,0); frequency.assign(n,0);
    }
    void add(int p, long long delta) {
        if (p < 0 || p >= n) throw out_of_range("index");
        if (delta < 0 && delta < -frequency[p]) throw invalid_argument("negative frequency");
        if (delta > 0 && total > LLONG_MAX-delta) throw overflow_error("total");
        frequency[p] += delta; total += delta;
        for (int i = p+1; i <= n; i += i&-i) bit[i] += delta;
    }
    optional<int> kth(long long k) const {
        if (k < 1 || k > total) return nullopt;
        int index = 0, step = 1;
        while (step <= n/2) step *= 2;
        for (; step > 0; step /= 2) {
            int next = index+step;
            if (next <= n && bit[next] < k) {
                index = next; k -= bit[next];
            }
        }
        return index; // 已跳过 index 项，下一个一基位置对应零基 index
    }
    long long count() const { return total; }
};

面试追问：关键点完整解答

普通前缀和为什么不适合频繁修改？

修改 a[p] 后，所有终点大于 p 的前缀都改变，显式前缀数组可能要更新 O(n) 项。树状数组只维护按二进制分块的摘要，一次修改影响 O(log n) 个块；查询也用 O(log n) 个块拼起来。

树状数组能否直接把加法换成 min，仍做任意区间查询？

不能用 prefixMin(r)−prefixMin(l) 得到区间最小值，min 没有这种可逆性。某些单调更新的前缀 min 可以用专门 Fenwick 变式，但不等于支持任意赋值和任意区间 min；通常改用线段树。

离散化是否保留两点之间的真实距离？

不保留。10、1000、1001 可能变成排名 1、2、3，排名差相等而真实差不同。排名适合顺序、频率和比较；若计算坐标长度、面积或带权间隔，应另外保留原始坐标。

逆序对为何查询 rank−1，而不是 rank？

定义是严格大于或严格小于，相等不算逆序。右向左扫描时，prefix(rank−1) 只统计右侧更小值；prefix(rank) 会把相等值也算进去。重复元素多的用例最容易暴露这个错误。

双树状数组的第二棵树为什么乘 i−1？

一个差分 D[i] 会出现在前 x 项总和里的第 i 到 x 项，共 x−i+1 次。展开成 x·D[i]−(i−1)·D[i] 后，就需要分别累计 D[i] 和 (i−1)D[i]。公式来自累加次数，不能只记两个数组名称。

第 K 小为什么需要非负频率？

非负频率使前缀累计单调，可以根据一整块和判断目标在块内还是块后。负频率会造成跨过阈值后又跌回去，二分和倍增的排除判断失效。结构因此禁止减成负频率，不是任意数值前缀树都支持 kth。

赋值操作为什么不能直接 add(p,newValue)？

add 的语义是增量，直接传新值会在旧值上再次累加。应算 delta=newValue−oldValue，然后更新；oldValue 可从保存的原数组读取，或用单点区间和得到。

13.04

线段树：可合并的区间信息

知识与适用场景

线段树把区间二分，父节点信息由两个孩子合并。sum 用加法，max 用最大值。相比树状数组，它支持更广泛的可结合运算，但实现更复杂。

4.1 线段树存的是能合并的区间摘要

父区间由左区间和右区间组成，要求摘要有一个结合的合并操作：merge(merge(A,B),C)=merge(A,merge(B,C))。加法、最小值、最大值满足；字符串拼接也满足结合律，但不满足交换律，因此左右顺序不能颠倒。

空区间需要正确的单位元：和为 0，最小值可用正无穷或显式空值，字符串为空串。最大非空子数组不能直接用 0 当所有摘要的初值，否则全负区间会被错误地允许选空段。后面的实现用 empty 标记隔离空摘要。

4.2 最大子数组区间摘要：一个 best 不够

跨中点的最优段必须由左后缀加右前缀组成；仅保存左右各自 best 无法计算跨界结果。这与第九章的分治摘要一致，只是现在把它组织成支持更新和查询的树。

4.3 懒标记是延迟通知孩子，不是延迟更新本节点

一个完全覆盖的区间加 d，当前节点 sum 立即增加 d·len，同时记下对孩子尚未执行的增量。不继续下探，才把一段很多元素的修改压成 O(log n) 个块。部分覆盖查询或更新前，先把标记按正确次序传给孩子，再继续递归。

若误以为 sum 也要等下传才更新，整段查询会返回旧值；若 sum 已更新却在下传时又重复加到父节点，会双重计数。下传只修改孩子并清空父标记，父节点 sum 本来已经正确。

4.5 静态查询与稀疏表

如果数组建好后从不修改，而且操作是 min/max/gcd 这样的幂等运算，稀疏表可预处理长度为 2 的幂的区间。任意查询取左右两块，块可以重叠，因为 min(x,x)=x；这样查询是 O(1)。

求和不具幂等性，重叠会重复计数，不能照抄“两块 O(1)”公式。静态区间和直接前缀和更简单；有修改需求则重新选择 Fenwick 或线段树，不要把预处理结构伪装成动态结构。

class SegmentTree {
    int n;
    vector<long long> tree;
public:
    explicit SegmentTree(const vector<int>& a):n((int)a.size()),tree(2*a.size(),0){
        for(int i=0;i<n;++i) tree[n+i]=a[i];
        for(int i=n-1;i>0;--i) tree[i]=tree[i*2]+tree[i*2+1];
    }
    void setValue(int p,long long value){
        if(p<0||p>=n) throw out_of_range("index");
        p+=n; tree[p]=value;
        for(p/=2;p>0;p/=2) tree[p]=tree[p*2]+tree[p*2+1];
    }
    long long query(int l,int r) const {
        if(l<0||r<l||r>n) throw out_of_range("range");
        long long ans=0;
        for(l+=n,r+=n;l<r;l/=2,r/=2){
            if(l&1) ans+=tree[l++];
            if(r&1) ans+=tree[--r];
        }
        return ans;
    }
};

class LazyRangeSum {
    struct Node {
        long long sum = 0, setValue = 0, addValue = 0;
        bool hasSet = false;
    };
    int n;
    vector<Node> tree;
    void pull(int p) { tree[p].sum = tree[p*2].sum+tree[p*2+1].sum; }
    void applySet(int p, int len, long long value) {
        tree[p].sum = value*len;
        tree[p].hasSet = true; tree[p].setValue = value; tree[p].addValue = 0;
    }
    void applyAdd(int p, int len, long long delta) {
        tree[p].sum += delta*len;
        if (tree[p].hasSet) tree[p].setValue += delta;
        else tree[p].addValue += delta;
    }
    void push(int p, int l, int r) {
        if (r-l == 1) return;
        int mid = l+(r-l)/2;
        if (tree[p].hasSet) {
            applySet(p*2,mid-l,tree[p].setValue);
            applySet(p*2+1,r-mid,tree[p].setValue);
            tree[p].hasSet = false;
        }
        if (tree[p].addValue != 0) {
            applyAdd(p*2,mid-l,tree[p].addValue);
            applyAdd(p*2+1,r-mid,tree[p].addValue);
            tree[p].addValue = 0;
        }
    }
    void build(int p, int l, int r, const vector<long long>& a) {
        if (r-l == 1) { tree[p].sum = a[l]; return; }
        int mid = l+(r-l)/2;
        build(p*2,l,mid,a); build(p*2+1,mid,r,a); pull(p);
    }
    void update(int p, int l, int r, int ql, int qr, long long x, bool assign) {
        if (ql <= l && r <= qr) {
            if (assign) applySet(p,r-l,x); else applyAdd(p,r-l,x);
            return;
        }
        push(p,l,r); int mid = l+(r-l)/2;
        if (ql < mid) update(p*2,l,mid,ql,qr,x,assign);
        if (qr > mid) update(p*2+1,mid,r,ql,qr,x,assign);
        pull(p);
    }
    long long query(int p, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tree[p].sum;
        push(p,l,r); int mid = l+(r-l)/2; long long answer = 0;
        if (ql < mid) answer += query(p*2,l,mid,ql,qr);
        if (qr > mid) answer += query(p*2+1,mid,r,ql,qr);
        return answer;
    }
    void check(int l, int r) const {
        if (l < 0 || r < l || r > n) throw out_of_range("range");
    }
public:
    explicit LazyRangeSum(const vector<long long>& a): n((int)a.size()) {
        if (a.size() > 1000000) throw invalid_argument("size limit");
        tree.resize(max(1,4*n));
        if (n) build(1,0,n,a);
    }
    void add(int l, int r, long long delta) {
        check(l,r); if (l < r) update(1,0,n,l,r,delta,false);
    }
    void assign(int l, int r, long long value) {
        check(l,r); if (l < r) update(1,0,n,l,r,value,true);
    }
    long long sum(int l, int r) {
        check(l,r); return l == r ? 0 : query(1,0,n,l,r);
    }
};

4.7 非交换摘要：动态区间最大非空子数组和

class MaxSubarrayTree {
    struct Info {
        bool empty = true;
        long long sum = 0, prefix = 0, suffix = 0, best = 0;
    };
    int n, base = 1;
    vector<Info> tree;
    static Info single(long long x) { return {false,x,x,x,x}; }
    static Info merge(const Info& left, const Info& right) {
        if (left.empty) return right;
        if (right.empty) return left;
        return {false,left.sum+right.sum,
            max(left.prefix,left.sum+right.prefix),
            max(right.suffix,right.sum+left.suffix),
            max({left.best,right.best,left.suffix+right.prefix})};
    }
public:
    explicit MaxSubarrayTree(const vector<int>& a): n((int)a.size()) {
        if (a.size() > 1000000) throw invalid_argument("size limit");
        while (base < n) base *= 2;
        tree.resize(2*base);
        for (int i = 0; i < n; ++i) tree[base+i] = single(a[i]);
        for (int p = base-1; p > 0; --p) tree[p] = merge(tree[p*2],tree[p*2+1]);
    }
    void setValue(int index, int value) {
        if (index < 0 || index >= n) throw out_of_range("index");
        int p = base+index; tree[p] = single(value);
        for (p /= 2; p > 0; p /= 2) tree[p] = merge(tree[p*2],tree[p*2+1]);
    }
    optional<long long> best(int l, int r) const {
        if (l < 0 || r < l || r > n) throw out_of_range("range");
        Info left, right;
        for (l += base,r += base; l < r; l /= 2,r /= 2) {
            if (l&1) left = merge(left,tree[l++]);
            if (r&1) right = merge(tree[--r],right);
        }
        Info result = merge(left,right);
        if (result.empty) return nullopt;
        return result.best;
    }
};

4.8 静态 RMQ：稀疏表的重叠块为什么合法

class SparseMinimum {
    int n;
    vector<int> logs;
    vector<vector<int>> table;
public:
    explicit SparseMinimum(const vector<int>& a): n((int)a.size()) {
        if (a.size() > 1000000) throw invalid_argument("size limit");
        logs.assign(n+1,0);
        for (int i = 2; i <= n; ++i) logs[i] = logs[i/2]+1;
        if (!n) return;
        table.push_back(a);
        for (int k = 1; k <= logs[n]; ++k) {
            int length = 1 << k, half = length/2;
            table.push_back(vector<int>(n-length+1));
            for (int i = 0; i+length <= n; ++i)
                table[k][i] = min(table[k-1][i],table[k-1][i+half]);
        }
    }
    optional<int> minimum(int l, int r) const {
        if (l < 0 || r < l || r > n) throw out_of_range("range");
        if (l == r) return nullopt;
        int k = logs[r-l], length = 1 << k;
        return min(table[k][l],table[k][r-length]);
    }
};

面试追问：关键点完整解答

线段树只要求结合律，为什么查询还要关心左右顺序？

结合律只允许改变括号，不允许交换元素。例如字符串 ab 与 cd 拼接不能随意变成 cdab。迭代查询从右边取出的块是从右向左出现，所以应前插到 right；左侧取出的块则后接到 left。

区间加 d 为什么 sum 加 d×长度，而不是只加 d？

节点代表 len 个元素，每个都加 d，总和变化就是 d·len。若维护的是 max/min，整段统一加 d 才是摘要直接加 d；更新规则由摘要语义决定，不能通用套一行。

为什么赋值标记不能用 0 表示没有？

赋成 0 是完全合法的操作。如果把 setValue==0 当无标记，后续部分查询就读到尚未清零的孩子。必须额外用 hasSet，或用 optional 等方式区分“无赋值”与“赋成零”。

先加 3 再赋值 2，与先赋值 2 再加 3 一样吗？

不一样，前者最终全是 2，后者全是 5。新赋值覆盖旧加法；新加法则要叠到旧赋值后面。懒标记是函数复合，顺序是旧操作先执行、新操作后执行。

做部分更新前忘了 push，会出什么错？

父节点可能已经逻辑上给整段赋值，但孩子仍保存旧数据。直接进入孩子局部修改，再 pull 父节点，会把未下传的整段更新丢掉。只有完整覆盖时可以直接改父节点，不触碰孩子。

最大子数组摘要为什么不能只保存 best？

跨左右边界的最优子数组需要知道左边能提供的最大后缀与右边最大前缀，而它们可能不是各自内部 best。sum 又用于合成更大前缀和后缀。四项共同构成对外足够的信息。

稀疏表为何能重叠查询 min，却不能用同一方式求和？

min、max、gcd 对重复输入幂等，重叠部分算两次也不改变结果；sum 重复会多计。比如 3 个数用两个长度 2 的块求和，中间元素被加两次。静态和用前缀和，不能盲目替换运算符。

回滚并查集与可持久化数据结构有什么区别？

回滚是沿当前修改栈撤销，通常按 DFS 顺序访问历史；可持久化允许多个版本同时存在并查询。这里的日志快照不是一个永久不可变版本对象，已丢弃分支的数字不能继续充当有效历史。

在数据结构里缓存摘要，怎样知道信息够不够？

尝试只用两个子区间摘要推导父区间结果，并检查所有可能跨界的情况。最大子数组的跨界答案需要左后缀和右前缀，所以只有 best 不够。若无法由摘要得出更新后的结果，也可能不能直接支持懒更新。

为何同一份随机操作必须与朴素模型逐步比较？

只比较最后一次结果可能让中间错误相互抵消。应在每次加、赋值、删除或回滚后，比较连通性、词频或全部小范围查询；再用定向用例覆盖赋值为零、重复元素、过期节点和非法 k。

算法复杂度中的平均、均摊和最坏能否互换？

不能。并查集 α(n) 是整段操作序列的均摊界；哈希通常说平均复杂度；回滚并查集按大小但不压缩可给单次 O(log n) 最坏界。Trie 通配符还依赖分支数。应写出所用实现和假设，而不是一律称近似常数。
