# 第 13 章：并查集与高级数据结构

## 并查集（Union-Find）

用于动态维护若干不相交集合，支持：

- `find(x)`：查找元素所在集合的代表元。
- `union(a,b)`：合并两个集合。
- `connected(a,b)`：判断是否属于同一集合。

路径压缩 + 按秩/按大小合并后，单次操作的均摊复杂度接近 `O(1)`。

```text
find(x):
    if parent[x] != x:
        parent[x] = find(parent[x])
    return parent[x]
```

应用：无向图连通性、冗余连接、岛屿合并、Kruskal 最小生成树、等式可满足性。

## Trie（前缀树）

- 每条根到节点的路径表示一个前缀，节点保存子节点映射和结束标记。
- 插入、查询、前缀判断复杂度均为 `O(L)`，`L` 为字符串长度。
- 字符集固定且较小时可用数组保存孩子；字符集大时用哈希映射节省空间。
- 应用：前缀搜索、自动补全、词典匹配、异或最大值的二进制 Trie。

## 树状数组（Fenwick Tree）

- 支持单点更新与前缀和查询，均为 `O(log n)`，空间 `O(n)`。
- 核心是 `lowbit(x)=x&(-x)`。
- 可通过两个前缀和相减得到区间和。
- 适合结构较简单的动态前缀统计，如逆序对、频率累计。

## 线段树

- 支持区间查询与单点更新，均为 `O(log n)`。
- 配合懒标记可支持区间更新；下传标记时必须正确合并。
- 节点保存的信息可以是和、最大值、最小值或更复杂的可合并结构。
- 相比树状数组更通用，但代码量更大、边界更易错。

## 何时使用

| 需求 | 数据结构 |
| --- | --- |
| 动态连通性 | 并查集 |
| 前缀字符串查询 | Trie |
| 单点更新 + 前缀/区间和 | 树状数组 |
| 多种区间查询/区间更新 | 线段树 |

## 易错点与自测

- [ ] 并查集合并的是根节点，不是直接修改任意节点父亲。
- [ ] Trie 区分“某前缀存在”和“完整单词存在”。
- [ ] 树状数组通常使用 1 下标，避免 `lowbit(0)` 导致死循环。
- [ ] 线段树的区间定义和懒标记组合规则始终一致。
- [ ] 能手写并查集，并知道其适用边界。
