## 手撕代码的推荐表达顺序

1. **确认题意**：输入规模、数据范围、是否有序、能否修改、返回值要求。
2. **举例推演**：用一个小样例说明理解一致。
3. **给出基线**：说明暴力解法及瓶颈。
4. **提出优化**：指出利用了什么性质，为什么选择该数据结构。
5. **声明不变量**：窗口、指针、递归函数或 DP 状态始终代表什么。
6. **编码**：边写边保持命名与结构清晰，不必逐字符朗读。
7. **测试**：正常、边界、反例各至少一个。
8. **复杂度**：准确说明时间和额外空间，包含递归栈。

## 常见扣分点

- 没确认题意就直接套模板。
- 只会说最优解，无法给出从暴力到优化的过程。
- 写完不测，靠编译器或面试官指出越界。
- 复杂度分析漏掉排序、哈希存储或递归栈。
- 变量名含糊，修改指针前未保存后继。
- 卡住后长时间沉默，不主动说明当前障碍和备选方向。

## 四周训练计划

### 第 1 周：基础结构与模板

- 数组/字符串、链表、栈队列、哈希、二分。
- 每天 3 题：2 道基础模板 + 1 道变式。
- 目标：核心模板能在 10 分钟内无提示写出。

### 第 2 周：树、堆、回溯、图

- 每天一个主题，先口述递归定义或图搜索状态再编码。
- 加入 1 次 45 分钟模拟面试。
- 目标：能处理遍历、Top K、排列组合、BFS/DFS 与拓扑排序。

### 第 3 周：贪心与动态规划

- 重点练习从暴力递归提炼状态、转移与遍历顺序。
- 每道贪心题尝试写出证明或反例。
- 目标：能独立完成线性 DP、背包、LCS、区间类基础题。

### 第 4 周：综合与限时模拟

- 按真实面试混合抽题，不提前知道类别。
- 每两天一次 45～60 分钟模拟，结束后立即复盘。
- 重做错题而不是盲目增加新题量。
- 目标：表达、编码、测试和复杂度分析形成稳定流程。

## 每日训练建议（约 2 小时）

- 15 分钟：默写一个模板。
- 60 分钟：限时完成 2～3 题。
- 25 分钟：重写当天最卡的一题。
- 20 分钟：整理题型信号、错误原因与边界用例。

## 模拟面试自评表

每项 0～2 分，总分 20 分：

| 项目 | 评分关注点 |
| --- | --- |
| 题意确认 | 是否主动确认约束和边界 |
| 思路推导 | 是否从基线自然推到优化 |
| 正确性 | 是否说明不变量或转移依据 |
| 代码结构 | 命名、模块化、可读性 |
| 边界处理 | 空值、重复、溢出、越界 |
| 测试能力 | 是否主动手推多类用例 |
| 复杂度 | 时间、空间是否准确 |
| 沟通 | 是否持续同步思考过程 |
| 纠错 | 发现问题后能否快速定位 |
| 熟练度 | 是否在合理时间内完成 |
