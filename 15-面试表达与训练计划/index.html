15.01

一场 40 分钟手撕的节奏

知识与适用场景

前 3 分钟确认题意和样例；接着约 7 分钟从暴力推到优化并说清不变量；约 20 分钟完成代码；剩余时间用于测试、复杂度和追问。时间仅作为训练参照，应随题目难度调整。

推导 / 不变量

以有序数组两数之和为例：先确认是否返回原下标、是否存在解、是否允许同一元素使用两次，然后解释相向双指针的排除依据，再编码。

手推一个例子

口述示例：数组已排序。若两端之和偏小，固定左端并减小右端只会更小，所以当前左端不可能参与答案，可以安全丢弃。

C++17
下载 .cpp
pair<int,int> twoSumSorted(const vector<int>& a,long long target){
    int l=0,r=(int)a.size()-1;
    while(l<r){
        long long sum=(long long)a[l]+a[r];
        if(sum==target) return {l,r};
        if(sum<target) ++l;
        else --r;
    }
    return {-1,-1};
}
复杂度
时间 O(n)，空间 O(1)，输入为非降序；返回 0 下标，无解返回 {-1,-1}。
易错点与边界
不要在代码写完后才发现题目要求 1 下标或多个解。卡住时说明已验证的性质和具体障碍，而不是无声地重复试代码。

经典考点与练习

训练：录音完成一次从澄清到复杂度的 5 分钟口述；检查是否明确了排序、重复值和下标约定。

面试官可能继续问什么？

如果数组未排序但要求原下标，怎么改？如果需要返回所有不同值对呢？

15.02

边界测试与反例设计

知识与适用场景

测试应覆盖结构边界和算法前提。二分测空数组、首尾命中、重复值、全部小于或大于目标；链表测空、单节点、头部删除；DP 测不可达、全负、零容量。

推导 / 不变量

使用已知答案的 assert 进行小规模回归。为了验证最优算法，可以为随机小输入写暴力基线做差分测试：两者不一致时输出原输入，而不是继续运行掩盖错误。

手推一个例子

最大子数组和若全负 [-5,-2,-9]，正确答案是 -2。这个用例能直接发现把 best 初始化为 0 的错误。

C++17
下载 .cpp
long long kadane(const vector<int>& a){
    if(a.empty()) throw invalid_argument("nonempty required");
    long long cur=a[0],ans=a[0];
    for(int i=1;i<(int)a.size();++i){
        cur=max((long long)a[i],cur+a[i]); ans=max(ans,cur);
    }
    return ans;
}
int main(){
    assert(kadane({-5,-2,-9})==-2);
    assert(kadane({0})==0);
    assert(kadane({4,-1,2,1})==6);
    assert(kadane({-2,1,-3,4,-1,2,1,-5,4})==6);
    cout<<"all checks passed\n";
}
复杂度
每个测试调用 O(n)，测试总成本取决于用例规模。差分测试只用于小输入，不把指数暴力放进正式提交。
易错点与边界
assert 在定义 NDEBUG 时会被禁用。随机测试不能替代正确性证明；没有触发 bug 不代表算法一定正确。

经典考点与练习

训练：每题至少写一个正常用例、一个边界用例、一个针对核心假设的反例。

面试官可能继续问什么？

哪一个最小反例能打破你最初的贪心？哪种输入会让当前算法退化？

先用自己的话回答，再回到本节的前提、不变量和边界检查论证。

15.03

C++ 标准库、比较器与编码习惯

知识与适用场景

面试中优先使用标准库表达已掌握的结构，但需要能解释复杂度和语义。比较器必须满足严格弱序：相等对象比较应为 false，不能用 <= 替代 <。

推导 / 不变量

多关键字排序先比主关键字，再比较次关键字。避免用 a.score-b.score 判断大小，因为差值可能溢出。const 引用避免比较过程中复制大型对象。

手推一个例子

按成绩降序、同分按名字升序排列：90 分的 Alice 应排在 90 分的 Bob 前面，二者都在 80 分记录之前。

C++17
下载 .cpp
struct Student { string name; int score; };
void sortStudents(vector<Student>& students){
    sort(students.begin(),students.end(),
         [](const Student& a,const Student& b){
             if(a.score!=b.score) return a.score>b.score;
             return a.name<b.name;
         });
}
long long sumValues(const vector<int>& a){
    return accumulate(a.begin(),a.end(),0LL);
}
复杂度
排序 O(n log n) 次比较；字符串比较还取决于公共前缀长度。求和 O(n)，额外空间 O(1)。
易错点与边界
range-for 按 auto x 复制元素，auto& x 才能修改原元素。vector::reserve 只预留容量，不改变 size；下标访问仍要求 index<size。

经典考点与练习

训练：从空文件写出常用头文件、输入输出、vector、哈希、小顶堆和自定义排序。

lambda 捕获引用的对象能否在它销毁后继续访问？sort 与 stable_sort 何时选择？

15.04

四周计划、错题复盘与掌握标准

知识与适用场景

第一周学习复杂度、数组、链表、栈队列、哈希、二分；第二周学习树、堆、回溯、图；第三周重点练贪心与 DP；第四周混合抽题和设计题，做限时模拟。高级结构按岗位和时间补充，不挤占基础训练。

推导 / 不变量

每天约两小时：15 分钟默写模板，60 分钟独立做题，25 分钟重写卡住题，20 分钟复盘。第 1、3、7 天重做错题；连续两次独立完成并能解释证明，才标记为掌握。

手推一个例子

复盘示例：不是“二分不会”，而是“把 [l,r) 与闭区间更新混用，导致单元素死循环”；下一次练习目标就是在编码前写出区间不变量。

// 小规模暴力基线：用于核对最大子数组和优化实现。
long long bruteMaxSubArray(const vector<int>& a){
    if(a.empty()) throw invalid_argument("nonempty required");
    long long best=LLONG_MIN;
    for(int l=0;l<(int)a.size();++l){
        long long sum=0;
        for(int r=l;r<(int)a.size();++r){
            sum+=a[r]; best=max(best,sum);
        }
    }
    return best;
}
复杂度
暴力基线 O(n²) 时间、O(1) 空间。与上一节 O(n) 实现对照，可以用很短随机数组快速定位反例。
易错点与边界
题量不能替代迁移能力。复盘记录：识别信号、暴力瓶颈、不变量/状态、失败用例、修正原因、下次复习日期。

经典考点与练习

毕业练习：每次随机抽一道数组/树题和一道 DP/图题，完成 45–60 分钟模拟，再分别给正确性、编码、表达、测试打分。
