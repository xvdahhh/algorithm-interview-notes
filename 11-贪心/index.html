本章目标：写出选择规则，也写出不丢最优解的理由

贪心不是“排序后扫一遍”的同义词。它是只保留当前选定的决策，永久放弃其他候选，因此必须证明至少存在一个最优解与这个选择一致。识别到最大数量、最少成本等词语，只是开始分析的信号，不是贪心成立的证据。

11.01

区间调度与交换论证

知识与适用场景

最大化互不重叠区间数量时，优先选择结束最早的区间。它为后续留下最多空间；最短区间、最早开始都不具有同样保证。

1.1 交换论证需要四个环节

设当前可选区间中结束最早者为 g，某个最优方案按时间排列的第一个区间为 o。因为 end(g)≤end(o)，把 o 换为 g 后，所有原本从 end(o) 以后开始的后续区间仍能接上；被选数量没有减少。所以存在以 g 开头的最优解。

选定 g 后，只留下起点不小于 end(g) 的区间，剩余问题与原问题相同，递归地应用同一结论。这四件事缺一不可：定义最优解、给出交换、检查可行性、证明目标值不变差并说明子问题同型。只说 g 最早结束，没有完成证明。

把任意最优解的第一个区间替换成全局结束最早的区间，后续已选区间仍然可行且数量不变。因此存在以贪心选择开始的最优解，之后对剩余问题重复。

int maxNonOverlapping(vector<pair<int,int>> intervals) {
    sort(intervals.begin(),intervals.end(),[](auto a,auto b){
        return a.second<b.second;
    });
    long long end=LLONG_MIN;
    int count=0;
    for(auto [l,r]:intervals){
        if(l>=end){ ++count; end=r; }
    }
    return count;
}

1.5 返回区间选择方案：保留原下标方便验证

正长度半开区间，l 必须小于 r。按右端点、左端点、原下标依次排序，返回按选择顺序排列的原下标；并列情况下保证结果稳定，但不承诺原下标序列字典序最小。空输入返回空方案。最大保留数量为结果长度，最少删除数量为输入长度减结果长度。时间 O(n log n)，辅助空间 O(n)。

vector<int> selectIntervals(const vector<pair<int,int>>& intervals) {
    vector<tuple<int,int,int>> order; // (右端点, 左端点, 原下标)
    for (int i = 0; i < (int)intervals.size(); ++i) {
        auto [l,r] = intervals[i];
        if (l >= r) throw invalid_argument("positive-length interval required");
        order.push_back({r,l,i});
    }
    sort(order.begin(),order.end());
    long long end = LLONG_MIN;
    vector<int> chosen;
    for (auto [r,l,id] : order) if (l >= end) {
        chosen.push_back(id); end = r;
    }
    return chosen;
}

1.6 最少箭：右端点同时给出下界与可达方案

在尚未击中的气球中选右端点最小的区间 [l,r]，把箭放在 r。不论最优方案在 [l,r] 内哪里放箭，都可把这支箭右移到 r：所有它原本射中的尚未处理气球右端点都至少为 r，且左端点不大于原箭位置，右移后仍能射中。每次遇到左端点大于上支箭的位置才新增一支。

算法每次新开一箭时，对应的基准气球与前一个基准气球严格分离，因此任何解至少需要这么多支箭；我们的方案达到下界。闭区间允许 l=r，不用 r+1，从而避免最大整数端点溢出。O(n log n) 时间，输入副本与输出 O(n)。

vector<int> minimumArrowPositions(vector<pair<int,int>> balloons) {
    for (auto [l,r] : balloons) if (l > r) throw invalid_argument("interval");
    sort(balloons.begin(),balloons.end(),[](auto a,auto b) {
        if (a.second != b.second) return a.second < b.second;
        return a.first < b.first;
    });
    vector<int> arrows;
    for (auto [l,r] : balloons)
        if (arrows.empty() || l > arrows.back()) arrows.push_back(r);
    return arrows;
}

1.7 最少区间覆盖：选当前能接上的最远右端

目标 [left,right] 是连续实线段；left==right 在本函数约定下视为无需覆盖的空目标，返回 0；left>right 非法。候选要求 l<r，可越过目标边界。每轮扫描所有 l≤frontier 的新候选，选最大 r；这些候选以后不必再考虑，因为它们都不比本轮选择伸得远。排序 O(n log n)、扫描 O(n)，因输入按值传递占 O(n) 空间。

前缀领先证明：在使用同样 k 段后，贪心前沿不小于任何可行方案。另一方案下一段起点不超过它的前沿，也就不超过贪心前沿，所以其延伸能力在贪心可选集合中，贪心仍不落后。由此贪心不会比最优解用更多段。

optional<int> minimumIntervalCover(
    vector<pair<int,int>> intervals, int left, int right) {
    if (left > right) throw invalid_argument("target");
    for (auto [l,r] : intervals) if (l >= r) throw invalid_argument("interval");
    if (left == right) return 0;
    sort(intervals.begin(),intervals.end());
    int frontier = left, used = 0;
    size_t i = 0;
    while (frontier < right) {
        int next = frontier;
        while (i < intervals.size() && intervals[i].first <= frontier) {
            next = max(next,intervals[i].second); ++i;
        }
        if (next == frontier) return nullopt;
        frontier = next; ++used;
    }
    return used;
}

1.8 分发饼干：最小可用资源满足最小需求

每个孩子最多一块饼干，一块只能给一个孩子，尺寸≥需求即满足。将需求和尺寸升序排列，过小的饼干无法满足当前最小需求，更不可能满足后面的人，可以丢弃；足够时就匹配。交换论证说明，把当前最小合适饼干给最小需求，不会降低可满足人数。排序 O(n log n+m log m)，扫描 O(n+m)，输入副本 O(n+m)。这不是有收益、可拆分或多人共享资源的模型。

int assignResources(vector<int> needs, vector<int> sizes) {
    for (int x : needs) if (x < 0) throw invalid_argument("need");
    for (int x : sizes) if (x < 0) throw invalid_argument("size");
    sort(needs.begin(),needs.end()); sort(sizes.begin(),sizes.end());

    for (int size : sizes)
        if (child < needs.size() && size >= needs[child]) ++child;
    return (int)child;
}

面试追问：关键点完整解答

删除最少区间如何转成保留最多？

任意删除方案与它的保留集合一一对应，总数 n 固定，删除数=n−保留数。因此最小化删除数等价于最大化合法保留数。若每个删除操作成本不同，目标不再是数量，不能直接用 n 减去最早结束策略的结果。

端点相等时，到底写 >=、> 还是 <=？

先翻译语义。半开会议 [1,2)、[2,3) 可接，调度条件 l≥end；闭区间气球 [1,2]、[2,3] 可由位置 2 的同一箭击中，只有 l>arrow 才新增箭；连续覆盖 [0,2] 与 [2,4] 没有空隙，允许 l≤frontier。比较符号来自模型，不来自算法名字。

结束时间相同，要不要再按起点排序？

对合法正长度、等价值区间调度而言，同结束时间的候选留下相同后续空间，扫描可行者即可，不影响最大数量。补充代码增加起点和原下标用于确定性输出。不能使用 <= 作为排序比较器，否则 cmp(x,x) 为真，违反严格弱序要求。

最短区间为什么不能保证最多个？

[0,3)、[2,4)、[3,6) 中，中间长度 2 最短，但它同时占住左右两段的接缝；先选它只能得到 1 段，而左右两段可得到 2 段。区间长度小不等于结束早，也不等于对其他区间干扰小。

为何覆盖问题不能继续用最早结束？

调度追求放入更多互不重叠对象，早点结束会留下时间；覆盖追求用更少对象走到目标，应在能接上的候选里延伸最远。目标 [0,10]，有 [0,2]、[0,10] 时，最早结束会先选无必要的短段，最远延伸一段即可完成。

带权区间调度为何需要更多状态？

交换成更早结束的区间虽然保留可行性，却可能丢失收益，原交换论证的“目标不变差”不成立。可按结束时间排序，用 DP 在不选当前区间与选择它加上最后兼容前缀的最优收益之间取最大；兼容位置可二分寻找。

资源匹配把小饼干给小需求，交换论证怎么说完整？

设最小需求为 a，最小能满足它的饼干为 b。若某最优解用更大饼干 c 满足 a，而 b 给了别人 d，则 b≥d，换成 b 给 a、c 给 d 仍可行；若 b 没使用，直接替换也可行。若 a 未满足但 b 给了别人，可把 b 改给 a，满足人数不减。因此存在含该贪心匹配的最优解。

11.02

跳跃游戏：覆盖前沿与分层

知识与适用场景

每个位置给出向右最大跳跃长度。判断可达性只需记录所有已可达位置所能扩展的最远位置。最少跳数可以把一次跳跃能覆盖的范围看成 BFS 的一层。

2.1 不是每次真的选一个落点，而是保留整层的可能性

从下标 i 可以选择向右跳 1..a[i] 步。因为短跳也允许，从起点出发的可达位置始终形成连续前缀 [0,far]；已经可达的位置 i 能把这个前缀延伸到 max(far,i+a[i])。一旦 i>far，后面的点也不可能被越过断层到达。若题目规定恰好跳 a[i] 步，这个连续前缀性质就消失。

求最少跳数时，end 表示使用当前次数能够到达的最远边界，far 收集扫描这些位置后多跳一次的最大覆盖范围。算法不需要承诺落在某个具体点，而是合并所有同层候选；到 i==end 才提交下一层。它是利用区间结构压缩了 BFS 队列，不是盲目选择下一步 a[i] 最大的点。

2.3 同类前沿思路：划分字母区间

要求同一个字符只出现在一个分段内，并尽可能多分段。预先记录每个字符最后出现位置 last[c]，从当前段起点扫描，维护 end=max(end,last[s[i]])。当 i<end 时，前面已有字符还会在 end 出现，此时切开一定非法；当 i==end 时，当前段所有字符都已出现完，可以立即切开。

为什么立刻切能最大化段数？任何合法方案的当前段都不能早于这个位置结束；在最早合法位置切，不会给后续增加字符跨段约束，因此能留下最多可切机会。这里的目标是最多分段，不是把每个字符种类平均分配。

int minJumps(const vector<int>& a) {
    int n=(int)a.size();
    if(n<=1) return 0;
    long long far=0,end=0;
    int steps=0;
    for(int i=0;i<n-1;++i){

        far=max(far,(long long)i+a[i]);

    }

}

bool canReachEnd(const vector<int>& a) {

2.6 还原一条最少跳跃路径：只为新覆盖的位置记父节点

每次 far 扩大时，仅给 (旧 far,新 far] 内的位置设置 parent，所有位置总共只写一次。可达位置的最少跳数随下标非递减，按下标扫描就按 BFS 层推进；第一次覆盖位置 j 的父节点拥有最少层数，因此得到最短路径。不是从所有位置向所有可跳点连边，那会退化为 O(n²)。

空数组或不可达返回 nullopt，单点返回 [0]。答案是下标序列，跳数=路径长度−1。O(n) 时间、O(n) 辅助空间；基础最少跳数模板若不要求路径可只用 O(1) 空间。

optional<vector<int>> shortestJumpPath(const vector<int>& a) {
    for (int x : a) if (x < 0) throw invalid_argument("jump");
    int n = (int)a.size();
    if (!n) return nullopt;
    vector<int> parent(n,-1);
    int far = 0;
    for (int i = 0; i < n && i <= far; ++i) {
        int next = (int)min((long long)n-1,(long long)i+a[i]);
        for (int j = far+1; j <= next; ++j) parent[j] = i;
        far = max(far,next);
        if (far == n-1) break;
    }
    if (far < n-1) return nullopt;
    vector<int> path;
    for (int v = n-1; v != -1; v = parent[v]) path.push_back(v);
    reverse(path.begin(),path.end());
    return path;
}

optional<int> gasStationStart(const vector<int>& gas, const vector<int>& cost) {
    if (gas.size() != cost.size()) throw invalid_argument("length");
    if (gas.empty()) return nullopt;
    long long total = 0, tank = 0;
    int start = 0;
    for (int i = 0; i < (int)gas.size(); ++i) {
        if (gas[i] < 0 || cost[i] < 0) throw invalid_argument("negative value");
        long long delta = (long long)gas[i]-cost[i];

        if (tank < 0) { start = i+1; tank = 0; }

}

面试追问：关键点完整解答

为什么到当前层边界才增加跳数？

扫描当前层的所有位置，是在比较使用同样步数到达这些位置后再跳一次的可能范围，不能把一次扫描当成一次实际跳跃。只有当前层全部考察完，下一层最远边界才完整确定，此时才增加一步。若终点已在新边界内，直接返回，不再处理终点。

直接选择跳跃长度 a[i] 最大的位置有什么问题？

能延伸多远取决于 i+a[i]，不是 a[i] 单独大小；相同跳力在更靠右的位置可延伸更远。更稳妥的是不急着确定落点，而是统计当前层全部候选的最大 i+a[i]，保持层边界领先证明。若需要实际落点，再通过父节点恢复。

可达性为何能压缩成一个 far？允许左右跳还成立吗？

本模型允许从 i 任意向右跳不超过 a[i] 步，因此覆盖是没有缺口的前缀。允许特定跳长、左右跳、有障碍或进入位置消耗不同资源时，可达集合可能不连续或未来能力不同，就不能只用一个端点代表全部状态，应重新建图使用 BFS、最短路或 DP。

题目保证可达，哪些判断可以省略？

在非负最大跳长模型且题目确实保证可达时，可以省去 i>far 和边界无法推进的失败分支；但仍需单点处理、只扫描到 n−2，以及计算 i+a[i] 时的数值安全。写通用函数时保留失败分支更便于复用。

划分字母区间为什么不能在第一次遇到新字符时就切？

字符可能在后面再次出现。比如 abac，看到 b 不表示 a 已结束；last[a]=2，前一段必须至少覆盖到 2。end 收集当前段里所有字符的最后位置，只要 i<end 就一定还有已出现字符需要留在本段。

加油站 total≥0 就足够吗？为什么还要找 start？

在无容量上限的标准模型中，总量非负保证存在某个起点，但不是任意起点都行。gas=[1,2]、cost=[2,1] 的总量为 0，从 0 出发第一步就失败，从 1 才可行。排除候选扫描负责构造一个可行起点，总量检查负责判断是否存在。

加油站油箱有容量上限，还能套同一算法吗？

不能直接套。过多的油可能因容量限制被丢弃，状态不再只是所有 delta 的前缀和。容量 1、gas=[2,0]、cost=[0,2] 总量为 0，但无论从哪里开始都无法支付成本 2。原总量条件和最低前缀构造都依赖无限容量。

最优合并与小顶堆

知识与适用场景

每次合并两项的成本等于两项之和，希望总成本最小。小元素应更早参与合并、大元素应更晚参与，避免大权值被多次计入。这个结构对应 Huffman 树。

3.1 把合并顺序看成一棵满二叉树

每个原始权重是一片叶子，每次把两堆合成一堆相当于建立它们的父节点，内部节点权重等于两孩子的权重之和。总合并成本等于所有内部节点权重之和，也等于每片叶子权重乘它到根的深度之和，因为一片叶子会在每个祖先处被重复收费。

因此小权值适合放深处，大权值适合放浅处。取最优满二叉树中最深的一片叶子，它的兄弟一定也是叶子，否则会有更深叶子。把两个最小权值交换到这对最深兄弟位置不会增加成本：若小权 a≤b、深度 d≥e，则 a·d+b·e≤a·e+b·d。两个最小权值可作为兄弟被合并，再收缩为权重 a+b 的新叶子。

收缩后，原成本等于新树成本加固定的 a+b；如果收缩后的树不是剩余权重的最优树，就能用更好子树替换而改进原最优树，矛盾。由此得到“每次合并最小两项”的完整结构归纳，而不是仅凭第一步最便宜来猜全局最优。

二元相邻合并可以定义 dp[l][r] 为把连续区间 l..r 合成一堆的最小成本。最后一次合并一定把它分为 [l,k] 与 [k+1,r] 两堆，因此 dp[l][r]=min(dp[l][k]+dp[k+1][r]+sum(l..r))。前缀和 O(1) 取得区间总重，长度从短到长转移。每次合并 K 堆则又是另一模型，不能直接使用这个二元公式。

long long optimalMergeChecked(const vector<long long>& weights) {
    priority_queue<long long,vector<long long>,greater<long long>> pq;
    for (long long x : weights) {
        if (x < 0) throw invalid_argument("nonnegative weights required");
        pq.push(x);
    }
    long long cost = 0;
    while (pq.size() > 1) {
        long long a = pq.top(); pq.pop();
        long long b = pq.top(); pq.pop();
        if (a > LLONG_MAX-b) throw overflow_error("merged weight");
        long long merged = a+b;
        if (cost > LLONG_MAX-merged) throw overflow_error("total cost");
        cost += merged; pq.push(merged);
    }
    return cost;
}

long long adjacentMergeCost(const vector<int>& a) {
    int n = (int)a.size();
    if (n > 300) throw invalid_argument("teaching size limit");
    vector<long long> prefix(n+1);
    for (int i = 0; i < n; ++i) {
        if (a[i] < 0 || a[i] > 1000000000) throw invalid_argument("weight");
        prefix[i+1] = prefix[i]+a[i];
    }
    if (n <= 1) return 0;
    const long long INF = LLONG_MAX/4;
    vector<vector<long long>> dp(n,vector<long long>(n,0));
    for (int len = 2; len <= n; ++len) {
        for (int l = 0; l+len <= n; ++l) {
            int r = l+len-1; dp[l][r] = INF;
            for (int k = l; k < r; ++k)
                dp[l][r] = min(dp[l][r],dp[l][k]+dp[k+1][r]+prefix[r+1]-prefix[l]);
        }
    }
    return dp[0][n-1];
}

面试追问：关键点完整解答

为什么必须反复取当前最小两项，而不是先排序后顺次合并？

合并得到的新权重还会参与下一轮竞争，不能只按原数组顺序取。例 [1,2,3,100]，先合 1+2=3 后，新 3 应与原 3 合并为 6；若简单把原来的 3 和 100 配一对，就造成大权重过早多次计费。堆维护动态候选集合。

初次合并成本最小，为什么不足以作为证明？

一次局部收费最低并不普遍推出最终总收费最低，后续会反复包含之前的权重。真正的证明使用整棵合并树的带权路径长度，先证明两个最小值可以成为最深兄弟，再证明收缩后的剩余问题仍最优；这是对所有未来代价的统一论证。

零权重和相同权重会不会使算法出错？

不会。交换论证使用非严格大小关系，零和并列也满足条件。并列时不同合并顺序可能得到不同树，但最小总成本相同。空或单元素没有内部节点，所以返回 0，而不是返回唯一元素权重。

为什么相邻合并不能用同一个小顶堆？

堆只保存权重，丢失原始相邻关系，可能把中间隔着其他堆的两项直接合并。[1,100,1] 中两个 1 就不能先合。即使改成每次挑最便宜相邻对，也需要新证明，不能由 Huffman 的任意换叶论证推出，因为换叶可能改变合法顺序。

相邻合并 DP 为什么每个分割都要加一次区间总和？

左右子区间先各自合成一堆，它们的费用已在两个 dp 值中；最后把这两堆合成一堆，新的收费恰好是整个区间权重之和，与分割位置无关。单点已经是一堆，不产生最后合并，所以 dp[i][i]=0。

每次必须合并 K 堆，有什么额外条件？

每次堆数减少 K−1，若最终要从 n 堆变成 1 堆，必须有 (n−1) 能被 K−1 整除。这只是必要的计数条件，具体算法还取决于能否任意选择、是否相邻等约束。相邻 K 元合并通常需要更多状态或相应的区间 DP 推导，不能把二元堆模板里的 pop 次数直接改掉就算完成。

用 long long 为什么仍需检查累计成本？

同一权重会在不同层反复计费，总成本是权重乘深度之和。即使最后一堆的总重能放入 long long，所有内部合并成本之和仍可能超界。非负数相加可先检查 a>LLONG_MAX−b，再真正执行加法；事后检查溢出已太晚，因为有符号溢出属于未定义行为。

4.4 DP 不是承认失败，而是保留仍可能有用的状态

cash 表示当天处理完后不持股的最大已实现资金，hold 表示持一股时的最大资金余额。持股余额可以为负，不等于最终利润；它记录支付买价后的状态。手续费在卖出时扣：newCash=max(oldCash,oldHold+price−fee)，newHold=max(oldHold,oldCash−price)。

使用 old 状态快照，明确每天最多执行一个动作，避免写入新 cash 后又用它更新 hold，悄悄允许同日多步交易。某些特定无费用模型中这种原地更新恰好不影响数值，也不能把这种巧合推广到所有约束。

冷冻期需要区分刚卖出与早已空仓：sold=oldHold+price；rest=max(oldRest,oldSold)；hold=max(oldHold,oldRest−price)。只能从 oldRest 买入，不能从 oldSold 买。最终只能返回不持股状态的最大值，不能把未卖出的股票当作已兑现利润。

推导 / 不变量

下降段不持有，上涨段捕获全部增量。对于任何合法交易，跨越的总价差不可能超过其中所有正增量之和；该上界又可通过低买高卖实现。

long long stockProfitWithFee(const vector<int>& prices, int fee) {
    if (fee < 0) throw invalid_argument("fee");
    const long long NEG = LLONG_MIN/4;
    long long cash = 0, hold = NEG;
    for (int price : prices) {
        if (price < 0) throw invalid_argument("price");
        long long oldCash = cash, oldHold = hold;
        cash = oldCash;
        if (oldHold != NEG) cash = max(cash,oldHold+price-fee);
        hold = max(oldHold,oldCash-price);
    }
    return cash;
}

4.7 冷冻期一天：把刚卖出单独作为状态

sold 只表示今天刚卖出，不是历史上曾卖出。rest 是今天结束时空仓且明天可买的状态；昨天 sold 的资金可进入今天 rest，但不能直接进入今天 hold。空数组返回 0，最终取 max(rest,sold)。O(n) 时间、O(1) 空间。

long long stockProfitCooldown(const vector<int>& prices) {
    const long long NEG = LLONG_MIN/4;
    long long hold = NEG, sold = NEG, rest = 0;
    for (int price : prices) {
        if (price < 0) throw invalid_argument("price");
        long long oldHold = hold, oldSold = sold, oldRest = rest;
        hold = max(oldHold,oldRest-price);
        sold = oldHold == NEG ? NEG : oldHold+price;
        rest = max(oldRest,oldSold);
    }
    return max(rest,sold);
}

面试追问：关键点完整解答

无限次交易为什么可以把正差全部相加？

每笔交易的价差都能拆成相邻增量，忽略负增量得到总收益上界。每段连续上涨买低卖高能达到所有正增量之和，因此上界可达，贪心最优。这个证明依赖没有交易费用、次数上限与冷冻限制，不能省略这些前提。

最多一次交易维护历史最低价格，为什么不直接找全局最低与最高？

全局最高可能在最低之前。[7,1,5] 的全局差为 6，但不能先在 1 买再回到过去的 7 卖，实际最大收益为 4。扫描每一天作为卖出日，只使用此前最低价格，就同时满足时间顺序与最佳买入选择。

手续费具体破坏了无费用证明的哪一步？

把一段持有拆成多笔交易会增加收费次数，因此不再能免费收集每一段小上涨。例如 [1,3,2,4]、fee=2，拆成两笔得到 0，持有到 4 才卖得到 1。所有正差仍是忽略费用的上界，但未必能用合法收费策略达到。

手续费一定要用 DP，完全不能贪心吗？

特定手续费模型也存在维护有效买入成本的贪心，但必须重新证明它如何合并交易、何时只虚拟结算并避免重复收费。这里使用两状态 DP，是为了直接表达合法状态和费用，并不是声称任何带费用问题都不存在贪心解。原来的“直接加正差”不能照用。

hold 为负数是否意味着这条状态应该丢弃？

不应该。hold=-3 表示买入后余额为 -3，未来高价卖出可能获得最佳利润。比较同样持股状态下哪个余额更大，才有意义；不能把持股和空仓余额直接混在一起只保留一个最大值，因为它们允许的后续动作不同。

冷冻期为什么不能只用一个空仓状态买入？

今天空仓可能是昨天刚卖，也可能很早已卖或从未买，两者今天能否买入不同。若都混成 cash 并允许立即买，就可能在 [1,2,3,0,2] 中选择 3 卖后次日在 0 买，得到非法利润 4。拆出 sold 与 rest 后才能区分动作权限。

贪心与 DP 的界线，是不是“当前选择影响未来”这么简单？

不是，区间选择也会影响未来。真正区别是能否证明某个选择或某个状态支配其他候选，使丢弃它们不损失最优解。若不能证明，就考虑保留按持仓、次数、冷冻等维度区分的状态。DP 有时可进一步化简成贪心，但需要新的支配或交换论证。

0/1 背包能否按单位价值贪心？

硬币面额任意时，先拿最大硬币能保证最少个数吗？

不能。面额 1、3、4，金额 6，先拿 4 后补两个 1 需要 3 枚，两个 3 只需 2 枚。某些特殊币制的贪心成立要另证；任意正整数币制通常考虑 DP 或 BFS。不要把日常货币的经验当通用定理。

贪心输出不唯一时怎样测试？

不应只与某一组标准下标完全相等。区间方案要检查原下标合法且不重复、彼此兼容和数量最优；箭要检查每个气球被覆盖且箭数最少；跳跃路径要检查每步合法和跳数最少；加油站只要完整绕行不缺油即可，不要求与另一个算法返回相同起点。

怎样区分测试、证明和工程输入检查？

证明说明全部满足前提的输入为什么正确；小规模对照测试帮助发现实现、边界和状态转移错误；输入检查保证调用者没有违反契约，并在可能溢出时显式失败。三者互补：浏览器复制按钮正常不能证明 C++ 算法正确，随机用例通过也不代表未知范围永远安全。

int bitCount(int mask) {
    int count = 0;
    while (mask) { count += mask & 1; mask >>= 1; }
    return count;
}
int bruteSchedule(const vector<pair<int,int>>& a) {
    int n = (int)a.size(), best = 0;
    for (int mask = 0; mask < (1 << n); ++mask) {
        bool ok = true;
        for (int i = 0; i < n; ++i) if ((mask >> i) & 1)
            for (int j = i+1; j < n; ++j) if ((mask >> j) & 1)
                if (max(a[i].first,a[j].first) < min(a[i].second,a[j].second)) ok = false;
        if (ok) best = max(best,bitCount(mask));
    }
    return best;
}
int bruteArrows(const vector<pair<int,int>>& a) {
    vector<int> endpoints;
    for (auto [l,r] : a) { endpoints.push_back(l); endpoints.push_back(r); }
    sort(endpoints.begin(),endpoints.end());
    endpoints.erase(unique(endpoints.begin(),endpoints.end()),endpoints.end());
    int best = (int)a.size();
    // 闭区间的最优刺点总可移动到一个端点；仅用于很小输入。
    for (int mask = 0; mask < (1 << endpoints.size()); ++mask) {
        if (bitCount(mask) >= best) continue;
        bool ok = true;
        for (auto [l,r] : a) {
            bool hit = false;
            for (int j = 0; j < (int)endpoints.size(); ++j)
                if (((mask >> j) & 1) && l <= endpoints[j] && endpoints[j] <= r) hit = true;
            if (!hit) ok = false;
        }
        if (ok) best = bitCount(mask);
    }
    return best;
}
optional<int> bruteCover(vector<pair<int,int>> a, int left, int right) {
    if (left == right) return 0;
    sort(a.begin(),a.end());
    optional<int> best; int n = (int)a.size();
    for (int mask = 0; mask < (1 << n); ++mask) {
        int reach = left;
        for (int i = 0; i < n; ++i) if ((mask >> i) & 1) {
            if (a[i].first > reach) break;
            reach = max(reach,a[i].second);
        }
        if (reach >= right && (!best || bitCount(mask) < *best)) best = bitCount(mask);
    }
    return best;
}
int bruteResources(const vector<int>& needs, const vector<int>& sizes) {
    function<int(int,int)> dfs = [&](int i,int mask) {
        if (i == (int)needs.size()) return 0;
        int best = dfs(i+1,mask);
        for (int j = 0; j < (int)sizes.size(); ++j)
            if (!((mask >> j) & 1) && sizes[j] >= needs[i])
                best = max(best,1+dfs(i+1,mask|(1 << j)));
        return best;
    };
    return dfs(0,0);
}
int bruteJumps(const vector<int>& a) {
    if (a.empty()) return -1;
    int n = (int)a.size();
    vector<int> d(n,-1); queue<int> q; d[0] = 0; q.push(0);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v = u+1; v < n && (long long)v <= (long long)u+a[u]; ++v)
            if (d[v] == -1) { d[v] = d[u]+1; q.push(v); }
    }
    return d[n-1];
}
int brutePartitions(const string& s) {
    if (s.empty()) return 0;
    int n = (int)s.size(), best = 0;
    for (int cuts = 0; cuts < (1 << (n-1)); ++cuts) {
        array<int,256> owner; owner.fill(-1);
        int part = 0; bool ok = true;
        for (int i = 0; i < n; ++i) {
            unsigned char c = (unsigned char)s[i];
            if (owner[c] != -1 && owner[c] != part) ok = false;
            owner[c] = part;
            if (i < n-1 && ((cuts >> i) & 1)) ++part;
        }
        if (ok) best = max(best,part+1);
    }
    return best;
}

long long bruteMerge(vector<long long> a, bool adjacent) {
    if (a.size() <= 1) return 0;
    long long best = LLONG_MAX;
    for (int i = 0; i < (int)a.size(); ++i)
        for (int j = i+1; j < (int)a.size(); ++j) {
            if (adjacent && j != i+1) continue;
            auto next = a;
            long long merged = a[i]+a[j];
            next[i] = merged; next.erase(next.begin()+j);
            best = min(best,merged+bruteMerge(next,adjacent));
        }
    return best;
}
long long bruteTrading(const vector<int>& p, int fee, bool cooldown, int maxSales) {
    const long long NEG = LLONG_MIN/4;
    function<long long(int,bool,int,bool)> dfs = [&](int day,bool holding,int sales,bool blocked) {
        if (day == (int)p.size()) return holding ? NEG : 0LL;
        long long best = dfs(day+1,holding,sales,false); // 今天不操作
        if (holding && sales < maxSales) {
            best = max(best,(long long)p[day]-fee+dfs(day+1,false,sales+1,cooldown));
        } else if (!holding && !blocked && sales < maxSales) {
            long long later = dfs(day+1,true,sales,false);
            if (later != NEG) best = max(best,later-p[day]);
        }
        return best;
    };
    return dfs(0,false,0,false);
}

            assert(id >= 0 && id < n && !used[id]); used[id] = true;
            assert(intervals[id].first >= end); end = intervals[id].second;
        }
        auto arrows = minimumArrowPositions(intervals);
        assert((int)arrows.size() == bruteArrows(intervals));
        for (auto [l,r] : intervals) {
            bool hit = false;
            for (int x : arrows) if (l <= x && x <= r) hit = true;
            assert(hit);
        }
        assert(minimumIntervalCover(intervals,0,6) == bruteCover(intervals,0,6));
        vector<int> needs(rng()%6), sizes(rng()%6);
        for (int& x : needs) x = rng()%5;
        for (int& x : sizes) x = rng()%5;
        assert(assignResources(needs,sizes) == bruteResources(needs,sizes));
        vector<int> jumps(n); for (int& x : jumps) x = rng()%5;
        int expected = bruteJumps(jumps);
        assert(canReachEnd(jumps) == (expected >= 0));
        assert(minJumps(jumps) == (jumps.empty() ? 0 : expected));
        auto path = shortestJumpPath(jumps);
        assert(path.has_value() == (expected >= 0));
        if (path) {
            assert(path->front() == 0 && path->back() == n-1);
            assert((int)path->size()-1 == expected);
            for (size_t j = 1; j < path->size(); ++j)
                assert((*path)[j] > (*path)[j-1] && (long long)(*path)[j] <= (long long)(*path)[j-1]+jumps[(*path)[j-1]]);
        }
        string s; for (int i = 0; i < n; ++i) s.push_back(char('a'+rng()%4));
        auto parts = partitionByteLabels(s); assert((int)parts.size() == brutePartitions(s));
        array<int,256> owner; owner.fill(-1); int offset = 0;
        for (int part = 0; part < (int)parts.size(); ++part) {
            assert(parts[part] > 0 && offset+parts[part] <= n);
            for (int j = 0; j < parts[part]; ++j) {
                unsigned char c = (unsigned char)s[offset++];
                assert(owner[c] == -1 || owner[c] == part); owner[c] = part;
            }
        }
        assert(offset == n);
        vector<int> gas(n), cost(n);
        for (int& x : gas) x = rng()%5;
        for (int& x : cost) x = rng()%5;
        bool possible = false;
        for (int start = 0; start < n; ++start) possible = possible || validGasStart(gas,cost,start);
        auto start = gasStationStart(gas,cost);
        assert(start.has_value() == possible); if (start) assert(validGasStart(gas,cost,*start));
        vector<int> weights(rng()%6); for (int& x : weights) x = rng()%8;
        vector<long long> wide(weights.begin(),weights.end());
        assert(optimalMergeChecked(wide) == bruteMerge(wide,false));
        assert(minMergeCost(weights) == optimalMergeChecked(wide));
        assert(adjacentMergeCost(weights) == bruteMerge(wide,true));
        vector<int> prices(n); for (int& x : prices) x = rng()%8;
        int fee = rng()%4;
        assert(stockProfitOnce(prices) == bruteTrading(prices,0,false,1));
        assert(maxProfitUnlimited(prices) == bruteTrading(prices,0,false,n));
        assert(stockProfitWithFee(prices,0) == maxProfitUnlimited(prices));
        assert(stockProfitWithFee(prices,fee) == bruteTrading(prices,fee,false,n));
        assert(stockProfitCooldown(prices) == bruteTrading(prices,0,true,n));
    }
    cout << "greedy checks passed\n";
