11.01

区间调度与交换论证

知识与适用场景

最大化互不重叠区间数量时，优先选择结束最早的区间。它为后续留下最多空间；最短区间、最早开始都不具有同样保证。

推导 / 不变量

把任意最优解的第一个区间替换成全局结束最早的区间，后续已选区间仍然可行且数量不变。因此存在以贪心选择开始的最优解，之后对剩余问题重复。

手推一个例子

[1,4]、[2,3]、[3,5]，先选 [2,3] 再选 [3,5] 可以选 2 个；按最早开始选 [1,4] 只能选 1 个。约定端点相接不冲突。

C++17
下载 .cpp
int maxNonOverlapping(vector<pair<int,int>> intervals) {
    sort(intervals.begin(),intervals.end(),[](auto a,auto b){
        return a.second<b.second;
    });
    long long end=LLONG_MIN;
    int count=0;
    for(auto [l,r]:intervals){
        if(l>=end){ ++count; end=r; }
    }
    return count;
}
复杂度
排序 O(n log n)，扫描 O(n)；输入复制 O(n)。
易错点与边界
若端点相接也算冲突，判断需改为 l>end。求覆盖目标区间的最少数量则需要每一步选择可衔接且延伸最远者，不能套结束最早。

经典考点与练习

练习：LeetCode 435 无重叠区间、452 用最少数量的箭引爆气球。

11.02

跳跃游戏：覆盖前沿与分层

知识与适用场景

每个位置给出向右最大跳跃长度。判断可达性只需记录所有已可达位置所能扩展的最远位置。最少跳数可以把一次跳跃能覆盖的范围看成 BFS 的一层。

推导 / 不变量

遍历当前层时更新 far；到达当前层右边界 end 时，必须增加一次跳跃并把 end 扩展到 far。如果 far 未超过当前位置，就无法继续。

手推一个例子

[2,3,1,1,4]：第一层从 0 到达最远 2；扫描位置 1、2 时可把下一层扩展到 4，因此共两次跳跃。

C++17
下载 .cpp
int minJumps(const vector<int>& a) {
    int n=(int)a.size();
    if(n<=1) return 0;
    long long far=0,end=0;
    int steps=0;
    for(int i=0;i<n-1;++i){
        if(i>far) return -1;
        far=max(far,(long long)i+a[i]);
        if(i==end){
            if(far<=i) return -1;
            ++steps; end=far;
            if(end>=n-1) return steps;
        }
    }
    return -1;
}
复杂度
时间 O(n)，空间 O(1)。前提：a[i] 非负。
易错点与边界
不应直接跳到 a[i] 最大的位置，应比较 i+a[i] 的覆盖能力。循环不处理终点，避免到达后又增加一次跳跃。

经典考点与练习

练习：LeetCode 55 跳跃游戏、45 跳跃游戏 II、763 划分字母区间。

面试官可能继续问什么？

为什么当前层边界处才增加步数？若题目保证可达，哪些判断可省略？

11.03

最优合并与小顶堆

知识与适用场景

每次合并两项的成本等于两项之和，希望总成本最小。小元素应更早参与合并、大元素应更晚参与，避免大权值被多次计入。这个结构对应 Huffman 树。

推导 / 不变量

选择最小的两个值合并，再把和放回集合。可以用交换论证说明存在最优树让两个最小权值成为最深的一对兄弟，因此这一步可以收缩为更小问题。

手推一个例子

[1,2,3]：先合 1+2=3，再合 3+3=6，总成本 9；若先合 2+3=5，再加 1，总成本 11。

C++17
下载 .cpp
long long minMergeCost(const vector<int>& weights) {
    priority_queue<long long,vector<long long>,greater<long long>> pq;
    for(int x:weights){
        if(x<0) throw invalid_argument("nonnegative weights required");
        pq.push(x);
    }
    long long cost=0;
    while(pq.size()>1){
        long long a=pq.top(); pq.pop();
        long long b=pq.top(); pq.pop();
        cost+=a+b; pq.push(a+b);
    }
    return cost;
}
复杂度
时间 O(n log n)，空间 O(n)。总成本需在 long long 范围内。
易错点与边界
如果只允许合并相邻区间，任取最小两项不再合法，需要区间 DP 等方法。约束改变后不能照搬贪心。

经典考点与练习

练习：经典合并果子；对比 LeetCode 1000 合并石头的最低成本。

为什么相邻合并不能使用同样的堆？如何构造反例？

11.04

股票问题：从合法策略判断贪心边界

知识与适用场景

允许无限次交易、不能同时持有多股、没有手续费和冷冻期时，所有相邻上涨差值相加就是最优收益。一次长上涨的利润可以拆成若干相邻上涨之和。

推导 / 不变量

下降段不持有，上涨段捕获全部增量。对于任何合法交易，跨越的总价差不可能超过其中所有正增量之和；该上界又可通过低买高卖实现。

手推一个例子

[7,1,5,3,6,4]，正增量是 4 和 3，总收益 7。若限制最多一次交易，则不能把两段利润直接相加。

C++17
下载 .cpp
long long maxProfitUnlimited(const vector<int>& prices) {
    long long profit=0;
    for(int i=1;i<(int)prices.size();++i)
        profit+=max(0LL,(long long)prices[i]-prices[i-1]);
    return profit;
}
复杂度
时间 O(n)，空间 O(1)。
易错点与边界
加手续费、冷冻期或交易次数上限后，决策之间产生额外依赖，通常应建持有/未持有状态 DP。

经典考点与练习

练习：LeetCode 121 买卖股票的最佳时机、122 买卖股票的最佳时机 II；对比 309、714。
