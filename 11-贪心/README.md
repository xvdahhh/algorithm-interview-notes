## 核心思想

贪心在每一步选择当前看来最优的方案，并希望构成全局最优。难点不是写代码，而是证明局部选择不会破坏全局最优。

## 识别信号

- 题目要求最大数量、最少资源、最早完成、最小代价。
- 对象可排序，做出选择后剩余问题与原问题结构相同。
- 决策不可撤回，但存在清晰的“最优优先级”。
- 可以通过交换相邻决策而不让答案变差。

## 常用证明方法

### 交换论证

假设存在一个最优解没有采用当前贪心选择，证明把它的某个选择替换成贪心选择后，解仍可行且不更差，因此总存在包含贪心选择的最优解。

### 领先法

证明贪心方案在每个前缀上都不落后于其他方案，最终自然不差。

### 反证法

假设贪心方案不是最优，从第一个不同决策处导出矛盾。

## 高频模型

- 区间调度：按结束时间升序，优先选择最早结束且不冲突的区间。
- 合并/删除区间：先排序，再维护当前覆盖范围。
- 跳跃游戏：维护当前能到达的最远位置；求最少跳数时维护当前层边界。
- 分发资源：排序后让需求与资源按合适顺序匹配。
- 买卖股票：不同交易次数限制对应不同贪心或 DP，不能混用结论。
- Huffman 合并：每次合并最小的两项，用小顶堆实现。

## 贪心与动态规划的界线

- 关键不是“当前选择是否影响未来”，而是能否证明某个选择可安全保留、其余候选可永久丢弃。区间调度同样影响未来，但可由交换论证保证正确。
- 若只保留一个局部最优状态会丢失潜在答案，应保留多个状态。
- 遇到反例时不要修补贪心细节，应重新审视是否存在贪心选择性质。
- 手续费股票存在专门的贪心推导，但不能照搬无费用时累加正差的规则；本章用状态 DP 明确表达动作与费用。

## 易错点与自测

- [ ] 能给出贪心选择的证明，而不是只说“直觉上最好”。
- [ ] 排序键正确，结束时间、开始时间、长度并不等价。
- [ ] 区间端点相等时是否冲突与题意一致。
- [ ] 会主动构造小规模反例检验贪心策略。
- [ ] 能区分区间调度、区间覆盖和区间分组。
- [ ] 能证明最少跳数的层边界，以及加油站失败后为何排除整段起点。
- [ ] 能从合并树解释最优合并，并说明相邻约束为什么改变算法。
- [ ] 能用反例区分一次交易、无限次交易、手续费与冷冻期。
- [ ] 能区分理论证明、穷举对照测试和数值安全检查各自的作用。
