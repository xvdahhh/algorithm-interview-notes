03.01

虚拟头结点与有序合并

知识与适用场景

头结点可能改变时，增加 dummy 可以统一处理头部和中间节点。tail 永远指向已构建结果的最后一个节点，每次把较小节点接到尾部。

推导 / 不变量

两个输入链表均有序，因此它们当前头部的较小者也是所有剩余节点中的最小者。接入后只推进被选中的那条链表。

手推一个例子

[1,3] 与 [1,2] 合并：依次接入第一条的 1、第二条的 1、第二条的 2，最后直接接上剩余的 3。

C++17
下载 .cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int v = 0, ListNode* p = nullptr) : val(v), next(p) {}
};
ListNode* mergeTwo(ListNode* a, ListNode* b) {
    ListNode dummy;
    ListNode* tail = &dummy;
    while (a && b) {
        if (a->val <= b->val) { tail->next = a; a = a->next; }
        else { tail->next = b; b = b->next; }
        tail = tail->next;
    }
    tail->next = a ? a : b;
    return dummy.next;
}
复杂度
时间 O(m+n)，额外空间 O(1)，复用原节点并改变连接关系。前提是输入链表无环且不共享节点。
易错点与边界
dummy 是局部对象，但返回的是 dummy.next 所指的原节点，不能返回 &dummy。面试节点通常由平台管理，不要随意 delete。

经典考点与练习

练习：LeetCode 21 合并两个有序链表、203 移除链表元素、19 删除链表的倒数第 N 个结点。

03.02

迭代反转与局部拼接

知识与适用场景

反转时必须保存当前节点的旧后继。prev 表示已反转部分的头，cur 表示未处理部分的头。每轮把 cur 从未处理部分移到已反转部分前端。

推导 / 不变量

修改 cur->next 之前，用 next 保存剩余链表。局部反转还需要保留区间前驱和原区间头：原头在翻转后变成尾，要连接后续部分。

手推一个例子

1→2→3：第一轮变成 1→null 与 2→3；第二轮 2→1 与 3；第三轮 3→2→1，cur 为空时返回 prev。

C++17
下载 .cpp
struct ListNode {
    int val; ListNode* next;
    ListNode(int v = 0, ListNode* p = nullptr) : val(v), next(p) {}
};
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* cur = head;
    while (cur) {
        ListNode* next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    return prev;
}
复杂度
时间 O(n)，额外空间 O(1)。递归反转同样 O(n) 时间，但调用栈 O(n)。
易错点与边界
K 个一组反转必须先检查剩余是否有 K 个节点。回文链表题反转后半段后，如果要求输入保持原状，要再次反转恢复。

经典考点与练习

练习：LeetCode 206 反转链表、92 反转链表 II、25 K 个一组翻转链表。

面试官可能继续问什么？

为什么不能先执行 cur=cur->next？局部翻转后需要重新接上哪两条边？

03.03

快慢指针、环入口与中点

知识与适用场景

快慢指针用于在一次扫描中构造位置差。找中点依赖速度差，找倒数第 k 个依赖固定距离差。检测环时，环内相对速度为一步，必定相遇。

推导 / 不变量

相遇后让一个指针回到头部，两者每次各走一步。设入口前长度 a，相遇位置距入口 b，环长 L，则 a+b 是 L 的整数倍，故从相遇处再走 a 步回到入口。

手推一个例子

链表 1→2→3→4→2，环长 3。相遇后头部指针与相遇指针同步走，第一次相遇在 2。

C++17
下载 .cpp
struct ListNode {
    int val; ListNode* next;
    ListNode(int v = 0, ListNode* p = nullptr) : val(v), next(p) {}
};
ListNode* detectCycle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            ListNode* p = head;
            while (p != slow) { p = p->next; slow = slow->next; }
            return p;
        }
    }
    return nullptr;
}
复杂度
时间 O(n)，额外空间 O(1)。n 指不同节点总数。
易错点与边界
中点模板的初始位置决定偶数长度返回左中点还是右中点。判断相交比较节点地址，不能比较 val。

经典考点与练习

练习：LeetCode 141 环形链表、142 环形链表 II、876 链表的中间结点、160 相交链表。

面试官可能继续问什么？

03.04

随机指针复制与深拷贝

知识与适用场景

深拷贝要求新旧节点完全分离，但连接拓扑相同。难点在于 random 可能指向尚未复制的节点，因此将建点和连边分成两个阶段。

推导 / 不变量

第一遍为每个旧节点创建新节点并记录映射；第二遍根据映射设置 next 与 random。这样不论 random 指向前方、后方、自己还是空，都能统一处理。

手推一个例子

A.random=C，B.random=A。复制时先得到 A'、B'、C'；随后连 A'.random=C'，B'.random=A'，绝不能把新节点连回旧节点。

C++17
下载 .cpp
struct Node {
    int val; Node *next = nullptr, *random = nullptr;
    explicit Node(int v) : val(v) {}
};
Node* copyRandomList(Node* head) {
    unordered_map<Node*, Node*> copied;
    for (Node* p = head; p; p = p->next) copied[p] = new Node(p->val);
    for (Node* p = head; p; p = p->next) {
        copied[p]->next = p->next ? copied.at(p->next) : nullptr;
        copied[p]->random = p->random ? copied.at(p->random) : nullptr;
    }
    return head ? copied.at(head) : nullptr;
}
复杂度
平均时间 O(n)，额外映射 O(n)，新输出节点 O(n)。前提：next 无环，random 指向链表内节点或空。
易错点与边界
穿插复制节点可以把辅助空间降为 O(1)，但会暂时修改原链表，最后必须拆分恢复。真实项目要约定释放新节点的责任。

经典考点与练习

练习：LeetCode 138 随机链表的复制；进阶：将映射复制推广到图的克隆。
