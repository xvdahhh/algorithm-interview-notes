## 基础认知

- 单链表无法随机访问，查找第 `k` 个元素是 `O(k)`。
- 已知节点时插入删除可为 `O(1)`，但寻找位置仍需遍历。
- 链表题的难点通常不是算法复杂度，而是指针更新顺序和边界。

## 三个核心工具

### 虚拟头结点

在真实头结点前增加 `dummy`，让删除头结点、区间反转、合并链表等操作不再单独特判。最终返回 `dummy.next`。

### 快慢指针

- 找中点：快指针每次两步，慢指针每次一步。
- 判断环：若有环，快慢指针必相遇。
- 找环入口：相遇后一个指针回到头部，两者改为每次一步，再次相遇处是入口。
- 倒数第 `k` 个：快指针先走 `k` 步，再同步移动。

### 原地反转

```text
prev = null
cur = head
while cur != null:
    next = cur.next
    cur.next = prev
    prev = cur
    cur = next
return prev
```

始终先保存 `next`，否则会丢失未处理链表。

## 高频题型

- 合并两个有序链表：双指针 + 虚拟头结点，`O(m+n)`。
- K 个一组翻转：先确认剩余节点足够，再断开、翻转、拼接。
- 判断回文：找中点、反转后半段、逐项比较；是否恢复链表取决于约定。
- 两链表相交：双指针走完自己的链表后切换到另一条，消除长度差。
- 复制随机指针链表：哈希映射，或在原节点后穿插复制节点再拆分。
- LRU 缓存：哈希表 + 双向链表，实现 `O(1)` 查询、插入、删除和更新最近使用顺序。

## 指针操作不变量

- 指针含义按模板定义：整链反转中的 `prev` 指向已反转部分的头；合并中的 `tail` 指向结果尾；删除中的 `predecessor` 指向待删位置之前的节点。
- `cur` 指向当前待处理节点。
- 修改 `cur.next` 之前，未处理部分的入口已经保存。
- 删除节点时，持有它的前驱；双向链表还要同时维护前后两个方向。
