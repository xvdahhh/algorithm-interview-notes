## 图的表示

- 邻接表：空间 `O(V+E)`，适合稀疏图，是面试默认选择。
- 邻接矩阵：空间 `O(V²)`，适合稠密图或频繁判断两点是否相连。
- 无向边需添加两个方向；带权图的邻接项还要保存权重。

## DFS 与 BFS

- DFS 适合连通块、路径枚举、环检测、拓扑排序和树形信息汇总。
- BFS 适合无权图最短路、层级扩散、多源最短距离。
- 标记访问的时机通常是“入栈/入队时”，避免同一节点重复加入。
- 图可能不连通，需要从所有未访问节点启动搜索。

### 多源 BFS

把所有源点同时入队，距离初始化为 0，再逐层扩展。常用于腐烂橘子、最近零距离、扩散时间。

## 拓扑排序

仅适用于有向无环图（DAG）。Kahn 算法：

1. 统计每个节点入度。
2. 所有入度为 0 的节点入队。
3. 取出节点并删除其出边，邻居入度减一；新变为 0 的邻居入队。
4. 若最终处理节点数小于总节点数，则图中有环。

应用：课程依赖、任务编排、构建顺序。

## 最短路

| 算法 | 适用条件 | 复杂度 |
| --- | --- | --- |
| BFS | 无权图或等权图 | `O(V+E)` |
| Dijkstra | 边权非负 | 二叉堆实现 `O((V+E)log V)` |
| Bellman-Ford | 可有负边，可检测负环 | `O(VE)` |
| Floyd | 多源最短路，节点较少 | `O(V³)` |

Dijkstra 中堆可能保留旧距离；弹出状态时若距离不是当前最优值，应跳过。

## 最小生成树

- Kruskal：边按权重排序，依次加入不会成环的边，用并查集判断连通，`O(E log E)`。
- Prim：从一个点开始，每次选择连接已选集合与未选集合的最小边，常配合堆。
- 最小生成树要求无向、连通、带权；不连通时得到的是最小生成森林。

## 环检测

- 无向简单图 DFS：遇到已访问且不是父节点的邻居说明有环；多重图应跳过来路边编号，而非整个父节点，以免漏掉平行边形成的环。也可用并查集。
- 有向图 DFS：使用未访问、访问中、已完成三种颜色；指向“访问中”节点是回边。
- 拓扑排序处理数不足也说明有向图存在环。

## 易错点与自测

- [ ] 分清有向图与无向图的建边方式。
- [ ] 不把 Dijkstra 用在负权边图上。
- [ ] 能写 BFS、DFS、拓扑排序和 Dijkstra 模板。
- [ ] 搜索前考虑图是否有多个连通分量。
- [ ] 距离相加使用足够宽的整数并避免无穷大溢出。
- [ ] 能解释 Kahn 残留节点不全在环上，以及最终安全节点为何从反图入手。
- [ ] 区分不可达、有限最短路和负环导致的无有限最短路。
- [ ] 能说明 Prim 的 key 是跨割单边权，而 Dijkstra 的 dist 是路径代价。
- [ ] 能用割性质证明安全加边，并说明并列边下 MST 不一定唯一。
