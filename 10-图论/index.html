10.01

建图与 BFS：无权最短路

知识与适用场景

邻接表用 vector<vector<int>> 表示出边，空间 O(V+E)。无向边要添加两个方向。BFS 按距离层扩展，第一次发现一个节点时已经得到最少边数。

推导 / 不变量

距离数组 -1 表示未访问；源点距离置 0 并入队。发现邻居时立即赋距离并入队，防止它被同层多个父节点重复加入。

手推一个例子

边 0→1、0→2、1→3、2→3，源点 0。第一层发现 1、2，第二层只把 3 入队一次，距离为 2。

C++17
下载 .cpp
vector<int> bfsDistances(const vector<vector<int>>& g, int source) {
    int n=(int)g.size();
    if (source<0 || source>=n) throw out_of_range("source");
    vector<int> dist(n,-1);
    queue<int> q;
    dist[source]=0; q.push(source);
    while (!q.empty()) {
        int u=q.front(); q.pop();
        for (int v:g[u]) {
            if (dist[v]!=-1) continue;
            dist[v]=dist[u]+1;
            q.push(v);
        }
    }
    return dist;
}
复杂度
时间 O(V+E)，距离和队列空间 O(V)，图本身 O(V+E)。
易错点与边界
求全图连通块需从每个未访问节点启动搜索。多源 BFS 把所有源点初始距离设为 0，同时入队；普通 BFS 不适用于任意不同边权。

经典考点与练习

练习：LeetCode 200 岛屿数量、994 腐烂的橘子、542 01 矩阵。

10.02

拓扑排序与有向环

知识与适用场景

拓扑序要求每条边 u→v 中 u 都出现在 v 前面。只有 DAG 存在完整拓扑序；入度为 0 的节点表示当前没有尚未完成的前置依赖。

推导 / 不变量

Kahn 算法每次移除入度 0 的节点及其出边。若剩余节点全部入度大于 0，就无法继续，剩余部分包含有向环。

手推一个例子

课程依赖 0→1、0→2、1→3、2→3：先处理 0，再处理 1、2，最后 3。1 与 2 可交换，所以拓扑序不一定唯一。

C++17
下载 .cpp
vector<int> topoSort(const vector<vector<int>>& g) {
    int n=(int)g.size();
    vector<int> degree(n,0), order;
    for (const auto& edges:g) for (int v:edges) ++degree[v];
    queue<int> q;
    for (int u=0;u<n;++u) if (degree[u]==0) q.push(u);
    while (!q.empty()) {
        int u=q.front(); q.pop(); order.push_back(u);
        for (int v:g[u]) if (--degree[v]==0) q.push(v);
    }
    if ((int)order.size()!=n) return {}; // 非空图时，空结果表示有环
    return order;
}
复杂度
时间 O(V+E)，辅助空间 O(V)。
易错点与边界
不要把无向图的父节点判环规则搬到有向图。DFS 判有向环需要三色标记，指向“正在访问”的节点才是回边。

经典考点与练习

练习：LeetCode 207 课程表、210 课程表 II、802 找到最终的安全状态。

10.03

Dijkstra：非负权最短路

知识与适用场景

非负边权保证当前未确定节点中距离最小者，其距离不会再通过更远节点改小。这个贪心结论依赖非负权，存在负边时不成立。

推导 / 不变量

小顶堆保存 (候选距离,节点)。松弛成功时推入新状态，不必删除旧状态；弹出时若距离不等于当前 dist，说明是旧状态，跳过即可。

手推一个例子

0→1 权 10，0→2 权 1，2→1 权 2。1 先以 10 入堆，随后改为 3；弹出 (10,1) 时应跳过。

C++17
下载 .cpp
vector<long long> dijkstra(
    const vector<vector<pair<int,int>>>& g, int source) {
    const long long INF=LLONG_MAX/4;
    if (source<0 || source>=(int)g.size()) throw out_of_range("source");
    vector<long long> dist(g.size(),INF);
    using State=pair<long long,int>;
    priority_queue<State,vector<State>,greater<State>> pq;
    dist[source]=0; pq.push({0,source});
    while (!pq.empty()) {
        auto [d,u]=pq.top(); pq.pop();
        if (d!=dist[u]) continue;
        for (auto [v,w]:g[u]) {
            if (w<0) throw invalid_argument("negative edge");
            if (d+w<dist[v]) {
                dist[v]=d+w;
                pq.push({dist[v],v});
            }
        }
    }
    return dist;
}
复杂度
允许重复状态的堆实现：一般写 O((V+E) log(E+2))，简单图中常写 O((V+E) log V)；堆最多 O(E)，距离 O(V)。
易错点与边界
本例假设有效路径长度小于 INF。首次入堆并不代表距离最终确定，不能在入堆时永久标记。不可达节点距离仍为 INF。

经典考点与练习

练习：LeetCode 743 网络延迟时间、1631 最小体力消耗路径；了解 0-1 BFS。

10.04

Floyd 与负权算法的选择

知识与适用场景

多个点之间都要查询距离且节点数较少时，可用 Floyd。它逐步允许路径经过编号更大的中间节点。存在负边但无负环时仍适用；若负环影响某对点，最短路不再有限。

推导 / 不变量

外层必须枚举中间点 k，转移 d[i][j]=min(d[i][j],d[i][k]+d[k][j])。初始化对角为 0，直接边取最小权重，其余为 INF。

手推一个例子

0→1 为 3，1→2 为 -1，0→2 为 5。允许中间点 1 后，0→2 改为 2。

C++17
下载 .cpp
void floyd(vector<vector<long long>>& d) {
    const long long INF=LLONG_MAX/4;
    int n=(int)d.size();
    for (int k=0;k<n;++k)
        for (int i=0;i<n;++i) {
            if (d[i][k]==INF) continue;
            for (int j=0;j<n;++j) {
                if (d[k][j]==INF) continue;
                d[i][j]=min(d[i][j],d[i][k]+d[k][j]);
            }
        }
    // 如有 d[i][i] < 0，则存在负环。
}
复杂度
时间 O(V³)，距离矩阵 O(V²)，原地转移额外空间 O(1)。
易错点与边界
INF 参与加法前必须判断。边权规模需保证有限路径和不会溢出。单源含负边可选 Bellman-Ford：重复松弛 V-1 轮，再一轮检查可达负环。

经典考点与练习

练习：LeetCode 1334 阈值距离内邻居最少的城市；实现 Bellman-Ford 作为进阶练习。

10.05

最小生成树与最短路的区别

知识与适用场景

最小生成树要求用最小总边权连接所有节点，不要求从某个源到其他点的路径最短。Kruskal 按边权排序，选择连接不同连通块的最小边。

推导 / 不变量

并查集判断加边是否形成环。每选一条边，连通块数减少 1；选满 V-1 条边就得到生成树，若选不满则图不连通。

手推一个例子

三角形边权 1、2、3，选 1 和 2 即可连接全部节点，总权 3；继续选 3 会成环，必须跳过。

C++17

struct DSU {
    vector<int> p,sz;
    explicit DSU(int n):p(n),sz(n,1){ iota(p.begin(),p.end(),0); }
    int find(int x){ return p[x]==x ? x : p[x]=find(p[x]); }
    bool unite(int a,int b){
        a=find(a); b=find(b);
        if(a==b) return false;
        if(sz[a]<sz[b]) swap(a,b);
        p[b]=a; sz[a]+=sz[b]; return true;
    }
};
optional<long long> kruskal(int n, vector<tuple<int,int,int>> edges) {
    // 每条边为 (权重,u,v)，无向图；节点编号 0..n-1。
    if(n<=1) return 0LL;
    sort(edges.begin(),edges.end());
    DSU dsu(n);
    long long sum=0; int used=0;
    for(auto [w,u,v]:edges)
        if(dsu.unite(u,v)){
            sum+=w;
            if(++used==n-1) return sum;
        }
    return nullopt;
}
复杂度
时间 O(E log E + E·α(V))，并查集 O(V)；该实现按值传边表，额外复制 O(E)。
易错点与边界
有负边仍可求最小生成树。图必须无向；有向图的最小连接问题不能直接套 Kruskal。

经典考点与练习

练习：LeetCode 1584 连接所有点的最小费用、684 冗余连接。
