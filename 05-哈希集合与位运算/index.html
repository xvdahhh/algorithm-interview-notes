05.01

哈希映射：存在、下标还是次数

知识与适用场景

哈希表的 value 必须服务于问题目标：判断存在用 set，返回位置保存下标，统计数量保存频次，求最长区间常保存最早下标。键必须能完整代表你要比较的状态。

推导 / 不变量

两数之和先查询补数，再插入当前数，保证不会重复使用同一个位置。此前所有元素都在表中，因此当前元素作为较晚端点的解不会被遗漏。

手推一个例子

[3,3]，target=6：第一个 3 只入表；第二个 3 查到下标 0，返回 [0,1]。若先插入当前值，可能错误得到同一个下标两次。

C++17
下载 .cpp
vector<int> twoSum(const vector<int>& a, long long target) {
    unordered_map<long long, int> pos;
    for (int i = 0; i < (int)a.size(); ++i) {
        auto it = pos.find(target - a[i]);
        if (it != pos.end()) return {it->second, i};
        pos[a[i]] = i;
    }
    return {};
}
复杂度
平均时间 O(n)，最坏 O(n²)，空间 O(n)。
易错点与边界
operator[] 查询不存在的键会插入默认值；纯查询优先 find。rehash 会使迭代器失效，遍历中修改需谨慎。

经典考点与练习

练习：LeetCode 1 两数之和、49 字母异位词分组、205 同构字符串。

05.02

集合：最长连续序列为何是线性

知识与适用场景

把所有数放进集合后，仅从没有前驱 x-1 的数启动向后扩展。这保证每段连续区间只被扫描一次，而不是对每个起点重复扫描整段。

推导 / 不变量

集合去重后，连续块只有一个最小值能触发扩展。扫描集合一次，加上各块内总共 O(n) 次扩展，平均总成本 O(n)。

手推一个例子

[100,4,200,1,3,2,2] 去重后，只从 1、100、200 扩展。1 找到 2、3、4，长度 4；2、3、4 因为存在前驱不启动搜索。

C++17
下载 .cpp
int longestConsecutive(const vector<int>& a) {
    unordered_set<long long> values(a.begin(), a.end());
    int ans = 0;
    for (long long x : values) {
        if (values.count(x - 1)) continue;
        long long y = x;
        while (values.count(y)) ++y;
        ans = max(ans, (int)(y - x));
    }
    return ans;
}
复杂度
平均时间 O(n)，空间 O(n)，哈希最坏时间可能退化。
易错点与边界
使用 long long 存储 int 输入，避免 INT_MIN-1、INT_MAX+1 溢出。外层如果遍历含大量重复值的原数组，可能重复扩展同一长区间。

经典考点与练习

练习：LeetCode 128 最长连续序列、349 两个数组的交集。

为什么嵌套 while 不是 O(n²)？如果不去重会怎样？

05.03

异或与二进制计数

知识与适用场景

异或满足交换律、结合律，且 x^x=0，因此偶数次出现的元素会抵消。但不能把这个结论套到出现三次的问题，后者需要按位计数或状态机。

推导 / 不变量

x&(x-1) 每次清除最低位的 1：x-1 把最低位 1 变为 0，并把其右侧的 0 变成 1，相与后只删除该位。使用无符号类型使位级语义明确。

手推一个例子

x=12，即 1100；第一次变为 1000，第二次变为 0000，所以 popcount 为 2。

C++17
下载 .cpp
int singleNumber(const vector<int>& a) {
    int ans = 0;
    for (int x : a) ans ^= x;
    return ans;
}
int countBits(uint32_t x) {
    int count = 0;
    while (x) {
        x &= x - 1;
        ++count;
    }
    return count;
}
bool isPowerOfTwo(uint32_t x) {
    return x != 0 && (x & (x - 1)) == 0;
}
复杂度
异或归约 O(n) 时间、O(1) 空间；位计数 O(b)，b 为 1 的个数，最多 32。
易错点与边界
0 不是 2 的幂。位移位数不能大于等于类型宽度；设置高位用 1ULL<<k，并确认 k<64。

经典考点与练习

练习：LeetCode 136 只出现一次的数字、260 只出现一次的数字 III、191 位 1 的个数。

面试官可能继续问什么？

两个数各出现一次、其余两次时，如何用异或结果的最低位 1 分组？

05.04

位掩码表示子集

知识与适用场景

n 个选或不选状态可用 n 位二进制编码，第 i 位为 1 表示选择第 i 个元素。这适合 n 较小的穷举、状态压缩 DP 和集合运算。

推导 / 不变量

遍历 0 到 2^n-1，每个整数唯一对应一个子集。判断成员用 mask&(1ULL<<i)，集合并/交/差可以用按位或、与、与取反。

手推一个例子

[a,b,c] 的掩码 101 表示选择 a 与 c；000 为空集，111 为全集。共有 8 个状态。

C++17
下载 .cpp
vector<vector<int>> subsetsByMask(const vector<int>& a) {
    int n = (int)a.size();
    if (n > 20) throw invalid_argument("exponential output too large");
    vector<vector<int>> ans;
    uint64_t total = 1ULL << n;
    for (uint64_t mask = 0; mask < total; ++mask) {
        vector<int> cur;
        for (int i = 0; i < n; ++i)
            if (mask & (1ULL << i)) cur.push_back(a[i]);
        ans.push_back(move(cur));
    }
    return ans;
}
复杂度
时间与输出空间 O(n·2^n)，临时单个子集 O(n)。
易错点与边界
位宽允许不代表内存允许；n=40 即使掩码放得下，也无法直接枚举全部子集。输入含重复值时会生成内容重复的子集。

经典考点与练习

练习：LeetCode 78 子集；进阶：旅行商状态 dp[mask][last]。
