递归、回溯与分治

把穷举组织成决策树，再用约束消除无效分支。代码中的选择、递归、撤销必须一一对应；输出的大小也是复杂度的一部分。

本章怎么学

先读原理与不变量，遮住代码手推例子，再独立实现。最后用面试追问检查理解，按练习条目做变式。

本章目标：先定义搜索空间，再决定怎么裁剪

递归是组织函数调用的方法；回溯是在决策树上尝试选择并恢复共享状态；分治将问题拆成子问题后合并；记忆化缓存重复子问题。这些概念可以组合，但并非同义词。看到dfs函数不能直接断言它是回溯或时间为指数。

每个模板都先回答：参数描述什么状态、这一层做哪个决定、终止时输出什么、哪一项严格递减、子调用结束后谁恢复状态。C++17示例中的规模限制用于控制输出爆炸；即使合法规模也需结合时限与内存评估。

复杂度与安全边界

输出所有子集有2^n个答案，所有无重复全排列有n!个答案，复制每个长度O(n)的路径也是成本。不要把递归节点数、路径缓冲空间和全部结果空间混在一起。路径用引用共享时需要撤销，答案用push_back(path)保存副本；参数按值传递则不必恢复那份局部副本，但有复制开销。

递归深度并不会因记忆化自动减少。金额一万、长度一万的链式子问题仍可能产生深调用栈，依赖环境时应改用显式栈或自底向上DP。本章测试用小输入验证逻辑，不承诺极深递归可以安全运行。

09.01

子集与组合：start 消除排列重复

知识与适用场景

子集关心选哪些元素，不关心选取顺序，因此每次只能从上一次下标之后继续选。路径对应已经选取的元素，start 对应下一层可以选择的最小下标。

1.1 start不是下一个必须选择的位置，而是允许选择的最小下标

组合不关心选取顺序，让所选下标严格递增就能给每组元素一个唯一表示。选择i后传i+1，排除了先选后面再返回前面的路径，因此不会同时生成[1,2]和[2,1]。

子集题每个递归节点都代表一个答案，进入函数就记录；恰选K个的组合题只在路径长度达到K时记录。空输入的子集有一个空集；从n个数选0个也有一个空组合，不是没有答案。

1.3 恰选K个：用剩余数量收紧循环边界

选择当前value之前还需要need个数，value..n必须至少有need个位置，所以value<=n-need+1。这个剪枝只排除数量不足的分支，不丢合法组合。

辅助栈和路径O(k)，输出O(k·C(n,k))；含k=0的统一上界可写O((k+1)·C(n,k))。n上限只是教学保护，不是通用组合公式限制。

vector<vector<int>> chooseK(int n, int k) {
    if (n < 0 || n > 20 || k < 0 || k > n)
        throw invalid_argument("require 0 <= k <= n <= 20");
    vector<vector<int>> answer;
    vector<int> path;
    function<void(int)> dfs = [&](int start) {
        int need = k - (int)path.size();
        if (need == 0) { answer.push_back(path); return; }
        for (int value = start; value <= n - need + 1; ++value) {
            path.push_back(value);
            dfs(value + 1);
            path.pop_back();
        }
    };
    dfs(1);
    return answer;
}

1.4 组合总和：可复用与不可复用只差一项关键状态

允许无限使用某个候选时，选择i后下一层仍从i开始；每个下标最多使用一次时，下一层从i+1开始。两者都用start规范顺序，防止同一组合的排列被反复输出。

无限复用必须有保证终止的量。本章要求候选严格为正，剩余目标每次严格减少；0会让剩余目标不变，负数可能让它增大，所以不能直接放入同一递归模板。

推导 / 不变量

每个递归节点都代表一个合法子集，进入函数就记录。循环选择第 i 个元素后递归到 i+1，再撤销。

vector<vector<int>> subsets(const vector<int>& a) {
    vector<vector<int>> ans;
    vector<int> path;
    function<void(int)> dfs=[&](int start) {
        ans.push_back(path);
        for (int i=start;i<(int)a.size();++i) {
            path.push_back(a[i]);
            dfs(i+1);
            path.pop_back();
        }
    };
    dfs(0);
    return ans;
}

组合选 K 个时只有 path.size()==K 才记录，并可用剩余数量剪枝。元素允许重复使用时，递归传 i 而不是 i+1，但需保证问题能终止。

1.5 组合总和I：正数候选、允许复用

本接口把候选视为数值种类，先去重；target=0返回一个空组合，空候选且正目标返回无答案。排序后当前值超过remaining，后续更大值也不可行，可以break。

设最小候选c、深度D=floor(target/c)、不同候选数m，粗上界为指数级搜索，加上所有输出路径长度；不能写O(target·m)，那是某些DP的状态复杂度。辅助空间O(m+D)，不含输出；候选为空时不定义c，直接结束。

vector<vector<int>> combinationUnlimited(vector<int> candidates, int target) {
    if (target < 0 || target > 100 || candidates.size() > 20)
        throw invalid_argument("unsupported target or candidate count");
    for (int value : candidates)
        if (value <= 0) throw invalid_argument("positive candidates required");
    sort(candidates.begin(), candidates.end());
    candidates.erase(unique(candidates.begin(), candidates.end()), candidates.end());
    vector<vector<int>> answer;
    vector<int> path;
    function<void(int,int)> dfs = [&](int start, int remaining) {
        if (remaining == 0) { answer.push_back(path); return; }
        for (int i = start; i < (int)candidates.size(); ++i) {
            if (candidates[i] > remaining) break;
            path.push_back(candidates[i]);
            dfs(i, remaining - candidates[i]);
            path.pop_back();
        }
    };
    dfs(0, target);
    return answer;
}

1.6 组合总和II：每个位置一次，同层跳过相等值

相同数值的不同位置都可能被使用，例如[1,1,2]、target=2有[1,1]和[2]，不能先把输入整体去重。i>start只跳过本层重复起点，下一层仍能选择第二个1。

最坏时间可用O(n·2^n)上界（含路径复制），辅助O(n)，输出另算；实际受正数和剪枝影响。接口按值接收候选，排序不会改调用者原数组。

vector<vector<int>> combinationOnce(vector<int> candidates, int target) {
    if (target < 0 || target > 100 || candidates.size() > 20)
        throw invalid_argument("unsupported target or candidate count");
    for (int value : candidates)
        if (value <= 0) throw invalid_argument("positive candidates required");
    sort(candidates.begin(), candidates.end());
    vector<vector<int>> answer;
    vector<int> path;
    function<void(int,int)> dfs = [&](int start, int remaining) {
        if (remaining == 0) { answer.push_back(path); return; }
        for (int i = start; i < (int)candidates.size(); ++i) {
            if (i > start && candidates[i] == candidates[i - 1]) continue;
            if (candidates[i] > remaining) break;
            path.push_back(candidates[i]);
            dfs(i + 1, remaining - candidates[i]);
            path.pop_back();
        }
    };
    dfs(0, target);
    return answer;
}

面试追问：关键点完整解答

为什么子集进入函数就记录，排列却等满长才记录？

子集任意长度都合法，每个路径前缀就是一个子集；全排列要求每个位置恰好使用一次，未满长只是中间状态。记录时机由答案定义决定，不是统一模板规定。

start解决了什么重复，能代替used吗？

start强制下标递增，消除组合的顺序重复；排列需要允许不同先后次序，不能用递增下标限制，通常用used记录本条路径已选位置。

选K个时为什么上界是n-need+1？

从候选value到n总共有n-value+1个数，要至少填满need个位置，因此n-value+1>=need，整理得到value<=n-need+1。

无限复用为什么传i，而不是i+1？

传i保留当前候选，允许下一层再次使用；传i+1会把当前下标永久排除，变成每个位置只用一次的模型。终止性必须另由正候选使remaining下降保证。

候选含0或负数能直接套组合总和I吗？

不能。0会让状态原地递归，负数可使剩余金额上升；还可能存在无限多个满足条件的组合。需要限制使用次数或重新定义有限状态空间。

组合总和II为什么不能直接unique整个数组？

题目中的相同值来自不同可用位置，可能需要同时选多个。应保留次数，仅对同一层的等价分支去重；全局unique会减少可用次数，漏掉合法组合。

09.02

全排列与同层去重

知识与适用场景

排列允许每层从所有未使用元素中选择，因此需要 used 数组。输入有重复值时，仅仅按下标区分会输出重复排列，需要排序并控制相同元素的选择顺序。

2.1 全排列的不变量：used与path必须同步

path按顺序保存本次排列的前缀，used[i]恰好表示下标i已经出现在该前缀。每层扫描所有未使用位置，选择后置true并push，返回后pop并置false。递归深度等于已选数量，最多n层。

即使两个位置值相等，它们也是两个可用实例。基础去重条件i>0且a[i]==a[i-1]且!used[i-1]，给相等实例规定选择先后次序：前一个尚未使用时，不允许越过它从后一个启动分支；前一个已在祖先路径中时，后一个可以继续使用。

vector<vector<int>> permuteUnique(vector<int> a) {
    sort(a.begin(),a.end());
    vector<vector<int>> ans;
    vector<int> path;
    vector<bool> used(a.size(),false);
    function<void()> dfs=[&] {
        if (path.size()==a.size()) { ans.push_back(path); return; }
        for (int i=0;i<(int)a.size();++i) {
            if (used[i]) continue;
            if (i>0 && a[i]==a[i-1] && !used[i-1]) continue;
            used[i]=true; path.push_back(a[i]);
            dfs();
            path.pop_back(); used[i]=false;
        }
    };
    dfs();
    return ans;
}
复杂度
无重复时约 O(n·n!) 时间和输出空间，辅助 O(n)。重复会减少实际分支。
易错点与边界
不要把同层去重写成只要值相同就跳过，否则无法同时选择两个值相同的不同元素。

2.4 排列的另一种状态：剩余频次

排序+used按位置管理同值实例；频次版则把相等位置合成一种候选，每次选择某个值就扣一次剩余数量。分支直接按不同值展开，天然不会产生同值位置交换的重复。

频次版仍需保证每次选择后恢复计数，且答案拷贝不能引用之后会被改变的path。所有计数恢复后，再次调用函数不会受到上次递归影响。

2.5 频次版唯一全排列

空数组返回一个空排列。若唯一排列数P=n!/∏cj!，仅保存结果就需O(nP)；该实现还会在每个内部节点扫描m个不同值，精确表述为O(m·搜索节点数+nP)，最坏仍在O(n·n!)量级。路径、计数和递归O(n)，输出另算。

vector<vector<int>> frequencyPermutations(vector<int> a) {
    if (a.size() > 9) throw invalid_argument("permutation output too large");
    sort(a.begin(), a.end());
    vector<int> values, count;
    for (int x : a) {
        if (values.empty() || values.back() != x) {
            values.push_back(x); count.push_back(1);
        } else ++count.back();
    }
    vector<vector<int>> answer;
    vector<int> path;
    function<void()> dfs = [&] {
        if (path.size() == a.size()) { answer.push_back(path); return; }
        for (size_t i = 0; i < values.size(); ++i) {
            if (count[i] == 0) continue;
            --count[i]; path.push_back(values[i]);
            dfs();
            path.pop_back(); ++count[i];
        }
    };
    dfs();
    return answer;
}

2.6 电话号码字母组合：每层对应一个输入位置

vector<string> phoneLetters(const string& digits) {
    const array<string, 10> letters{"", "", "abc", "def", "ghi", "jkl",
                                  "mno", "pqrs", "tuv", "wxyz"};
    if (digits.size() > 8) throw invalid_argument("output too large");
    for (char c : digits)
        if (c < '2' || c > '9') throw invalid_argument("digits 2..9 required");
    if (digits.empty()) return {};
    vector<string> answer;
    string path;
    function<void(size_t)> dfs = [&](size_t index) {
        if (index == digits.size()) { answer.push_back(path); return; }
        for (char c : letters[digits[index] - '0']) {
            path.push_back(c); dfs(index + 1); path.pop_back();
        }
    };
    dfs(0);
    return answer;
}

排列为什么不能像组合一样递归传i+1？

那会强制所选下标递增，只保留每组下标的一种顺序，漏掉[2,1]等合法排列。排列每层都可从所有未使用位置选择，顺序本身就是答案信息。

!used[i-1]到底表示什么？

它表示前一个同值实例不在当前祖先路径上。此时选择后一个会与同层先选前一个产生等价分支，所以跳过；若前一个已使用，后一个是另一份可用实例，应允许选择。

子集去重为何写i>start，而不是i>0？

去重只针对当前循环层的兄弟候选。新一层的第一个i=start即使与前一位置值相同，也可能是合法增加一次重复值，不能跳过。

频次版排列如何避免重复？

同一个值只对应一个分支，剩余数量描述还能用几份。交换两个同值下标不再产生不同状态路径，从源头消除了位置身份带来的等价排列。

ans.push_back(path)之后再pop_back会改变已有答案吗？

vector的push_back(path)复制当前vector，已有答案拥有自己的元素。若改成存path的指针、引用或视图，则后续修改会影响观察结果；这种保存方式不适合这里的独立答案。

电话号码为什么没有used标记？

每层由index唯一指定处理哪个输入位置，递归到index+1自然保证每个位置用一次。used解决自由挑选位置时的复用问题，这里不存在该自由度。

剪枝：括号生成与约束传播

知识与适用场景

剪枝应基于明确的不可行条件。生成 n 对括号时，任意前缀右括号数都不能超过左括号数，否则之后再补字符也无法修复该前缀。

3.1 剪枝是一项正确性声明

可行性剪枝证明当前前缀已无法补成合法解；最优性剪枝证明即使乐观补全也不优于已有最优值；排序后的break还要求后续所有候选同样不可行。只因“看起来不太可能”就跳过会漏解。

括号生成的约束right<=left对所有前缀成立。一旦某个前缀右括号更多，未来追加字符不能改写过去这个前缀，因此整条分支必无解。相反，组合和超过target是否可剪，依赖剩余数是否全非负。

vector<vector<string>> solveNQueens(int n) {
    if (n < 0 || n > 12) throw invalid_argument("require 0 <= n <= 12");
    if (n == 0) return {{}};
    vector<vector<string>> answer;
    vector<string> board(n, string(n, '.'));
    vector<bool> column(n, false), down(2*n-1, false), up(2*n-1, false);
    function<void(int)> dfs = [&](int row) {
        if (row == n) { answer.push_back(board); return; }
        for (int col = 0; col < n; ++col) {
            int d = row - col + n - 1, u = row + col;
            if (column[col] || down[d] || up[u]) continue;
            board[row][col] = 'Q';
            column[col] = down[d] = up[u] = true;
            dfs(row + 1);
            column[col] = down[d] = up[u] = false;
            board[row][col] = '.';
        }
    };
    dfs(0);
    return answer;
}

    vector<string> ans;
    string path;
    function<void(int,int)> dfs=[&](int left,int right) {
        if (right==n) { ans.push_back(path); return; }
        if (left<n) {
            path.push_back('('); dfs(left+1,right); path.pop_back();
        }
        if (right<left) {

bool wordExists(const vector<string>& board, const string& word) {
    if (board.empty()) return word.empty();
    size_t columns = board[0].size();
    for (const auto& row : board)
        if (row.size() != columns) throw invalid_argument("rectangular board required");
    if (board.size() > 20 || columns > 20)
        throw invalid_argument("board too large for this example");
    if (word.empty()) return true;
    if (columns == 0 || word.size() > board.size()*columns) return false;
    array<int,256> available{}, needed{};
    for (const auto& row : board)
        for (unsigned char c : row) ++available[c];
    for (unsigned char c : word)
        if (++needed[c] > available[c]) return false;
    int rows = (int)board.size(), cols = (int)columns;
    vector<vector<bool>> used(rows, vector<bool>(cols, false));
    const int dr[4] = {-1,1,0,0}, dc[4] = {0,0,-1,1};
    function<bool(int,int,size_t)> dfs = [&](int r,int c,size_t index) {
        if (used[r][c] || board[r][c] != word[index]) return false;
        if (index + 1 == word.size()) return true;
        used[r][c] = true;
        bool found = false;
        for (int direction=0; direction<4 && !found; ++direction) {
            int nr=r+dr[direction], nc=c+dc[direction];
            if (nr>=0 && nr<rows && nc>=0 && nc<cols)
                found = dfs(nr,nc,index+1);
        }
        used[r][c] = false;
        return found;
    };
    for (int r=0;r<rows;++r)
        for (int c=0;c<cols;++c)
            if (dfs(r,c,0)) return true;
    return false;
}

bool solveSudoku(vector<string>& board) {
    if (board.size()!=9) throw invalid_argument("9 rows required");
    for (const auto& line:board)
        if (line.size()!=9) throw invalid_argument("9 columns required");
    array<unsigned,9> row{}, col{}, box{};
    vector<pair<int,int>> empty;
    for (int r=0;r<9;++r) for (int c=0;c<9;++c) {
        if (board[r][c]=='.') { empty.push_back({r,c}); continue; }
        if (board[r][c]<'1' || board[r][c]>'9') throw invalid_argument("bad symbol");
        unsigned bit=1U<<(board[r][c]-'1');
        int b=(r/3)*3+c/3;
        if ((row[r]|col[c]|box[b])&bit) throw invalid_argument("conflicting clues");
        row[r]|=bit; col[c]|=bit; box[b]|=bit;
    }
    auto candidates = [&](int r,int c) {
        return 511U & ~(row[r]|col[c]|box[(r/3)*3+c/3]);
    };
    auto countBits = [](unsigned x) {
        int count=0;
        while (x) { x&=x-1; ++count; }
        return count;
    };
    function<bool(size_t)> dfs = [&](size_t index) {
        if (index==empty.size()) return true;
        size_t best=index;
        int minimum=10;
        for (size_t i=index;i<empty.size();++i) {
            auto [r,c]=empty[i];
            int count=countBits(candidates(r,c));
            if (count<minimum) { minimum=count; best=i; }
        }
        if (minimum==0) return false;
        swap(empty[index],empty[best]);
        auto [r,c]=empty[index];
        int b=(r/3)*3+c/3;
        unsigned options=candidates(r,c);
        for (int digit=0;digit<9;++digit) {
            unsigned bit=1U<<digit;
            if (!(options&bit)) continue;
            row[r]|=bit; col[c]|=bit; box[b]|=bit;
            board[r][c]=char('1'+digit);
            if (dfs(index+1)) return true;
            board[r][c]='.';
            row[r]^=bit; col[c]^=bit; box[b]^=bit;
        }
        swap(empty[index],empty[best]);
        return false;
    };
    return dfs(0);
}

面试追问：关键点完整解答

括号前缀右括号多于左括号，之后补左括号能修复吗？

不能。合法括号要求每个前缀都满足右数不超过左数，追加字符不能改变已出现的错误前缀，因此该分支永远无解。

N皇后为何只存列与两组对角线，不存行？

递归层数直接决定当前行，每行只放一次，行约束由搜索结构保证。列和两种对角线仍可能被祖先行占用，必须显式记录。

单词搜索找到答案后为什么还恢复visited？

visited代表当前路径；统一在返回前恢复能维持函数契约，防止调用逻辑复用状态时出错。特别是如果改成覆盖board标记，更必须在成功早退前恢复，否则会修改用户输入。

数独成功时为何反而不撤销数字？

该接口的目标就是原地写入一份解，成功路径上的修改是输出。失败分支必须恢复，成功分支有意保留；是否撤销取决于公开接口契约，而不是所有回溯都机械pop。

MRV会不会因为优先换格子而漏掉解？

不会，它只改变先决定哪个空格，仍枚举该格所有合法数字。与真正剪枝不同，MRV依赖尽早暴露约束冲突来减少实际搜索，不提供多项式最坏复杂度保证。

最优性剪枝的乐观下界可以随便估计吗？

不可以。最小化问题中，下界必须不大于该分支真实能达到的最优成本；只有下界已经不小于当前best时，才能证明分支不会改进。过高的估计可能剪掉最优解。

知识与适用场景

4.1 记忆化缓存的是函数值，不是这次来过的标记

bool wordBreakMemo(const string& text, const vector<string>& dictionary) {
    if (text.size() > 10000) throw invalid_argument("text too large");
    for (const auto& word : dictionary)
        if (word.empty()) throw invalid_argument("empty word forbidden");
    vector<int> memo(text.size() + 1, -1);
    memo[text.size()] = 1;
    function<bool(size_t)> dfs = [&](size_t start) {
        if (memo[start] != -1) return memo[start] != 0;
        for (const string& word : dictionary) {
            if (word.size() <= text.size() - start &&
                text.compare(start, word.size(), word) == 0 &&
                dfs(start + word.size())) {
                memo[start] = 1;
                return true;
            }
        }
        memo[start] = 0;
        return false;
    };
    return dfs(0);
}

int coinChangeMemo(const vector<int>& coins, int amount) {
    if (amount<0) return -1;
    const int INF=INT_MAX/2;
    vector<int> memo(amount+1,-1);
    function<int(int)> dfs=[&](int rem) {
        if (rem==0) return 0;
        if (memo[rem]!=-1) return memo[rem];
        int best=INF;
        for (int c:coins) {
            if (c<=0) throw invalid_argument("positive coins required");
            if (c<=rem) best=min(best,1+dfs(rem-c));
        }
        return memo[rem]=best;
    };
    int ans=dfs(amount);
    return ans==INF ? -1 : ans;
}

每个根运算符切分都组合左结果与右结果的笛卡尔积，保证不漏括号化。n个操作数有Catalan(n-1)种结构；记忆化只避免子区间重复求解，不会把结果列表变成多项式。令M为所有子区间结果数量之和，不含输入解析的时间O(n³+M)，解析另需O(表达式字符数)、空间O(n²+M)，另有O(n)栈与最终返回副本。

vector<long long> expressionResults(const string& expression) {
    vector<int> numbers;
    vector<char> operators;
    size_t pos = 0;
    while (pos < expression.size()) {
        if (expression[pos] < '0' || expression[pos] > '9')
            throw invalid_argument("expected nonnegative integer");
        int value = 0;
        while (pos < expression.size() && expression[pos] >= '0' && expression[pos] <= '9') {
            int digit = expression[pos++] - '0';
            if (value > (100 - digit) / 10) throw invalid_argument("number exceeds 100");
            value = value * 10 + digit;
        }
        numbers.push_back(value);
        if (numbers.size() > 8) throw invalid_argument("too many operands");
        if (pos == expression.size()) break;
        char op = expression[pos++];
        if (op != '+' && op != '-' && op != '*') throw invalid_argument("bad operator");
        operators.push_back(op);
        if (pos == expression.size()) throw invalid_argument("missing operand");
    }
    if (numbers.empty()) throw invalid_argument("empty expression");
    int n = (int)numbers.size();
    vector<vector<vector<long long>>> memo(n, vector<vector<long long>>(n));
    vector<vector<bool>> ready(n, vector<bool>(n, false));
    function<const vector<long long>&(int,int)> solve =
        [&](int left, int right) -> const vector<long long>& {
            if (ready[left][right]) return memo[left][right];
            auto& result = memo[left][right];
            if (left == right) result.push_back(numbers[left]);
            else for (int split = left; split < right; ++split) {
                const auto& a = solve(left, split);
                const auto& b = solve(split + 1, right);
                for (long long x : a) for (long long y : b) {
                    char op = operators[split];
                    if (op == '+') result.push_back(x + y);
                    else if (op == '-') result.push_back(x - y);
                    else result.push_back(x * y);
                }
            }
            ready[left][right] = true;
            return result;
        };
    return solve(0, n - 1);
}

面试追问：关键点完整解答

缓存键为什么不能随意省掉start或used？

只有在省略信息不影响未来可选项与目标时才安全。组合计数的start决定还能使用哪些候选，单词路径的used决定哪些格子禁用；省掉它们会合并本质不同的子问题。

记忆化为什么要缓存失败状态？

不同前缀也会反复到达同一个无解后缀。只缓存成功会让无解区域被重复搜索，仍可能指数退化。应把未计算、成功、失败明确区分。

memo能降低递归深度吗？

通常只减少重复调用总数，不改变最长依赖链。零钱兑换有1元硬币时可能沿金额每次减1递归，深度仍O(amount)；需要迭代DP来消除系统栈风险。

表达式求值结果为什么不去重？

题目通常按不同括号化输出结果，即使数值相同也保留。例如两个不同运算树都可能得到-10。若要求不同数值集合才额外去重，不能悄悄改变答案语义。

分治最大子段只返回best够不够？

不够，父区间还需要知道能跨边界连接的最大后缀与前缀，以及整段sum。只返回内部最优无法正确计算跨界候选，需要一份可合并的完整报告。

为什么这里最大子段分治是O(n)而不是O(nlogn)？

每个递归节点只合并四个常数大小统计，不再扫描整个区间；二叉递归树共有O(n)节点。分治复杂度由子问题与合并工作量共同决定，不是见到二分就统一乘logn。

bool wordExists(const vector<string>& board, const string& word) {
    if (board.empty()) return word.empty();
    size_t columns = board[0].size();
    for (const auto& row : board)
        if (row.size() != columns) throw invalid_argument("rectangular board required");
    if (board.size() > 20 || columns > 20)
        throw invalid_argument("board too large for this example");
    if (word.empty()) return true;
    if (columns == 0 || word.size() > board.size()*columns) return false;
    array<int,256> available{}, needed{};
    for (const auto& row : board)
        for (unsigned char c : row) ++available[c];
    for (unsigned char c : word)
        if (++needed[c] > available[c]) return false;
    int rows = (int)board.size(), cols = (int)columns;
    vector<vector<bool>> used(rows, vector<bool>(cols, false));
    const int dr[4] = {-1,1,0,0}, dc[4] = {0,0,-1,1};
    function<bool(int,int,size_t)> dfs = [&](int r,int c,size_t index) {
        if (used[r][c] || board[r][c] != word[index]) return false;
        if (index + 1 == word.size()) return true;
        used[r][c] = true;
        bool found = false;
        for (int direction=0; direction<4 && !found; ++direction) {
            int nr=r+dr[direction], nc=c+dc[direction];
            if (nr>=0 && nr<rows && nc>=0 && nc<cols)
                found = dfs(nr,nc,index+1);
        }
        used[r][c] = false;
        return found;
    };
    for (int r=0;r<rows;++r)
        for (int c=0;c<cols;++c)
            if (dfs(r,c,0)) return true;
    return false;
}

bool solveSudoku(vector<string>& board) {
    if (board.size()!=9) throw invalid_argument("9 rows required");
    for (const auto& line:board)
        if (line.size()!=9) throw invalid_argument("9 columns required");
    array<unsigned,9> row{}, col{}, box{};
    vector<pair<int,int>> empty;
    for (int r=0;r<9;++r) for (int c=0;c<9;++c) {
        if (board[r][c]=='.') { empty.push_back({r,c}); continue; }
        if (board[r][c]<'1' || board[r][c]>'9') throw invalid_argument("bad symbol");
        unsigned bit=1U<<(board[r][c]-'1');
        int b=(r/3)*3+c/3;
        if ((row[r]|col[c]|box[b])&bit) throw invalid_argument("conflicting clues");
        row[r]|=bit; col[c]|=bit; box[b]|=bit;
    }
    auto candidates = [&](int r,int c) {
        return 511U & ~(row[r]|col[c]|box[(r/3)*3+c/3]);
    };
    auto countBits = [](unsigned x) {
        int count=0;
        while (x) { x&=x-1; ++count; }
        return count;
    };
    function<bool(size_t)> dfs = [&](size_t index) {
        if (index==empty.size()) return true;
        size_t best=index;
        int minimum=10;
        for (size_t i=index;i<empty.size();++i) {
            auto [r,c]=empty[i];
            int count=countBits(candidates(r,c));
            if (count<minimum) { minimum=count; best=i; }
        }
        if (minimum==0) return false;
        swap(empty[index],empty[best]);
        auto [r,c]=empty[index];
        int b=(r/3)*3+c/3;
        unsigned options=candidates(r,c);
        for (int digit=0;digit<9;++digit) {
            unsigned bit=1U<<digit;
            if (!(options&bit)) continue;
            row[r]|=bit; col[c]|=bit; box[b]|=bit;
            board[r][c]=char('1'+digit);
            if (dfs(index+1)) return true;
            board[r][c]='.';
            row[r]^=bit; col[c]^=bit; box[b]^=bit;
        }
        swap(empty[index],empty[best]);
        return false;
    };
    return dfs(0);
}

vector<long long> expressionResults(const string& expression) {
    vector<int> numbers;
    vector<char> operators;
    size_t pos = 0;
    while (pos < expression.size()) {
        if (expression[pos] < '0' || expression[pos] > '9')
            throw invalid_argument("expected nonnegative integer");
        int value = 0;
        while (pos < expression.size() && expression[pos] >= '0' && expression[pos] <= '9') {
            int digit = expression[pos++] - '0';
            if (value > (100 - digit) / 10) throw invalid_argument("number exceeds 100");
            value = value * 10 + digit;
        }
        numbers.push_back(value);
        if (numbers.size() > 8) throw invalid_argument("too many operands");
        if (pos == expression.size()) break;
        char op = expression[pos++];
        if (op != '+' && op != '-' && op != '*') throw invalid_argument("bad operator");
        operators.push_back(op);
        if (pos == expression.size()) throw invalid_argument("missing operand");
    }
    if (numbers.empty()) throw invalid_argument("empty expression");
    int n = (int)numbers.size();
    vector<vector<vector<long long>>> memo(n, vector<vector<long long>>(n));
    vector<vector<bool>> ready(n, vector<bool>(n, false));
    function<const vector<long long>&(int,int)> solve =
        [&](int left, int right) -> const vector<long long>& {
            if (ready[left][right]) return memo[left][right];
            auto& result = memo[left][right];
            if (left == right) result.push_back(numbers[left]);
            else for (int split = left; split < right; ++split) {
                const auto& a = solve(left, split);
                const auto& b = solve(split + 1, right);
                for (long long x : a) for (long long y : b) {
                    char op = operators[split];
                    if (op == '+') result.push_back(x + y);
                    else if (op == '-') result.push_back(x - y);
                    else result.push_back(x * y);
                }
            }
            ready[left][right] = true;
            return result;
        };
    return solve(0, n - 1);
}

            path.push_back(a[i]); sum+=a[i];
        }
        if (!target || sum==*target) answer.insert(path);
    }
    return {answer.begin(),answer.end()};
}
vector<vector<int>> bruteUnlimited(vector<int> candidates,int target) {
    sort(candidates.begin(),candidates.end());
    candidates.erase(unique(candidates.begin(),candidates.end()),candidates.end());
    vector<vector<int>> answer;
    vector<int> path;
    function<void(size_t,int)> dfs=[&](size_t index,int remaining) {
        if (index==candidates.size()) {
            if (remaining==0) answer.push_back(path);
            return;
        }
        size_t saved=path.size();
        int value=candidates[index];
        for (int count=0;count<=remaining/value;++count) {
            path.resize(saved);
            path.insert(path.end(),count,value);
            dfs(index+1,remaining-count*value);
        }
        path.resize(saved);
    };
    dfs(0,target);
    return canonical(answer);
}
bool bruteWord(const vector<string>& board,const string& word) {
    if (word.empty()) return true;
    int rows=(int)board.size(),cols=(int)board[0].size();
    function<bool(int,size_t,unsigned)> dfs=[&](int position,size_t index,unsigned used) {
        if ((used&(1U<<position)) || board[position/cols][position%cols]!=word[index])
            return false;
        if (index+1==word.size()) return true;
        used|=1U<<position;
        for (int next=0;next<rows*cols;++next)
            if (abs(position/cols-next/cols)+abs(position%cols-next%cols)==1 &&
                dfs(next,index+1,used)) return true;
        return false;
    };
    for (int position=0;position<rows*cols;++position)
        if (dfs(position,0,0)) return true;
    return false;
}
bool validSudokuSolution(const vector<string>& board) {
    for (const auto& row:board) for (char c:row) if (c<'1'||c>'9') return false;
    for (int i=0;i<9;++i) {
        unsigned row=0,col=0,box=0;
        for (int j=0;j<9;++j) {
            row|=1U<<(board[i][j]-'1');
            col|=1U<<(board[j][i]-'1');
            box|=1U<<(board[(i/3)*3+j/3][(i%3)*3+j%3]-'1');
        }
        if (row!=511 || col!=511 || box!=511) return false;
    }
    return true;
}

章末自测与完整解答

1. 子集输入为空时，是0个答案还是1个答案？

数学上有一个空子集，因此返回包含空vector的结果。恰选0个与空数组全排列也采用一个空解；但电话号码空输入等业务接口可约定无结果，必须明确语义。

2. [1,1,2]目标为2、每个位置最多用一次，有哪些答案？

有[1,1]和[2]。全局去重会漏掉前者；同层跳过第二个1只是避免重复首选分支，不妨碍下一层再选它。

3. 排列去重中前一个相同值已used，后一个为什么能选？

前一个是祖先选择，不是本层重复分支。还剩下另一个同值实例可用，允许选择才能生成含多个1的合法排列。

4. 当前组合和超过目标，一定可以剪枝吗？

只有后续无法降低和时才成立，例如剩余候选全为正数。若允许负数，继续选取可能降低和，直接剪会漏解。

5. 单词搜索能只缓存位置与字符下标吗？

一般不能，因为路径内已经占用哪些格子会影响后续可行性。不同visited集合下的相同位置与字符下标不是同一个子问题。

6. 数独的MRV保证多项式时间吗？

不保证。它只是优先选择约束最强的变量，常能更早发现矛盾，但最坏搜索仍可能指数。正确性来自仍枚举全部合法候选，而不是依靠启发式承诺。

7. 缓存了所有rem后，零钱兑换递归还会栈溢出吗？

可能。记忆化减少重复状态，却可能仍先走一条每次减1的长依赖链。大金额时用迭代DP能避免系统递归栈深限制。

8. 最大子段分治为什么返回四个量，而不只返回最优值？

父区间需要判断内部最优和跨界最优。跨界必须用左最大后缀加右最大前缀；生成父前后缀还需整段sum，因此四项共同构成可组合状态。
