09.01

子集与组合：start 消除排列重复

知识与适用场景

子集关心选哪些元素，不关心选取顺序，因此每次只能从上一次下标之后继续选。路径对应已经选取的元素，start 对应下一层可以选择的最小下标。

推导 / 不变量

每个递归节点都代表一个合法子集，进入函数就记录。循环选择第 i 个元素后递归到 i+1，再撤销。

手推一个例子

[1,2]：先记录 []，选择 1 得到 [1]，再选 2 得到 [1,2]；回到根再选 2 得到 [2]，不会生成 [2,1]。

C++17
下载 .cpp
vector<vector<int>> subsets(const vector<int>& a) {
    vector<vector<int>> ans;
    vector<int> path;
    function<void(int)> dfs=[&](int start) {
        ans.push_back(path);
        for (int i=start;i<(int)a.size();++i) {
            path.push_back(a[i]);
            dfs(i+1);
            path.pop_back();
        }
    };
    dfs(0);
    return ans;
}
复杂度
时间 O(n·2^n)，输出 O(n·2^n)，路径和递归栈 O(n)。
易错点与边界
组合选 K 个时只有 path.size()==K 才记录，并可用剩余数量剪枝。元素允许重复使用时，递归传 i 而不是 i+1，但需保证问题能终止。

经典考点与练习

练习：LeetCode 78 子集、77 组合、39 组合总和。

09.02

全排列与同层去重

知识与适用场景

排列允许每层从所有未使用元素中选择，因此需要 used 数组。输入有重复值时，仅仅按下标区分会输出重复排列，需要排序并控制相同元素的选择顺序。

推导 / 不变量

当 a[i]==a[i-1] 且前一个相同元素尚未被本条路径使用时，跳过 i。这表示同一层只允许最靠前的相同元素作为分支起点。

手推一个例子

[1,1,2]：根层只能选择第一个 1；在它的下一层，第二个 1 可以被选择，因为前一个已经 used，最终得到三种唯一排列。

C++17
下载 .cpp
vector<vector<int>> permuteUnique(vector<int> a) {
    sort(a.begin(),a.end());
    vector<vector<int>> ans;
    vector<int> path;
    vector<bool> used(a.size(),false);
    function<void()> dfs=[&] {
        if (path.size()==a.size()) { ans.push_back(path); return; }
        for (int i=0;i<(int)a.size();++i) {
            if (used[i]) continue;
            if (i>0 && a[i]==a[i-1] && !used[i-1]) continue;
            used[i]=true; path.push_back(a[i]);
            dfs();
            path.pop_back(); used[i]=false;
        }
    };
    dfs();
    return ans;
}
复杂度
无重复时约 O(n·n!) 时间和输出空间，辅助 O(n)。重复会减少实际分支。
易错点与边界
不要把同层去重写成只要值相同就跳过，否则无法同时选择两个值相同的不同元素。

经典考点与练习

练习：LeetCode 46 全排列、47 全排列 II、90 子集 II。

09.03

剪枝：括号生成与约束传播

知识与适用场景

剪枝应基于明确的不可行条件。生成 n 对括号时，任意前缀右括号数都不能超过左括号数，否则之后再补字符也无法修复该前缀。

推导 / 不变量

只有 left<n 才能放左括号，只有 right<left 才能放右括号。相比枚举 2^(2n) 个字符串后检查，这样只进入合法前缀。

手推一个例子

n=2：空串只能放 '('；当路径为 '()' 时只能再放 '('；最终得到 '(())'、'()()'。

C++17
下载 .cpp
vector<string> generateParenthesis(int n) {
    if (n<0) return {};
    vector<string> ans;
    string path;
    function<void(int,int)> dfs=[&](int left,int right) {
        if (right==n) { ans.push_back(path); return; }
        if (left<n) {
            path.push_back('('); dfs(left+1,right); path.pop_back();
        }
        if (right<left) {
            path.push_back(')'); dfs(left,right+1); path.pop_back();
        }
    };
    dfs(0,0);
    return ans;
}
复杂度
共有卡特兰数 Cn 个答案，时间 O(n·Cn)，辅助空间 O(n)，输出 O(n·Cn)。
易错点与边界
N 皇后可以用列与两类对角线占用表剪枝；网格单词搜索必须撤销 visited，不能永久标记路径上的节点。

经典考点与练习

练习：LeetCode 22 括号生成、51 N 皇后、79 单词搜索。

09.04

从暴力递归到记忆化

知识与适用场景

如果不同决策路径到达相同子问题，重复计算可以用缓存消除。缓存键必须包含决定未来结果的所有信息，不能省略仍影响可行性的状态。

推导 / 不变量

零钱兑换最少数量中，固定硬币集合后，剩余金额 rem 就完整决定子问题。f(rem)=1+min f(rem-coin)，rem=0 为 0，不可达为 INF。

手推一个例子

硬币 [1,3,4]，金额 6：选择 1 后剩 5，选择 3 后剩 3；不同分支都会再次遇到 rem=2、rem=1，缓存使每个金额只算一次。

C++17
下载 .cpp
int coinChangeMemo(const vector<int>& coins, int amount) {
    if (amount<0) return -1;
    const int INF=INT_MAX/2;
    vector<int> memo(amount+1,-1);
    function<int(int)> dfs=[&](int rem) {
        if (rem==0) return 0;
        if (memo[rem]!=-1) return memo[rem];
        int best=INF;
        for (int c:coins) {
            if (c<=0) throw invalid_argument("positive coins required");
            if (c<=rem) best=min(best,1+dfs(rem-c));
        }
        return memo[rem]=best;
    };
    int ans=dfs(amount);
    return ans==INF ? -1 : ans;
}
复杂度
时间 O(amount·币种数)，缓存 O(amount)，最深递归 O(amount/minCoin)。金额很大应改用递推。
易错点与边界
路径本身影响结果时，不能只缓存当前位置，例如允许路径内不重复访问的图搜索。分治子问题通常独立，记忆化针对重叠子问题。

经典考点与练习

练习：LeetCode 322 零钱兑换、139 单词拆分；在第 12 章改写成迭代 DP。
