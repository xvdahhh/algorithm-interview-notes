# 第 09 章：递归、回溯与分治

## 递归设计

递归需要明确三件事：

1. 函数定义：参数和返回值代表什么。
2. 终止条件：最小子问题如何直接求解。
3. 递推关系：当前问题如何依赖规模更小的子问题。

递归不是“调用自己”这么简单，真正关键是保证问题规模严格缩小。

## 回溯框架

回溯是在决策树上进行深度优先搜索：做选择、递归、撤销选择。

```text
backtrack(state, choices):
    if 满足答案条件:
        记录 state 的副本
        return
    for choice in choices:
        if choice 不合法: continue
        做选择
        backtrack(新状态, 新选择集)
        撤销选择
```

## 排列、组合、子集的区别

- 子集：每个元素选或不选，通常用 `start` 保证只向后选择。
- 组合：关心选哪些，不关心顺序；从 `start` 开始枚举。
- 排列：关心顺序；通常使用 `used[]` 标记已选元素。
- 有重复元素时先排序，再在“同一树层”跳过相同选择；不要误删不同树枝上的合法重复值。

## 剪枝

- 可行性剪枝：当前部分解已经违反约束。
- 最优性剪枝：即使继续搜索也不可能优于现有答案。
- 顺序剪枝：排序后发现后续选择只会更差，可直接停止枚举。
- 记忆化：同一状态重复出现时缓存结果，把搜索树压缩为状态图。

## 分治

把问题划分为若干独立子问题，分别求解后合并：

- 归并排序：分成两半排序，再线性合并。
- 快速排序：通过分区让基准就位，再处理左右两侧。
- 逆序对：在归并过程中统计跨左右区间的逆序关系。
- 大整数乘法、最近点对等也是典型分治问题。

## 高频题型

- 全排列、组合总和、子集、N 皇后、数独、单词搜索。
- 电话号码字母组合：每层对应一个数字的候选字符。
- 括号生成：维护已使用左右括号数，任何前缀中右括号不能多于左括号。

## 易错点与自测

- [ ] 记录答案时保存当前路径的副本，而非可变对象引用。
- [ ] 每次递归后完整撤销本层状态。
- [ ] 去重发生在正确的树层。
- [ ] 能估算搜索深度与分支数，说明指数复杂度来源。
- [ ] 能独立写出子集、排列、组合三类模板。
