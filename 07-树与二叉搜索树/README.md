## 遍历基础

- 前序：根—左—右，适合复制树、序列化、先处理父节点。
- 中序：左—根—右，二叉搜索树中可得到有序序列。
- 后序：左—右—根，适合从子树汇总高度、节点数或最优值。
- 层序：使用队列按层 BFS，适合最短层数、右视图、逐层统计。

递归函数一定先写清语义：输入是什么、返回什么、是否通过外部变量记录答案。

## 通用递归框架

```text
solve(node):
    if node == null: return 空树对应值
    leftInfo = solve(node.left)
    rightInfo = solve(node.right)
    currentInfo = 根据 node、leftInfo、rightInfo 合并
    必要时更新全局答案
    return currentInfo
```

很多树题本质是设计“子树向父节点返回的信息”。

## 高频题型

- 最大深度：返回 `1 + max(left,right)`。
- 判断平衡树：后序返回高度，发现高度差超过 1 时提前失败。
- 二叉树直径：每个节点处候选为左高 + 右高，向上只返回单边高度。
- 路径总和：区分路径是否必须从根开始、是否必须到叶、是否可任意起止。
- 最近公共祖先：左右子树分别找到目标时当前节点即答案；BST 可利用大小关系。
- 重建二叉树：前/后序确定根，中序划分左右子树；用哈希表加速定位。
- 序列化：必须记录空节点，否则结构可能不唯一。

## 二叉搜索树（BST）

- 对任一节点，左子树键值小于它，右子树键值大于它；重复值规则需另行约定。
- 中序遍历单调有序，可用于验证 BST、找第 K 小、恢复错误节点。
- 搜索/插入/删除为 `O(h)`；平衡树或合适随机模型下可得 `O(log n)`，普通 BST 不保证平衡，退化链状时为 `O(n)`。
- 验证 BST 应传递合法范围，不能只比较节点与直接孩子。

## 迭代遍历

- 前序：栈中先压右再压左。
- 中序：不断将左链入栈，弹出访问后转向右子树。
- 后序：可用两个栈，或记录上次访问节点。
- 层序：处理每层前记录当前队列长度。

## 易错点与自测

- [ ] 区分“节点深度”和“子树高度”。
- [ ] 空树的高度定义与题目保持一致。
- [ ] 全局答案在多次调用前正确重置。
- [ ] 能写递归和迭代中序遍历。
- [ ] 能说明递归空间是 `O(h)` 而不总是 `O(log n)`。
