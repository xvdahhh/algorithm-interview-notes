07.01

遍历顺序与显式栈

知识与适用场景

前序在进入节点时处理，中序在左子树完成后处理，后序在两个孩子完成后处理。层序使用队列。选择顺序取决于当前计算依赖父节点还是孩子信息。

1.1 三个访问时机与递归调用帧

在函数进入节点时处理是前序；左子树返回后处理是中序；两个孩子都返回后处理是后序。遍历次序取决于依赖，而不是任意背三个字：若父节点需要孩子高度，必须等孩子结果；若孩子需要父路径信息，则在下降前准备。

递归栈保存的不只是节点，还有执行位置、局部变量和返回地址。转成迭代时也要保存等价信息。仅存一个节点指针，不一定能判断后序节点是否已经完成两侧子树。

1.3 迭代中序的栈里究竟存什么

基础代码沿左链入栈时，这些祖先都还没被访问；最上面的节点已没有更左的未访问后代，所以可以弹出访问，再转入它的右子树。栈顶不是“下一个随意取出的点”，而是一个尚未完成中序流程的上下文。

每个节点只入栈、出栈一次，时间O(n)。栈中祖先链长度最多h，辅助空间O(h)，输出数组另占O(n)。若把输出也算进去，就不能把总空间写成O(h)。

1.4 递归三序遍历：只改变记录位置

这是对照学习工具，一次DFS生成三个输出，时间O(n)，调用栈O(h)，三个输出合计仍O(n)。真正只需要一种遍历时，只保留对应输出。所有状态在一次调用内创建，不会被上一棵树的结果污染。

struct TreeNode {
    int val;
    TreeNode *left = nullptr, *right = nullptr;
    explicit TreeNode(int value) : val(value) {}
};

struct Traversals {
    vector<int> preorder, inorder, postorder;
};
void visitOrders(TreeNode* node, Traversals& result) {
    if (!node) return;
    result.preorder.push_back(node->val);
    visitOrders(node->left, result);
    result.inorder.push_back(node->val);
    visitOrders(node->right, result);
    result.postorder.push_back(node->val);
}
Traversals recursiveOrders(TreeNode* root) {
    Traversals result;
    visitOrders(root, result);
    return result;
}
推导 / 不变量

迭代中序用栈保存暂时搁置的祖先：先沿左链入栈，弹出访问，再转到右子树。每个节点入栈、出栈各一次。

struct TreeNode {
    int val; TreeNode *left=nullptr, *right=nullptr;
    explicit TreeNode(int v):val(v){}
};
vector<int> inorder(TreeNode* root) {
    vector<int> ans;
    stack<TreeNode*> st;
    TreeNode* cur=root;
    while (cur || !st.empty()) {
        while (cur) { st.push(cur); cur=cur->left; }
        cur=st.top(); st.pop();
        ans.push_back(cur->val);
        cur=cur->right;
    }
    return ans;
}
复杂度
时间 O(n)，辅助栈 O(h)，输出 O(n)。退化树 h=n，平衡树 h=O(log n)。
易错点与边界
BFS 分层时，进入本层前保存队列大小，不能让新加入的下一层节点参与本层循环。

1.5 迭代前序和后序：显式保存待处理阶段

后序首次遇到节点，先把“回到这里输出”的帧压入，再压右孩子、左孩子。LIFO保证左右处理完后才回到已展开帧。时间O(n)，辅助栈O(h)，输出O(n)。双栈法也可实现后序，但第二个栈保存全部节点时辅助空间为O(n)。

struct TreeNode {
    int val;
    TreeNode *left = nullptr, *right = nullptr;
    explicit TreeNode(int value) : val(value) {}
};

vector<int> preorderIterative(TreeNode* root) {
    vector<int> result;
    if (!root) return result;
    vector<TreeNode*> pending{root};
    while (!pending.empty()) {
        TreeNode* node = pending.back(); pending.pop_back();
        result.push_back(node->val);
        if (node->right) pending.push_back(node->right);
        if (node->left) pending.push_back(node->left);
    }
    return result;
}
vector<int> postorderIterative(TreeNode* root) {
    vector<int> result;
    if (!root) return result;
    vector<pair<TreeNode*, bool>> pending{{root, false}};
    while (!pending.empty()) {
        auto [node, expanded] = pending.back(); pending.pop_back();
        if (expanded) { result.push_back(node->val); continue; }
        pending.push_back({node, true});
        if (node->right) pending.push_back({node->right, false});
        if (node->left) pending.push_back({node->left, false});
    }
    return result;
}

1.6 层序、右视图与最小深度

一层开始时保存队列长度，避免把新入队的下一层算进当前层。BFS首次遇到叶子的深度最小，因为节点按深度非递减出队。只有一个孩子的节点不是叶子。

层序时间O(n)、队列O(w)、输出O(n)。本例右视图为复用逻辑，先生成所有层，故总额外存储O(n)；只需右视图时可直接在BFS每层最后一次出队时记录，将辅助空间降为O(w)。最小深度最坏O(n)、队列O(w)。

struct TreeNode {
    int val;
    TreeNode *left = nullptr, *right = nullptr;
    explicit TreeNode(int value) : val(value) {}
};

vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> result;
    if (!root) return result;
    queue<TreeNode*> pending;
    pending.push(root);
    while (!pending.empty()) {
        size_t width = pending.size();
        vector<int> level;
        for (size_t i = 0; i < width; ++i) {
            TreeNode* node = pending.front(); pending.pop();
            level.push_back(node->val);
            if (node->left) pending.push(node->left);
            if (node->right) pending.push(node->right);
        }
        result.push_back(move(level));
    }
    return result;
}
vector<int> rightSideView(TreeNode* root) {
    vector<int> result;
    for (const auto& level : levelOrder(root)) result.push_back(level.back());
    return result;
}
int minimumDepth(TreeNode* root) {
    if (!root) return 0;
    queue<TreeNode*> pending;
    pending.push(root);
    int depth = 1;
    while (!pending.empty()) {
        size_t width = pending.size();
        for (size_t i = 0; i < width; ++i) {
            TreeNode* node = pending.front(); pending.pop();
            if (!node->left && !node->right) return depth;
            if (node->left) pending.push(node->left);
            if (node->right) pending.push(node->right);
        }
        ++depth;
    }
    return 0;
}

1.7 深度、最小深度与Morris遍历的边界

根深度是从根走来的距离，子树高度是从当前点往下能走多远。用节点数定义最大深度时可写1+max(左高,右高)；最小深度不能无条件写1+min，因为不存在的孩子返回0会被错误当作一条到叶路径。根只有左叶子时最小深度是2，不是1。

Morris遍历通过临时建立前驱到祖先的线索，以O(1)辅助空间完成某些遍历，但会临时修改树。必须恢复每条线索；提前return或异常中断可能留下环。共享读树、并发访问或不允许修改输入时不应直接使用。本章主要模板采用不改结构的栈/队列方法。

面试追问：关键点完整解答

迭代前序为什么先压右孩子？

栈是后进先出，后压左孩子会先访问左子树，从而得到根左右。若先压左再压右，得到的是根右左。压栈顺序和访问顺序相反。

后序显式栈中的expanded标记表示什么？

它表示这个节点的孩子任务已经在栈中安排，回到该帧时应访问节点而不再展开。先压回访帧再压孩子，保证回访发生在两侧任务完成之后。

BFS为什么不能在for条件里反复用queue.size()？

处理本层时会弹出当前层、加入下一层，队列大小不断变化。必须先固定本层节点数，否则可能过早结束或混入下一层，破坏层号和右视图结果。

最小深度为什么不是1+min(leftDepth,rightDepth)？

若一侧为空，它不是一条到叶的有效路径；返回0会错误优于真实孩子。递归写法要单独处理缺失孩子，或者用BFS在第一次遇到真正叶子时返回。

树遍历的空间为什么不总是O(logn)？

普通二叉树可能退化为链，h=n，DFS栈最坏线性。BFS存储取决于层宽w，完全二叉树底层可能有约n/2个节点。输出数组还需另算。

前序和中序为什么能重建树，只有前序为什么不行？

无重复值时前序首项确定根，中序根位置划出左右子树，再递归决定结构；只有前序无法区分“根的左孩子”和“根的右孩子”，除非补上空节点标记或其他结构约束。

07.02

后序汇总：平衡性与直径

知识与适用场景

一个子树可以同时返回结构信息并帮助更新全局答案。判断平衡需要高度；直径需要左右高度之和，但向父节点只能返回可继续连接的单边高度。

2.1 后序报告：先写空树值，再写合并公式

空树高度0、节点数0、直径0、平衡为true，是一份可以直接参与合并的子树报告。非空节点高度为1+max(左高,右高)，节点数为左数+右数+1，平衡要求左右都平衡且高度差至多1。

直径是一条任意两节点之间的简单路径，按边计。经过当前节点的候选直径是左高+右高；整棵子树的直径还要与左右子树内部的直径取max。不一定经过整棵树的根。

struct TreeNode {
    int val;
    TreeNode *left = nullptr, *right = nullptr;
    explicit TreeNode(int value) : val(value) {}
};

struct TreeSummary {
    int height = 0;
    int nodes = 0;
    int diameter = 0;
    bool balanced = true;
};
TreeSummary summarizeTree(TreeNode* root) {
    if (!root) return {};
    TreeSummary left = summarizeTree(root->left);
    TreeSummary right = summarizeTree(root->right);
    TreeSummary result;
    result.height = 1 + max(left.height, right.height);
    result.nodes = 1 + left.nodes + right.nodes;
    result.balanced = left.balanced && right.balanced &&
                      abs(left.height - right.height) <= 1;
    result.diameter = max({left.diameter, right.diameter, left.height + right.height});
    return result;
}

2.4 朴素重复求高度为什么可能二次

若每个节点先分别调用height求左右高度，再递归检查孩子，同一后代会被祖先反复扫描。链状树在不做有效短路的情况下累计n+(n-1)+…+1=O(n²)。后序把高度作为返回值传回，每个节点只处理常数次。

不要为了降低参数数量，把所有信息都塞入持久成员变量却忘记重置。把结果作为返回结构，或在公开入口里初始化局部答案再调用辅助DFS，更适合反复调用测试。

推导 / 不变量

平衡检查用 -1 代表不平衡。先算左右子树，只要任何一侧失败或高度差大于 1，立刻向上传递失败；否则返回当前高度。

一个节点左高 3、右高 1，高度差 2，整棵树在这里失败。祖先无需重复遍历子树计算高度。

struct TreeNode {
    int val; TreeNode *left=nullptr, *right=nullptr;
    explicit TreeNode(int v):val(v){}
};
int balancedHeight(TreeNode* node) {
    if (!node) return 0;
    int l=balancedHeight(node->left);
    if (l==-1) return -1;
    int r=balancedHeight(node->right);
    if (r==-1 || abs(l-r)>1) return -1;
    return 1+max(l,r);
}
bool isBalanced(TreeNode* root) {
    return balancedHeight(root)!=-1;
}
复杂度
时间 O(n)，空间 O(h)。逐节点重新求高度的朴素实现最坏 O(n²)。
易错点与边界
直径若以边数计，用 leftHeight+rightHeight；以节点数计再加 1。最大路径和中向上返回不能同时选左右两边。

2.5 最大路径和：完整路径可拐弯，返回值只能单边

一条简单路径在当前节点可以连接左右两支，但若把这条双分支路径再接父节点，就会出现三叉，不再是一条路径。因此更新best可以两边都取，向上只能返回一边。负收益不取，但当前节点必须取，以保证路径非空。

全负树必须返回最大那个节点，例如[-3,-2,-5]返回-2；best不能初始化为0。空树用nullopt表示不存在非空路径。时间O(n)、栈O(h)，路径和满足本章long long数值约束。

struct TreeNode {
    int val;
    TreeNode *left = nullptr, *right = nullptr;
    explicit TreeNode(int value) : val(value) {}
};

optional<long long> maximumPathSum(TreeNode* root) {
    if (!root) return nullopt;
    long long best = LLONG_MIN;
    function<long long(TreeNode*)> gain = [&](TreeNode* node) -> long long {
        if (!node) return 0;
        long long left = max(0LL, gain(node->left));
        long long right = max(0LL, gain(node->right));
        best = max(best, (long long)node->val + left + right);
        return (long long)node->val + max(left, right);
    };
    gain(root);
    return best;
}

        if (!node) return;

        sum += node->val;
        if (!node->left && !node->right) {
            if (sum == target) answer.push_back(path);
        } else {

            dfs(node->right, sum);
        }
        path.pop_back();
    };

2.8 树上前缀和：哈希表只包含当前祖先链

设当前根到节点累计和为S，若某个祖先之前的累计和为S-target，两者之间的向下路径和即为target。进入节点时先查询，再将S频次加一；递归左右孩子后把S频次减一。初始频次0为1，代表根之前的空前缀。

数组前缀表越走越长，因为所有过去位置都可能作为起点；树上兄弟节点不是祖先关系，不能共享已经退出分支的前缀。这里回溯不仅是节省空间，更是正确性的必要条件。

2.9 任意起点的向下路径数量：退出时撤销前缀

使用本章路径和范围，prefix-target也在long long内。每个节点平均常数次哈希操作，平均O(n)，冲突极端时最坏可达O(n²)；递归栈和当前路径前缀条目O(h)。回溯后重新find迭代器，避免使用递归插入可能触发rehash前保存的旧迭代器。

struct TreeNode {
    int val;
    TreeNode *left = nullptr, *right = nullptr;
    explicit TreeNode(int value) : val(value) {}
};

long long countDownwardPaths(TreeNode* root, long long target) {
    unordered_map<long long, long long> frequency;
    frequency[0] = 1;
    function<long long(TreeNode*, long long)> dfs =
        [&](TreeNode* node, long long prefix) -> long long {
            if (!node) return 0;
            prefix += node->val;
            long long result = 0;
            auto found = frequency.find(prefix - target);
            if (found != frequency.end()) result += found->second;
            ++frequency[prefix];
            result += dfs(node->left, prefix);
            result += dfs(node->right, prefix);
            auto current = frequency.find(prefix);
            if (--current->second == 0) frequency.erase(current);
            return result;
        };
    return dfs(root, 0);
}

面试追问：关键点完整解答

直径为什么是左高+右高，不需要再加1？

本章子树高度按节点数计，而直径按边数计。左子树到当前点的连接路径恰有leftHeight条边，右侧同理，加起来就是左右端点之间的边数；若题目按节点数定义路径长度，则再加1。

最大路径和为什么更新答案取两边，返回时只取一边？

完整路径可以以当前点为最高点连接左右两支，但父节点接入时只能连接一条向下链。把两支一起向上传递会造成当前节点连接三条边，不是一条简单路径。

负收益可以丢掉，为什么全负树答案不能是0？

题目要求非空路径，至少选一个节点。只允许丢掉孩子贡献，当前节点值仍参与候选；best初始化为负无穷，最终会选全树最大负值，而不是一条不存在的空路径。

根到叶路径中，和达到target就可以返回成功吗？

只有当前节点同时没有左右孩子时才符合终点条件。内部节点和恰好匹配不够；若允许负数，后续和还可能增减，所以也不能仅凭当前和超目标就剪枝。

树上前缀频次为什么一定要回溯？

遍历右子树时，左子树中的节点不是它的祖先。若残留左分支前缀，会把跨兄弟的状态差当作合法向下路径。撤销保证哈希表始终只描述当前祖先链。

为什么退出前缀后还要删除计数为0的键？

减到0已足以避免答案多计，但保留零频次键会让表随全树不同前缀增长到O(n)。删除后活跃条目与当前路径相关，条目空间保持O(h)；查询使用find也避免插入无用的补数键。

07.03

BST 的全局范围约束

知识与适用场景

BST 不仅要求左孩子小于根，还要求整个左子树都小于根。验证时把祖先施加的上下界一路传下去；默认不允许重复值。

3.1 BST约束覆盖整棵子树，不是只看两条边

默认所有键互异。每个节点的左子树所有键都小于它，右子树所有键都大于它。基础范围验证从(LLONG_MIN,LLONG_MAX)开始，左递归收紧上界、右递归收紧下界，因此祖先约束不会在下一层丢失。

节点值是int，所以long long极值可作为严格外部边界。如果节点本身改成long long，不能再用同类型极值当排除边界，应改成optional边界或显式开闭标记。

3.3 中序严格递增与全局合法范围等价

严格BST中，左子树的所有值小于根、右侧所有值大于根，递归中序得到严格递增序列。反过来，对二叉树中序序列逐个检查严格递增，也能保证左、根、右的全局次序。用一个prev指针或optional保存前项即可，不能把prev值初始化成INT_MIN并立即比较。

若允许重复且只放右子树，中序仅非递减是必要但不充分：根2的左孩子2也会生成非递减序列，却违反重复放右的规则。需要把约束改成左侧上界不含根、右侧下界包含根，并明确每个边界的开闭性。

struct TreeNode {
    int val;
    TreeNode *left = nullptr, *right = nullptr;

};

bool validBSTIterative(TreeNode* root) {
    vector<TreeNode*> pending;
    TreeNode* current = root;
    optional<int> previous;
    while (current || !pending.empty()) {
        while (current) { pending.push_back(current); current = current->left; }
        current = pending.back(); pending.pop_back();
        if (previous && current->val <= *previous) return false;
        previous = current->val;
        current = current->right;
    }
    return true;
}
TreeNode* searchBST(TreeNode* root, int key) {
    while (root && root->val != key)
        root = key < root->val ? root->left : root->right;
    return root;
}
optional<int> kthSmallestBST(TreeNode* root, int k) {
    if (k <= 0) return nullopt;
    vector<TreeNode*> pending;
    TreeNode* current = root;
    while (current || !pending.empty()) {
        while (current) { pending.push_back(current); current = current->left; }
        current = pending.back(); pending.pop_back();
        if (--k == 0) return current->val;
        current = current->right;
    }
    return nullopt;
}

3.6 插入与删除：树的根本身也可能改变

插入沿键值方向走到空链接，将新节点接入。返回根或以TreeNode*&更新根，不能只改变函数内根指针副本。重复键在本章接口中拒绝，传入节点必须是由调用者持有的孤立节点，不得已经属于其他树。

删除分三类：叶子用空替代；单孩子用孩子替代；双孩子用右子树最小节点（后继）替代。常见实现复制后继值再删后继，但会改变某个节点的值；如果外部持有节点身份，这种语义要说明。下面采用物理移植后继，保留其他节点的值与身份。

3.7 非拥有式插入与删除：摘除节点但不释放

两函数假设原树为严格BST，时间O(h)、额外空间O(1)。detach返回被摘除的原节点；不存在则返回nullptr。TreeNode**让同一段逻辑既能更新根链接也能更新父节点孩子链接。

不调用delete，因为节点可能来自arena、栈或外部统一管理。若调用者用new单独分配且拥有该节点，摘除后可自行释放；若来自TreeArena，不得单独delete。节点摘除后左右指针清空，便于检查与复用。

struct TreeNode {
    int val;
    TreeNode *left = nullptr, *right = nullptr;
    explicit TreeNode(int value) : val(value) {}
};

bool insertBST(TreeNode*& root, TreeNode* fresh) {
    if (!fresh || fresh->left || fresh->right)
        throw invalid_argument("detached leaf required");
    TreeNode** link = &root;
    while (*link) {
        if ((*link)->val == fresh->val) return false;
        link = fresh->val < (*link)->val ? &(*link)->left : &(*link)->right;
    }
    *link = fresh;
    return true;
}
TreeNode* detachBST(TreeNode*& root, int key) {
    TreeNode** link = &root;
    while (*link && (*link)->val != key)
        link = key < (*link)->val ? &(*link)->left : &(*link)->right;
    if (!*link) return nullptr;
    TreeNode* victim = *link;
    if (!victim->left) *link = victim->right;
    else if (!victim->right) *link = victim->left;
    else {
        TreeNode** nextLink = &victim->right;
        while ((*nextLink)->left) nextLink = &(*nextLink)->left;
        TreeNode* successor = *nextLink;
        *nextLink = successor->right;
        successor->left = victim->left;
        successor->right = victim->right;
        *link = successor;
    }
    victim->left = victim->right = nullptr;
    return victim;
}

3.8 BST惰性迭代器：一次next不一定是常数时间

构造O(h)、辅助空间O(h)。一次next可能压入长左链而耗时O(h)，但遍历所有节点时每个节点入出栈一次，整体O(n)，next按完整遍历均摊O(1)。若只取k个，含初始化成本为O(h+k)。

迭代器不拥有节点。使用期间树必须存活且不进行会改变这些连接或释放节点的操作；它没有自动跟踪BST插入删除的能力。

3.9 恢复恰好两个交换值的BST

契约是原树为互异键BST，恰有两个节点的值被交换且连接不变。中序相邻位置交换形成一个下降点，非相邻交换通常形成两个；记录第一次下降的前项与最后一次下降的后项并交换。时间O(n)、栈O(h)。

返回true只表示执行了交换，不代表能修复任意非法二叉树。该函数会改变值，不移动节点；合法未交换的BST返回false。不要把它用作通用排序整棵树的算法。

struct TreeNode {
    int val;
    TreeNode *left = nullptr, *right = nullptr;
    explicit TreeNode(int value) : val(value) {}
};

bool recoverSwappedBST(TreeNode* root) {
    vector<TreeNode*> pending;
    TreeNode *current = root, *previous = nullptr;
    TreeNode *first = nullptr, *second = nullptr;
    while (current || !pending.empty()) {
        while (current) { pending.push_back(current); current = current->left; }
        current = pending.back(); pending.pop_back();
        if (previous && previous->val > current->val) {
            if (!first) first = previous;
            second = current;
        }
        previous = current;
        current = current->right;
    }
    if (!first) return false;
    swap(first->val, second->val);
    return true;
}

为什么只比较node和直接左右孩子不够？

后代还要满足所有祖先的范围。例如10的左孩子5、5的右孩子12，每条直接边都满足大小方向，但12仍位于10的左子树而大于10。

普通BST搜索为什么不能无条件写O(logn)？

每次只排除一个子树，但剩余子树未必只有一半。顺序插入1..n会形成高度n的链，搜索最坏O(n)。只有平衡性或合适随机模型下才能得到对数高度结论。

重复只允许放右边时，中序非递减能充分验证吗？

不能。根2左孩子2同样中序非递减，却违反重复放右。要用带开闭性的上下界，确保左子树严格小于根、右子树允许等于根，并继承祖先限制。

删除双孩子节点为什么后继没有左孩子？

后继是右子树中不断向左走到的最小节点。如果它还有左孩子，这个孩子会更小，与最小性矛盾。它可能有右孩子，移植时必须接回后继原位置，不能丢掉。

维护子树size为何能加速多次第K小查询？

知道左子树节点数L，就可判断K<=L去左边、K=L+1取根、否则去右边找K-L-1。每层只走一侧，时间O(h)；插入删除和旋转时必须同步维护size，不能使用过期统计。

迭代器next均摊O(1)能推出每次延迟都是O(1)吗？

不能。某次next可能展开深右子树的整条左链，花O(h)。均摊只说明完整序列的总成本线性；严格实时延迟要求需要另外的接口和数据结构设计。

4.1 普通LCA的返回语义与存在性前提

    TreeNode *left = nullptr, *right = nullptr;
    explicit TreeNode(int value) : val(value) {}
};

struct LcaReport {
    unsigned mask = 0; // bit 0: p found, bit 1: q found
    TreeNode* ancestor = nullptr;
};
LcaReport reportLca(TreeNode* node, TreeNode* p, TreeNode* q) {
    if (!node) return {};
    LcaReport left = reportLca(node->left, p, q);
    LcaReport right = reportLca(node->right, p, q);
    unsigned own = (node == p ? 1U : 0U) | (node == q ? 2U : 0U);
    unsigned mask = left.mask | right.mask | own;
    TreeNode* ancestor = left.ancestor ? left.ancestor : right.ancestor;
    if (!ancestor && mask == 3U) ancestor = node;
    return {mask, ancestor};
}
TreeNode* lcaChecked(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!p || !q) return nullptr;
    LcaReport result = reportLca(root, p, q);
    return result.mask == 3U ? result.ancestor : nullptr;
}
TreeNode* lcaBSTChecked(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!p || !q) return nullptr;
    auto containsIdentity = [&](TreeNode* target) {
        TreeNode* node = root;
        while (node && node->val != target->val)
            node = target->val < node->val ? node->left : node->right;
        return node == target;
    };
    if (!containsIdentity(p) || !containsIdentity(q)) return nullptr;
    int low = min(p->val, q->val), high = max(p->val, q->val);
    while (root) {
        if (root->val < low) root = root->right;
        else if (root->val > high) root = root->left;
        else return root;
    }
    return nullptr;
}

4.4 多次LCA查询：用预处理交换查询成本

若同一棵静态树有十万次查询，每次DFS总O(nq)可能太慢。可先赋予节点编号、记录深度与父节点，再建up[v][j]表示2^j层祖先：先把深节点提到同深度，再从高位往低位一起跳，最后返回父节点。预处理O(nlogn)、查询O(logn)、空间O(nlogn)。

另一条路线是Euler游走记录节点与深度，将LCA变为首次出现位置间的最小深度查询，再用RMQ结构处理。这里只介绍选择依据；树结构发生改变后，静态预处理信息不能继续无条件复用。

推导 / 不变量

遇到 p 或 q 直接返回；左右非空时返回当前节点，否则返回非空一侧。这个简洁版本要求 p、q 都确实存在于树中。

4.5 重建：前序消耗一个根，中序决定左右范围

无重复值时，前序当前元素是子树根，中序中该值的位置m唯一确定左[l,m)、右[m+1,r)。维护一个共享前序游标，先构造左边再右边；中序位置用哈希索引，避免每次线性扫描，也避免对子数组进行反复拷贝。

前提不仅是长度相同，还要值集合相同、各自无重复，而且根必须落在当前中序范围。例如前序[1,2,3]、中序[3,1,2]集合相同却无法匹配递归范围，仍应拒绝。含重复值时不能用“值→唯一位置”的映射直接重建。

TreeNode* rebuildPreIn(const vector<int>& preorder, const vector<int>& inorder,
                       TreeArena& arena) {
    if (preorder.size() != inorder.size() || preorder.size() > 100000)
        throw invalid_argument("size mismatch or input too large");
    int n = (int)preorder.size();
    unordered_map<int, int> position;
    for (int i = 0; i < n; ++i)
        if (!position.emplace(inorder[i], i).second)
            throw invalid_argument("duplicate inorder key");
    unordered_set<int> seen;
    for (int value : preorder)
        if (!position.count(value) || !seen.insert(value).second)
            throw invalid_argument("different keys or duplicate preorder key");
    int cursor = 0;
    function<TreeNode*(int, int)> build = [&](int l, int r) -> TreeNode* {
        if (l == r) return nullptr;
        if (cursor == n) throw invalid_argument("preorder exhausted");
        int value = preorder[cursor++];
        int middle = position.at(value);
        if (middle < l || middle >= r) throw invalid_argument("inconsistent traversals");
        TreeNode* root = arena.make(value);
        root->left = build(l, middle);
        root->right = build(middle + 1, r);
        return root;
    };
    TreeNode* root = build(0, n);
    if (cursor != n) throw invalid_argument("unused preorder entries");
    return root;
}

4.8 序列化必须保留结构，不只是遍历值

只有值的前序序列[1,2]可能是1的左孩子2，也可能是右孩子2。把每个空孩子写成#，两棵树分别为1,2,#,#,#与1,#,2,#,#，才可唯一恢复。n个节点的完整前序空标记格式共有2n+1个token。

解码可用“待填槽位”预检查：初始一个根槽位；每个token消耗一个槽位；非空节点再增加两个孩子槽位。中途槽位不能已经为0却还有token，结束必须恰为0。这样可拒绝缺少空标记、额外尾部数据等格式错误。

4.9 前序序列化与解码：空标记、验证与独立副本

序列化输出vector<string>，可用逗号或换行连接成文本；调用解码前需按相同分隔约定切成token。整数解析采用stoi语义（允许符号及其接受的前导空白），序列化端输出规范十进制。#专用于空节点，空树编码为单个#。

解码在分配前验证全部token值和槽位结构，整数越界也会抛异常。新树节点全部从传入arena新建，值与结构保持，指针身份不与原树相同。时间O(n)（固定int长度）、token和解析缓存O(n)、递归O(h)、新树O(n)。它是普通树格式，不支持环或共享子节点图。

vector<string> serializeTree(TreeNode* root) {
    vector<string> tokens;
    function<void(TreeNode*)> encode = [&](TreeNode* node) {
        if (!node) { tokens.push_back("#"); return; }
        tokens.push_back(to_string(node->val));
        encode(node->left);
        encode(node->right);
    };
    encode(root);
    return tokens;
}
TreeNode* deserializeTree(const vector<string>& tokens, TreeArena& arena) {
    if (tokens.empty() || tokens.size() > 200001)
        throw invalid_argument("invalid token count");
    vector<optional<int>> parsed;
    long long slots = 1;
    for (const string& token : tokens) {
        if (slots == 0) throw invalid_argument("trailing token");
        --slots;
        if (token == "#") parsed.push_back(nullopt);
        else {
            size_t used = 0;
            int value = stoi(token, &used);
            if (used != token.size()) throw invalid_argument("bad integer token");
            parsed.push_back(value);
            slots += 2;
        }
    }
    if (slots != 0) throw invalid_argument("missing child token");
    size_t cursor = 0;
    function<TreeNode*()> decode = [&]() -> TreeNode* {
        optional<int> value = parsed[cursor++];
        if (!value) return nullptr;
        TreeNode* node = arena.make(*value);
        node->left = decode();
        node->right = decode();
        return node;
    };
    return decode();
}

面试追问：关键点完整解答

普通LCA为什么必须按指针而不是值比较？

两个不同节点可能有相同值。题目要找的是两个具体节点的共同祖先，仅按val会把其他同值节点误认成目标。指针身份代表对象，值只是对象的一个字段。

一个目标不存在时，基础LCA会返回什么？

它可能返回存在的那个目标，而不是nullptr，因为非空返回值没有区分“只找到一个”和“两个都找齐”。应采用命中位掩码或先检查目标存在性；本章checked接口找不齐返回nullptr。

p和q是同一个节点，需要特殊处理吗？

需要保证算法语义支持该情况。位掩码实现同一指针同时设置两个目标位，因此找到一次就命中两者；该节点就是自身与自身的最近公共祖先，若不在树里仍返回nullptr。

前序+中序有重复值时还保证唯一吗？

不保证。例如两个相同值无法唯一确定中序哪个位置是根，也无法区分单孩子方向。若要重建必须补充身份、结构标记或其他约束，不能简单把哈希表中的重复位置覆盖掉。

序列化为什么需要2n+1个token？

二叉树n个非空节点共有2n个孩子槽位，其中n-1个连接真实孩子，剩余n+1个为空。加上n个节点值，共2n+1个token；空树n=0时也有一个#。

重建返回的根指针谁负责释放？

本章分配型示例由TreeArena统一拥有。返回指针只是借用，在arena销毁后立即失效；不能单独delete。不同所有权模型可以实现同样算法，但必须统一，不能把arena节点当成独立new节点释放。

vector<int> preorderIterative(TreeNode* root) {

    while (!pending.empty()) {
        TreeNode* node = pending.back(); pending.pop_back();

vector<int> postorderIterative(TreeNode* root) {
    vector<int> result;
    if (!root) return result;
    vector<pair<TreeNode*, bool>> pending{{root, false}};
    while (!pending.empty()) {
        auto [node, expanded] = pending.back(); pending.pop_back();
        if (expanded) { result.push_back(node->val); continue; }
        pending.push_back({node, true});
        if (node->right) pending.push_back({node->right, false});
        if (node->left) pending.push_back({node->left, false});
    }
    return result;
}

vector<vector<int>> levelOrder(TreeNode* root) {

        for (size_t i = 0; i < width; ++i) {

            if (node->left) pending.push(node->left);
            if (node->right) pending.push(node->right);

        result.push_back(move(level));
    }
    return result;

optional<long long> maximumPathSum(TreeNode* root) {
    if (!root) return nullopt;
    long long best = LLONG_MIN;
    function<long long(TreeNode*)> gain = [&](TreeNode* node) -> long long {
        if (!node) return 0;
        long long left = max(0LL, gain(node->left));
        long long right = max(0LL, gain(node->right));
        best = max(best, (long long)node->val + left + right);
        return (long long)node->val + max(left, right);
    };
    gain(root);
    return best;
}

vector<vector<int>> rootLeafPaths(TreeNode* root, long long target) {
    vector<vector<int>> answer;
    vector<int> path;
    function<void(TreeNode*, long long)> dfs = [&](TreeNode* node, long long sum) {
        if (!node) return;
        path.push_back(node->val);
        sum += node->val;
        if (!node->left && !node->right) {
            if (sum == target) answer.push_back(path);
        } else {
            dfs(node->left, sum);
            dfs(node->right, sum);
        }
        path.pop_back();
    };
    dfs(root, 0);
    return answer;
}

long long countDownwardPaths(TreeNode* root, long long target) {
    unordered_map<long long, long long> frequency;
    frequency[0] = 1;
    function<long long(TreeNode*, long long)> dfs =
        [&](TreeNode* node, long long prefix) -> long long {
            if (!node) return 0;
            prefix += node->val;
            long long result = 0;
            auto found = frequency.find(prefix - target);
            if (found != frequency.end()) result += found->second;
            ++frequency[prefix];
            result += dfs(node->left, prefix);
            result += dfs(node->right, prefix);
            auto current = frequency.find(prefix);
            if (--current->second == 0) frequency.erase(current);
            return result;
        };
    return dfs(root, 0);
}

bool validBSTIterative(TreeNode* root) {
    vector<TreeNode*> pending;
    TreeNode* current = root;
    optional<int> previous;
    while (current || !pending.empty()) {
        while (current) { pending.push_back(current); current = current->left; }
        current = pending.back(); pending.pop_back();
        if (previous && current->val <= *previous) return false;
        previous = current->val;
        current = current->right;
    }
    return true;
}

bool insertBST(TreeNode*& root, TreeNode* fresh) {
    if (!fresh || fresh->left || fresh->right)
        throw invalid_argument("detached leaf required");
    TreeNode** link = &root;
    while (*link) {
        if ((*link)->val == fresh->val) return false;
        link = fresh->val < (*link)->val ? &(*link)->left : &(*link)->right;
    }
    *link = fresh;
    return true;
}
TreeNode* detachBST(TreeNode*& root, int key) {
    TreeNode** link = &root;
    while (*link && (*link)->val != key)
        link = key < (*link)->val ? &(*link)->left : &(*link)->right;
    if (!*link) return nullptr;
    TreeNode* victim = *link;
    if (!victim->left) *link = victim->right;
    else if (!victim->right) *link = victim->left;
    else {
        TreeNode** nextLink = &victim->right;
        while ((*nextLink)->left) nextLink = &(*nextLink)->left;
        TreeNode* successor = *nextLink;
        *nextLink = successor->right;
        successor->left = victim->left;
        successor->right = victim->right;
        *link = successor;
    }
    victim->left = victim->right = nullptr;
    return victim;
}

class BSTIterator {
    vector<TreeNode*> pending;
    void pushLeft(TreeNode* node) {
        while (node) { pending.push_back(node); node = node->left; }
    }
public:
    explicit BSTIterator(TreeNode* root) { pushLeft(root); }
    bool hasNext() const { return !pending.empty(); }
    int next() {
        if (pending.empty()) throw out_of_range("iterator exhausted");
        TreeNode* node = pending.back(); pending.pop_back();
        pushLeft(node->right);
        return node->val;
    }
};

bool recoverSwappedBST(TreeNode* root) {
    vector<TreeNode*> pending;
    TreeNode *current = root, *previous = nullptr;
    TreeNode *first = nullptr, *second = nullptr;
    while (current || !pending.empty()) {
        while (current) { pending.push_back(current); current = current->left; }
        current = pending.back(); pending.pop_back();
        if (previous && previous->val > current->val) {
            if (!first) first = previous;
            second = current;
        }
        previous = current;
        current = current->right;
    }
    if (!first) return false;
    swap(first->val, second->val);
    return true;
}

struct LcaReport {
    unsigned mask = 0; // bit 0: p found, bit 1: q found
    TreeNode* ancestor = nullptr;
};
LcaReport reportLca(TreeNode* node, TreeNode* p, TreeNode* q) {
    if (!node) return {};
    LcaReport left = reportLca(node->left, p, q);
    LcaReport right = reportLca(node->right, p, q);
    unsigned own = (node == p ? 1U : 0U) | (node == q ? 2U : 0U);
    unsigned mask = left.mask | right.mask | own;
    TreeNode* ancestor = left.ancestor ? left.ancestor : right.ancestor;
    if (!ancestor && mask == 3U) ancestor = node;
    return {mask, ancestor};
}
TreeNode* lcaChecked(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!p || !q) return nullptr;
    LcaReport result = reportLca(root, p, q);
    return result.mask == 3U ? result.ancestor : nullptr;
}
TreeNode* lcaBSTChecked(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!p || !q) return nullptr;
    auto containsIdentity = [&](TreeNode* target) {
        TreeNode* node = root;
        while (node && node->val != target->val)
            node = target->val < node->val ? node->left : node->right;
        return node == target;
    };
    if (!containsIdentity(p) || !containsIdentity(q)) return nullptr;
    int low = min(p->val, q->val), high = max(p->val, q->val);
    while (root) {
        if (root->val < low) root = root->right;
        else if (root->val > high) root = root->left;
        else return root;
    }
    return nullptr;
}

TreeNode* rebuildPreIn(const vector<int>& preorder, const vector<int>& inorder,
                       TreeArena& arena) {
    if (preorder.size() != inorder.size() || preorder.size() > 100000)
        throw invalid_argument("size mismatch or input too large");
    int n = (int)preorder.size();
    unordered_map<int, int> position;
    for (int i = 0; i < n; ++i)
        if (!position.emplace(inorder[i], i).second)
            throw invalid_argument("duplicate inorder key");
    unordered_set<int> seen;
    for (int value : preorder)
        if (!position.count(value) || !seen.insert(value).second)
            throw invalid_argument("different keys or duplicate preorder key");
    int cursor = 0;
    function<TreeNode*(int, int)> build = [&](int l, int r) -> TreeNode* {
        if (l == r) return nullptr;
        if (cursor == n) throw invalid_argument("preorder exhausted");
        int value = preorder[cursor++];
        int middle = position.at(value);
        if (middle < l || middle >= r) throw invalid_argument("inconsistent traversals");
        TreeNode* root = arena.make(value);
        root->left = build(l, middle);
        root->right = build(middle + 1, r);
        return root;
    };
    TreeNode* root = build(0, n);
    if (cursor != n) throw invalid_argument("unused preorder entries");
    return root;
}

vector<string> serializeTree(TreeNode* root) {
    vector<string> tokens;
    function<void(TreeNode*)> encode = [&](TreeNode* node) {
        if (!node) { tokens.push_back("#"); return; }
        tokens.push_back(to_string(node->val));
        encode(node->left);
        encode(node->right);
    };
    encode(root);
    return tokens;
}
TreeNode* deserializeTree(const vector<string>& tokens, TreeArena& arena) {
    if (tokens.empty() || tokens.size() > 200001)
        throw invalid_argument("invalid token count");
    vector<optional<int>> parsed;
    long long slots = 1;
    for (const string& token : tokens) {
        if (slots == 0) throw invalid_argument("trailing token");
        --slots;
        if (token == "#") parsed.push_back(nullopt);
        else {
            size_t used = 0;
            int value = stoi(token, &used);
            if (used != token.size()) throw invalid_argument("bad integer token");
            parsed.push_back(value);
            slots += 2;
        }
    }
    if (slots != 0) throw invalid_argument("missing child token");
    size_t cursor = 0;
    function<TreeNode*()> decode = [&]() -> TreeNode* {
        optional<int> value = parsed[cursor++];
        if (!value) return nullptr;
        TreeNode* node = arena.make(*value);
        node->left = decode();
        node->right = decode();
        return node;
    };
    return decode();
}

void require(bool ok, const string& message) {
    if (!ok) throw runtime_error(message);
}
vector<TreeNode*> checkedNodes(TreeNode* root) {
    vector<TreeNode*> result;
    if (!root) return result;
    unordered_set<TreeNode*> seen;
    vector<TreeNode*> pending{root};
    while (!pending.empty()) {
        TreeNode* node = pending.back(); pending.pop_back();
        require(seen.insert(node).second, "cycle or shared child");
        result.push_back(node);
        if (node->right) pending.push_back(node->right);
        if (node->left) pending.push_back(node->left);
    }
    return result;
}
int bruteMinimumDepth(TreeNode* node) {
    if (!node) return 0;
    if (!node->left) return 1 + bruteMinimumDepth(node->right);
    if (!node->right) return 1 + bruteMinimumDepth(node->left);
    return 1 + min(bruteMinimumDepth(node->left), bruteMinimumDepth(node->right));
}
long long bruteDownward(TreeNode* root, long long target) {
    function<long long(TreeNode*, long long)> from =
        [&](TreeNode* node, long long sum) -> long long {
            if (!node) return 0;
            sum += node->val;
            return (sum == target) + from(node->left, sum) + from(node->right, sum);
        };
    long long count = 0;
    for (TreeNode* node : checkedNodes(root)) count += from(node, 0);
    return count;
}
pair<int, optional<long long>> bruteAllPaths(TreeNode* root) {
    auto nodes = checkedNodes(root);
    if (nodes.empty()) return {0, nullopt};
    unordered_map<TreeNode*, int> id;
    for (int i = 0; i < (int)nodes.size(); ++i) id[nodes[i]] = i;
    vector<vector<int>> edges(nodes.size());
    for (int i = 0; i < (int)nodes.size(); ++i) {
        for (TreeNode* child : {nodes[i]->left, nodes[i]->right}) {
            if (!child) continue;
            int j = id.at(child);
            edges[i].push_back(j); edges[j].push_back(i);
        }
    }
    int diameter = 0;
    long long best = LLONG_MIN;
    for (int start = 0; start < (int)nodes.size(); ++start) {
        vector<int> distance(nodes.size(), -1);
        vector<long long> sum(nodes.size());
        queue<int> pending;
        distance[start] = 0; sum[start] = nodes[start]->val; pending.push(start);
        while (!pending.empty()) {
            int u = pending.front(); pending.pop();
            diameter = max(diameter, distance[u]);
            best = max(best, sum[u]);
            for (int v : edges[u]) if (distance[v] == -1) {
                distance[v] = distance[u] + 1;
                sum[v] = sum[u] + nodes[v]->val;
                pending.push(v);
            }
        }
    }
    return {diameter, best};
}
TreeNode* bruteLca(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || !p || !q) return nullptr;
    unordered_map<TreeNode*, TreeNode*> parent;
    parent[root] = nullptr;
    for (TreeNode* node : checkedNodes(root)) {
        if (node->left) parent[node->left] = node;
        if (node->right) parent[node->right] = node;
    }
    if (!parent.count(p) || !parent.count(q)) return nullptr;
    unordered_set<TreeNode*> ancestors;
    for (; p; p = parent.at(p)) ancestors.insert(p);
    for (; q; q = parent.at(q)) if (ancestors.count(q)) return q;
    return nullptr;
}

章末自测：八个关键问题及答案

1. 根只有一个左叶子，最小深度和直径分别是多少？

按本章约定最小深度为2个节点，直径为1条边。空的右孩子不是可选的根叶路径，不能用min(1,0)+1得到1。

2. 左高3、右高2，当前高度和经过当前点的直径是多少？

当前高度为1+max(3,2)=4，经过当前点的直径为3+2=5条边。整棵子树直径还要与左右子树内部直径比较，不能只看当前候选。

3. 全负树的最大路径为什么不是空路径0？

定义要求至少一个节点。负的孩子收益可以舍弃，但当前节点仍需参加候选；最终选择最大负值节点，空树则通过optional单独表达无路径。

4. 根1、左右孩子都是-1，向下和为0的路径有几条？

只有根到左孩子、根到右孩子两条。左右孩子不构成合法向下祖先链，进入右分支前必须撤销左分支前缀，否则会多计。

5. 根10、左5、5右12是不是BST？

不是。12必须同时满足大于5和小于祖先10，即落在(5,10)，但实际越界。检查直接父子关系会漏掉这个反例。

6. p是树内节点，q是树外但同值节点，LCA该怎么返回？

带存在性验证的接口应返回nullptr。节点相等必须比较身份而非val，基础简洁LCA若缺少存在性契约可能只返回p，不能据此宣称找到了两个目标的祖先。

7. 前序1,2与前序1,2,#,#,#的信息量有什么不同？

前者可能是左孩子2或右孩子2，结构不唯一；后者带空标记，唯一表示根1的左孩子2、右孩子为空。空标记是结构的一部分，不应任意丢弃。

8. arena生成的节点从BST摘除后，能直接delete吗？

不能。arena仍是节点所有者，摘除只改变可达关系；节点存储最终随arena统一回收。手动delete一个deque中的对象地址不匹配分配方式，会造成错误。
