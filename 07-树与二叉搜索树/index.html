07.01

遍历顺序与显式栈

知识与适用场景

前序在进入节点时处理，中序在左子树完成后处理，后序在两个孩子完成后处理。层序使用队列。选择顺序取决于当前计算依赖父节点还是孩子信息。

推导 / 不变量

迭代中序用栈保存暂时搁置的祖先：先沿左链入栈，弹出访问，再转到右子树。每个节点入栈、出栈各一次。

手推一个例子

树 2 的左右孩子为 1、3：压入 2、1，弹出 1；随后弹出 2，再进入 3，输出 1、2、3。

C++17
下载 .cpp
struct TreeNode {
    int val; TreeNode *left=nullptr, *right=nullptr;
    explicit TreeNode(int v):val(v){}
};
vector<int> inorder(TreeNode* root) {
    vector<int> ans;
    stack<TreeNode*> st;
    TreeNode* cur=root;
    while (cur || !st.empty()) {
        while (cur) { st.push(cur); cur=cur->left; }
        cur=st.top(); st.pop();
        ans.push_back(cur->val);
        cur=cur->right;
    }
    return ans;
}
复杂度
时间 O(n)，辅助栈 O(h)，输出 O(n)。退化树 h=n，平衡树 h=O(log n)。
易错点与边界
BFS 分层时，进入本层前保存队列大小，不能让新加入的下一层节点参与本层循环。

经典考点与练习

练习：LeetCode 94 中序遍历、102 层序遍历、199 二叉树的右视图。

07.02

后序汇总：平衡性与直径

知识与适用场景

一个子树可以同时返回结构信息并帮助更新全局答案。判断平衡需要高度；直径需要左右高度之和，但向父节点只能返回可继续连接的单边高度。

推导 / 不变量

平衡检查用 -1 代表不平衡。先算左右子树，只要任何一侧失败或高度差大于 1，立刻向上传递失败；否则返回当前高度。

手推一个例子

一个节点左高 3、右高 1，高度差 2，整棵树在这里失败。祖先无需重复遍历子树计算高度。

C++17
下载 .cpp
struct TreeNode {
    int val; TreeNode *left=nullptr, *right=nullptr;
    explicit TreeNode(int v):val(v){}
};
int balancedHeight(TreeNode* node) {
    if (!node) return 0;
    int l=balancedHeight(node->left);
    if (l==-1) return -1;
    int r=balancedHeight(node->right);
    if (r==-1 || abs(l-r)>1) return -1;
    return 1+max(l,r);
}
bool isBalanced(TreeNode* root) {
    return balancedHeight(root)!=-1;
}
复杂度
时间 O(n)，空间 O(h)。逐节点重新求高度的朴素实现最坏 O(n²)。
易错点与边界
直径若以边数计，用 leftHeight+rightHeight；以节点数计再加 1。最大路径和中向上返回不能同时选左右两边。

经典考点与练习

练习：LeetCode 110 平衡二叉树、543 二叉树的直径、124 二叉树中的最大路径和。

面试官可能继续问什么？

07.03

BST 的全局范围约束

知识与适用场景

BST 不仅要求左孩子小于根，还要求整个左子树都小于根。验证时把祖先施加的上下界一路传下去；默认不允许重复值。

推导 / 不变量

当前节点必须落在开区间 (lo,hi)。左子树的上界收紧为当前值，右子树的下界收紧为当前值。使用 long long 边界覆盖所有 int 节点值。

手推一个例子

根 10，左孩子 5，5 的右孩子 12。虽然每条父子边看似合理，但 12 位于 10 的左子树，违反上界 10。

C++17
下载 .cpp
struct TreeNode {
    int val; TreeNode *left=nullptr, *right=nullptr;
    explicit TreeNode(int v):val(v){}
};
bool validRange(TreeNode* p, long long lo, long long hi) {
    if (!p) return true;
    if (p->val<=lo || p->val>=hi) return false;
    return validRange(p->left,lo,p->val)
        && validRange(p->right,p->val,hi);
}
bool isValidBST(TreeNode* root) {
    return validRange(root,LLONG_MIN,LLONG_MAX);
}
复杂度
时间 O(n)，空间 O(h)。BST 查找平均 O(log n)，退化时 O(n)，普通 BST 不自动平衡。
易错点与边界
中序检查也能验证，但前一个值不能初始化为 INT_MIN 后直接严格比较，否则节点值等于 INT_MIN 时出错。

经典考点与练习

练习：LeetCode 98 验证二叉搜索树、230 二叉搜索树中第 K 小的元素、450 删除二叉搜索树中的节点。

07.04

最近公共祖先与返回值语义

知识与适用场景

对普通二叉树，递归返回“该子树中找到的目标节点或它们的 LCA”。若左右各找到一个，当前根就是分叉点；若只找到一侧，答案向上传递。

推导 / 不变量

遇到 p 或 q 直接返回；左右非空时返回当前节点，否则返回非空一侧。这个简洁版本要求 p、q 都确实存在于树中。

手推一个例子

若 p 在左子树、q 在右子树，当前节点是首次汇合点；若 p 本身是 q 的祖先，递归到 p 时返回 p，正好符合祖先可以是自身的定义。

C++17
下载 .cpp
struct TreeNode {
    int val; TreeNode *left=nullptr, *right=nullptr;
    explicit TreeNode(int v):val(v){}
};
TreeNode* lca(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || root==p || root==q) return root;
    TreeNode* a=lca(root->left,p,q);
    TreeNode* b=lca(root->right,p,q);
    if (a && b) return root;
    return a ? a : b;
}
复杂度
时间 O(n)，空间 O(h)。BST 的 LCA 可利用键值方向迭代，时间 O(h)、空间 O(1)。
易错点与边界
按节点身份比较指针，不能靠值区分重复节点。若目标可能不存在，需要额外统计找到的目标数或预先验证。

经典考点与练习

练习：LeetCode 236 二叉树的最近公共祖先、235 二叉搜索树的最近公共祖先、105 从前序与中序遍历构造二叉树。
