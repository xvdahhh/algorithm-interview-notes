## 建议学习方式

1. 先看摘要，能口述“适用信号、核心不变量、复杂度”。
2. 不看答案手写模板，并用最小输入、一般输入、极端输入验证。
3. 每类至少练 3 题：模板题、变式题、综合题。
4. 错题不要只存代码，要记录误判原因、关键不变量和下次识别信号。
5. 每周进行一次 45 分钟模拟面试：沟通、编码、测试、复杂度分析缺一不可。

## 掌握标准

- 能在 1 分钟内说明思路和数据结构选择。
- 能在 15～25 分钟内写出主体代码。
- 能主动覆盖空输入、单元素、重复值、溢出和越界。
- 能准确说明时间、空间复杂度，而不是只说“大概是线性的”。
- 能解释算法为什么正确，至少说清循环不变量、递归含义或状态转移来源。
